## 주요 폴더 설명

| 경로 | 내용 |
|---|---|
| `data/강원도_날씨데이터/` | 강원도 기상 격자, 시간/일 단위 날씨 데이터, 기상청 지점 목록과 시각화 이미지가 있습니다. |
| `data/강원도_데이터/` | 강원도 산불 발생 데이터와 공간 분석용 하위 데이터가 있습니다. |
| `data/강원도_데이터/강원도_공간데이터/` | DEM, 등산로, 도로, 임도망도, 토지피복도 등 강원도 공간 데이터가 있습니다. |
| `data/강원도_데이터/산불_공간데이터/` | 산불 분석에 활용되는 소방서, 소방용수시설, 지형특성 계산 데이터가 있습니다. |
| `data/예측데이터/` | 예측 모델 입력에 활용되는 강원도 전신주 좌표 데이터가 있습니다. |

# 예측데이터

## 1. 데이터 설명

`예측데이터` 폴더는 예측 모델 입력 또는 공간 예측 격자 생성을 위해 사용하는 좌표 기반 데이터를 보관한다.

현재 포함된 `gangwon_poles_4326.csv`는 강원 지역 전신주 위치 좌표 데이터이며, 각 행은 하나의 전신주 위치를 의미한다.

- 파일명: `gangwon_poles_4326.csv`
- 문자 인코딩: UTF-8
- 좌표계: WGS84 경도/위도(EPSG:4326)

## 2. 데이터 변수표

### `gangwon_poles_4326.csv`

| 변수명 | 자료 형태 | 설명 | 예시 데이터 |
|---|---|---|---|
| `pole_id` | integer | 전신주 위치의 고유 ID. | `0` |
| `lon` | float | 전신주 위치의 WGS84 경도. | `127.618391566544219` |
| `lat` | float | 전신주 위치의 WGS84 위도. | `37.732191618245423` |

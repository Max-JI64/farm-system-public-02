# 산불_전국

## 1. 데이터 출처

- 원천 데이터: 산림빅데이터 거래소 `산불발생위치도_전국`
- 원천 URL: <https://www.bigdata-forest.kr/orderProduct/FRT000101>
- 생성 코드: `전처리코드/data_preprocessing.ipynb`

## 2. 데이터 설명

`산불_전국` 폴더는 전국 산불 발생 위치 데이터를 정리한 CSV 파일을 보관한다. `산불발생위치도_전국.csv`는 산불 발생 시각, 위치, 발생 원인, 피해 정보를 포함하는 기본 테이블이며, `산불_공간DB_위경도.csv`는 공간 분석 연계를 위해 `fire_id`, `위도`, `경도`만 추출한 좌표 테이블이다.

- 좌표계: WGS84 위도/경도(EPSG:4326)

## 3. 생성 데이터 변수표

### `산불발생위치도_전국.csv`

- 행 수: 25,036건

| 변수명 | 자료 형태 | 설명 | 예시 데이터 |
|---|---|---|---|
| `fire_id` | string | 산불 발생 건의 고유 ID. | `F_000000` |
| `연도` | integer | 산불 발생 연도. | `2013` |
| `월` | integer | 산불 발생 월. | `3` |

| `시간` | integer | 산불 발생 시각의 시간 값. | `17` |
| `진화소요시간(HH)` | float | 산불 진화에 소요된 시간. 단위는 시간. | `0.9333333333333333` |
| `위도` | float | 산불 발생 위치의 WGS84 위도. | `37.63510045170228` |
| `경도` | float | 산불 발생 위치의 WGS84 경도. | `126.99758205559453` |
| `발생지역시도명` | string | 산불 발생 위치의 시도명. | `서울특별시` |
| `발생지역시군구명` | string | 산불 발생 위치의 시군구명. | `강북구` |
| `발생지역읍면동명` | string | 산불 발생 위치의 읍면동명. | `수유동` |
| `발생지역리명` | string | 산불 발생 위치의 리명. |  |
| `발생지역번지` | string | 산불 발생 위치의 지번. | `산127-1` |
| `발생원인명` | string | 산불 발생 원인명. | `노숙자실화 추정` |
| `피해면적(ha)` | float | 산불 피해 면적. 단위는 ha. |  |
| `피해금액` | float | 산불 피해 금액. |  |

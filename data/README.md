# data

이 폴더는 프로젝트에서 사용하는 데이터셋을 보관한다. 각 하위 폴더의 상세 설명은 해당 폴더의 `README.md`를 확인한다.

## 폴더 안내

| 폴더 | 설명 |
|---|---|
| `예측데이터` | 예측 모델 입력 또는 공간 예측 격자 생성을 위한 좌표 기반 데이터 |
| `산불_전국` | 전국 산불 발생 위치 및 산불 발생 좌표 데이터 |
| `산불_공간DB` | 산불 발생 지점과 공간·지형·시설 데이터를 결합한 공간 DB |
| `날씨데이터` | ASOS/AWS 기상 관측 자료 및 조회 범위 데이터 |

## 대용량 데이터 공유 안내

`날씨데이터`와 `산불_공간DB` 폴더는 파일 용량 이슈로 인해 Git 추적을 끊고 Google Drive로 공유된다.

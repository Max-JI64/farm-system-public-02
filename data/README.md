### `강원도날씨_격자.csv`, `강원도날씨_격자.geojson`, `강원도날씨_격자_영동영서_시각화.png`  
강원도 ASOS/AWS 관측지점을 함께 사용해 만든 대형 기상 셀.
전국 지형 데이터 `한반도90m_GRS80.img` DEM으로 태백산맥 기반 영동/영서 분리선을 만든다.
영동과 영서 영역 안에서 ASOS/AWS 지점을 모두 사용해 Voronoi 대형 셀을 생성한다.
`강원도날씨_격자_영동영서_시각화.png`은 이 셀과 영동영서 분리선을 시각화 한 이미지 파일이다.

#### 영동 영서 경계
1. 강원도 경계 내부에 1,000m 간격 샘플 점을 만들고, DEM에서 각 점의 고도를 읽는다.
2. 남북 방향으로 3,000m 높이의 구간을 나눈 뒤, 각 구간에서 고도가 높은 후보를 찾는다. 기본 후보 기준은 해당 구간 고도의 75퍼센타일 이상 또는 500m 이상이며, 후보가 너무 적으면 70퍼센타일 기준으로 완화한다.
3. 각 남북 구간에서 고도 후보 중 가장 동쪽에 있는 점을 선택한다. 이는 기후 분리선이 내륙의 절대 최고봉이 아니라 동해안으로 넘어가기 직전의 마지막 고지대에 가깝다는 판단을 반영한 것이다.
4. 선택된 점들을 남쪽에서 북쪽 순서로 정렬하고, X좌표를 가우시안 필터로 완만하게 다듬은 뒤 강원도 경계 위아래로 50km 연장한 선을 만든다.
5. 이 선으로 강원도 경계를 자른다. 잘린 조각의 대표점이 같은 Y좌표에서 분리선보다 동쪽이면 `영동`, 서쪽이면 `영서`로 분류하고 각각 하나의 권역으로 합친다.

#### 강원도 대형 기상 셀
1. 영동 권역 안에 있는 관측지점만 모아 영동 Voronoi를 만들고, 영서 권역 안에 있는 관측지점만 모아 영서 Voronoi를 만든다.
2. Voronoi는 EPSG:5186 좌표의 관측지점 좌표로 계산한다. 무한대로 열린 Voronoi 영역은 유한 폴리곤으로 복원한 뒤 각 권역 경계로 잘라낸다.
3. 이렇게 잘라낸 폴리곤 하나가 하나의 기상 셀이 된다. 따라서 셀은 강원도 경계 밖으로 나가지 않고, 영동/영서 분리선을 넘지 않는다.
4. 셀 ID는 권역 접두어와 순번으로 만든다. 영동은 `YD_0001`, `YD_0002` 형식이고 영서는 `YS_0001`, `YS_0002` 형식이다. 최종 `기상셀ID`는 `셀ID`와 동일하게 저장한다.
5. 각 셀에는 그 Voronoi를 만든 대표 관측지점의 관측망, 지점번호, 지점명, 면적, 중심 좌표, WGS84 WKT 영역을 함께 저장한다.

최종 결과는 `gangwon_weather_cells.csv`와 `gangwon_weather_cells.geojson`에 저장된다.

### `강원도날씨_격자_일단위.csv`, `강원도날씨_격자_시간단위.csv`  
생성된 92개 셀 중심점에 대해 ASOS/AWS 공통 변수만 IDW 보간한다.


#### IDW 보간 방법

IDW(Inverse Distance Weighting, 역거리 가중 보간)는 가까운 관측지점의 값일수록 더 큰 가중치를 주는 공간 보간 방식이다. 이 폴더의 보간은 50m 격자 전체가 아니라 `gangwon_weather_cells.csv`의 92개 셀 중심점에 대해 수행한다.

보간 대상 위치는 각 셀 폴리곤의 중심점이다. 중심점은 EPSG:5186에서 계산한 뒤 WGS84 위도/경도로 변환해 저장하고, 거리 계산에는 WGS84 위도/경도를 사용한다. 셀 내부 모든 지점이 같은 날씨값을 공유한다고 보고, 셀 중심점의 보간값을 해당 셀의 대표 날씨값으로 사용한다.

가중치 계산 절차는 다음과 같다.

1. `기상청_지점_목록.csv`에서 2020-2021년에 유효한 관측소 좌표를 읽는다.
2. 실제 ASOS/AWS 원자료에 존재하는 지점만 다시 필터링한다. 좌표 메타데이터가 없거나 해당 기간에 유효하지 않은 지점은 보간 가중치에서 제외한다.
3. 각 셀 중심점과 각 관측지점 사이의 거리는 haversine 공식으로 계산한다. 지구 반지름은 6,371.0088km를 사용한다.
4. 셀 중심점과 관측지점 거리가 0.001km 이하이면 같은 위치로 보고, 해당 지점 값에만 가중치를 준다. 같은 위치로 판정된 지점이 여러 개면 동일 가중으로 나눈다.
5. 기본 탐색 반경은 ASOS/AWS 공통 변수에서 30km다. 반경 안에 관측지점이 2개 이상 있으면 그 지점들을 모두 사용한다.
6. 반경 안 관측지점이 2개 미만이면 가장 가까운 3개 지점을 사용한다. 이 fallback 때문에 산간 또는 경계부 셀도 빈 보간값 없이 계산된다.
7. 선택된 관측지점 거리 `d`에 대해 원 가중치 `1 / d^2`를 계산한다.
8. 원 가중치 합이 1이 되도록 정규화한 뒤, 셀별 가중치 행렬을 `scipy.sparse.csr_matrix`로 저장한다.

일반 수치 변수의 보간값은 다음 식으로 계산한다.

```text
셀 보간값 = Σ(관측지점값_i × 정규화가중치_i)
정규화가중치_i = (1 / 거리_i^2) / Σ(1 / 거리_j^2)
```

풍향처럼 0도와 360도가 이어지는 방향 변수는 단순 평균을 사용하지 않는다. 예를 들어 350도와 10도를 산술평균하면 180도가 되어 실제 방향과 반대가 될 수 있기 때문이다. 그래서 풍향은 각도를 sine/cosine 성분으로 바꾼 뒤 각각 IDW 보간하고, 보간된 sine/cosine을 다시 각도로 변환한다.

```text
sin_interp = Σ(sin(풍향_i) × 정규화가중치_i)
cos_interp = Σ(cos(풍향_i) × 정규화가중치_i)
보간풍향 = atan2(sin_interp, cos_interp) mod 360
```

보간 변수는 ASOS와 AWS에 공통으로 존재하는 항목만 출력한다.

- 일별: 평균기온, 최저기온, 최고기온, 강수량, 최대순간풍속, 최대순간풍향
- 시간별: 기온, 풍속, 풍향, 강수량, 현지기압, 해면기압, 습도

보간 전 원자료는 변수별 허용 범위를 벗어나는 값을 `NaN`으로 바꾼다. 이후 관측지점별 시계열을 날짜/시간 축에 맞춰 정렬하고, 앞 방향 채움과 뒤 방향 채움으로 결측을 보정한다. 그래도 값이 남지 않는 경우에는 변수 성격에 맞는 기본값을 사용한다. 예를 들어 강수량, 풍속, 풍향은 0, 기압은 1000hPa, 습도는 50%, 기온 계열은 15도를 기본값으로 둔다.

성능을 위해 가중치는 매 날짜/시간마다 새로 계산하지 않는다. 먼저 92개 셀 중심점과 관측지점 사이의 IDW 가중치 행렬을 한 번 만들고, 이후 각 날짜/시간의 관측값 벡터에 행렬 곱을 적용한다. 출력 시 값은 소수 둘째 자리까지 반올림하고, 컬럼명은 한국어로 변환해 CSV에 저장한다.

### `강원도_산불_지형특성계산.csv`
`강원도_산불발생.csv` 산불이 발생한 지역의 지형적인 특성을 계산한 데이터이다.
DEM 데이터와 TWI 데이터가 사용되었다.
출쳐 : 산불발생위치도_전국 https://www.bigdata-forest.kr/orderProduct/FRT000101, 전국 DEM `한반도90m_GRS80.img` https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?dsId=30206, TWI https://www.bigdata-forest.kr/orderProduct/APH202112

#### 파생 변수 설명
* **고도(m)**: 해당 좌표의 해발 고도
* **경사도(도)**: 지형의 기울기 (0~90도). 산불 확산 속도에 직접적인 영향을 미침.
* **사면방향_sin / 사면방향_cos**: 사면이 바라보는 방위. 0도와 360도가 연결되는 원형 데이터(Circular Data)의 특성을 머신러닝 모델이 정확하게 인식하도록 안전하게 삼각함수 변환을 거친 값.
  * `사면방향_sin (동서 축)`: +1에 가까울수록 정동쪽, -1에 가까울수록 정서쪽
  * `사면방향_cos (남북 축)`: +1에 가까울수록 정북쪽, -1에 가까울수록 정남쪽
* **TPI(지형위치지수, Topographic Position Index)**: 주변 3x3 지형 평균 고도 대비 해당 좌표의 상대적인 고도 차이. (양수: 능선/산봉우리, 음수: 계곡/오목한 지형). 양간지풍 등 강풍의 영향을 많이 받는 능선부를 판단하는 핵심 지표.
* **TWI(지형다습지수, Topographic Wetness Index)**: 해당 지형에 물이 얼마나 잘 모이는지를 수치화한 지표. 값이 작을수록 건조하고 가파른 지형을 의미하며 산불 확산에 매우 취약함.

## `산불_공간DB_임상도_전국통합.csv`

### 1. 데이터 출처

- 산불 발생 위치 데이터: 산림빅데이터거래소 `산불발생위치도_전국`
  - URL: <https://www.bigdata-forest.kr/orderProduct/FRT000101>
- 임상도(1:5000): 브이월드 `임상도(1:5000)`
  - URL: <https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?dsId=30136>
- 수종별임상도(나무종류지도): 산림빅데이터거래소 `수종별임상도(나무종류지도)_시도`
  - URL: <https://www.bigdata-forest.kr/orderProduct/FRT001102>

### 2. 데이터 생성 방법

본 데이터는 `jsw/data/임상도/integrate_forest_maps.py`로 생성되었다. 산불 발생 위치 좌표에 2023년 임상도와 2020년 수종별임상도 추출 결과를 통합한 데이터셋이다.

1. 산불 발생 위치별 임상도 추출 결과 2개를 `fire_id` 기준으로 읽는다.
   - 2023 임상도 추출 결과
   - 2020 수종별임상도 추출 결과
2. `fire_id` 전체 목록을 만들고, 2023 데이터의 순서를 우선 사용한다.
3. 임상도 값 선택 규칙을 적용한다.
   - 2023 임상도에 `임상구분코드`, `수종코드`, `경급코드`, `영급코드`, `소밀도코드` 중 하나라도 값이 있으면 2023 값을 사용한다.
   - 2023 값이 없고 2020 수종별임상도 값이 있으면 2020 값을 보완 사용한다.
   - 두 데이터 모두 임상도 값이 없으면 임상도 변수는 결측으로 둔다.
4. `fire_id`, `위도`, `경도`는 2023 행이 있으면 2023 값을, 없으면 2020 값을 사용한다.
5. 임상도 값의 출처를 `임상도_출처`에 `2023`, `2020_보완`, `결측` 중 하나로 기록한다.
6. 최종 결과를 `data/산불_공간DB/산불_공간DB_임상도_전국통합.csv`로 저장한다.


### 3. 임상도 출처별 건수

| 임상도_출처 | 행 수 | 설명 |
|---|---:|---|
| `2023` | 8,119 | 2023 임상도 값을 사용 |
| `2020_보완` | 305 | 2023 값이 없어 2020 수종별임상도 값으로 보완 |
| `결측` | 1,382 | 2023/2020 임상도 모두 매칭되지 않음 |

# 날씨 변수 데이터 누수 정리

작성일: 2026-06-11

## 문제 배경

`data/강원도_날씨데이터/강원도날씨_격자_일단위.csv`의 일별 기상값은 해당 날짜 전체 관측치를 집계한 값이다. 산불 발생 또는 예측 기준시각이 그 날짜 중간인 경우, 같은 날짜의 일별 평균/최대/최소/합계 변수에는 기준시각 이후의 관측값이 포함될 수 있다.

예를 들어 10시에 산불이 발생했는데 15시에 더 강한 바람이 불었다면, 같은 날짜의 `최대순간풍속_m_s`를 10시 산불 사례에 붙이는 것은 15시 정보를 미리 사용한 것이므로 미래 정보 누수이다. 같은 이유로 일별 `평균기온_C`, `최저기온_C`, `최고기온_C`, `강수량_mm`도 기준시각 이후 관측값을 포함할 수 있다.

FA와 EDA에서 예측용 또는 기준시각 조건 분석을 할 때는 모든 동적 기상 변수는 기준시각 이전에 이미 관측된 값만 사용한다.

## 공통 수정 원칙

- 같은 날짜 전체를 집계한 일단위 변수는 기준시각 변수로 직접 사용하지 않는다.
- 동적 기상 변수는 `data/강원도_날씨데이터/강원도날씨_격자_시간단위.csv`에서 기준시각 이전 시간창으로 재계산한다.
- 현재 시각 관측값인 `시점_*` 변수는 기준시각에 이미 관측된 값으로 간주할 수 있을 때만 사용한다.
- `D-1`, `D-2`, `D-3`처럼 기준일 이전 날짜의 전체 집계값은 기준시각보다 과거이므로 사용할 수 있다. 단, `D-0` 또는 당일 전체 집계값과 혼동하지 않는다.
- 예보 모델로 확장할 경우에는 관측값 대신 기준시각에 이용 가능한 예보값만 사용하고, 타깃 기간을 별도로 정의한다.

## FA 노트북 적용 내역

대상 노트북: `jsw/Analysis/2026-06-10_FA-재생성.ipynb`

| 기존 변수 | 문제 | 변경 후 사용 변수 | 산출 방식 |
| --- | --- | --- | --- |
| `당일_최대순간풍속_m_s` | 발생일 전체의 최대순간풍속이므로 기준시각 이후 돌풍을 포함할 수 있음 | 제거 | 시간단위 자료에 순간풍속 컬럼이 없으므로 직접 대체하지 않음. 기존의 `시점_풍속_m_s`, `직전24h_최대풍속`, `직전48h_최대풍속`으로 기준시각 이전 강풍 조건을 표현 |
| `평균기온_C` | 발생일 전체 평균기온이므로 기준시각 이후 기온을 포함함 | `시점_기온_C` | 시간단위 자료의 발생시각 `기온_C`를 이름 변경 |
| `평균기온_C` | 같은 문제 | `직전24h_평균기온_C` | 시간단위 `기온_C`를 기상셀별로 1시간 shift한 뒤 직전 24시간 rolling mean으로 계산 |

FA 입력 변수 수는 기존과 같이 24개로 유지한다. 일단위 변수 2개를 제거하고, 시간단위에서 계산한 기온 변수 2개를 추가한다.

## FA에서 유지 가능한 날씨 변수

아래 변수들은 기준시각 또는 기준시각 이전 창에서 계산되므로 누수 위험이 낮다.

| 변수군 | 사용 변수 | 비고 |
| --- | --- | --- |
| 시점 관측 | `시점_풍속_m_s`, `시점_습도_pct`, `시점_기온_C` | 발생시각의 시간단위 관측값 |
| 직전 풍속 | `직전24h_평균풍속`, `직전24h_최대풍속`, `직전48h_평균풍속`, `직전48h_최대풍속` | 현재 행을 제외하기 위해 1시간 shift 후 rolling 계산 |
| 직전 기온 | `직전24h_평균기온_C` | 현재 행을 제외하기 위해 1시간 shift 후 rolling 계산 |
| 직전 습도 | `직전24h_평균습도`, `직전24h_최소습도`, `직전48h_평균습도`, `직전48h_최소습도` | 현재 행을 제외하기 위해 1시간 shift 후 rolling 계산 |
| 전일 습도 | `D-1_평균습도_pct`, `D-1_최소습도_pct`, `D-2_최소습도_pct`, `D-3_최소습도_pct` | 시간단위 자료를 일별 집계한 뒤 기준일 이전 날짜만 매칭 |
| 강수 | `직전24h_강수량합`, `직전48h_강수량합`, `D-1_강수량합_mm` | 직전 시간창 또는 전일 합계만 사용 |

## EDA 재적용 체크리스트

EDA 코드에서도 아래 유형의 변수가 있으면 같은 방식으로 바꾼다.

| 누수 가능 변수 유형 | 사용 금지 예시 | 권장 대체 |
| --- | --- | --- |
| 당일 전체 최대값 | `당일_최대순간풍속_m_s`, 일별 `최고기온_C` | `시점_풍속_m_s`, `직전24h_최대풍속`, `직전48h_최대풍속`, `직전24h_최고기온_C` |
| 당일 전체 최소값 | 일별 `최저기온_C`, 당일 최저습도 | `직전24h_최저기온_C`, `직전24h_최소습도`, `직전48h_최소습도` |
| 당일 전체 평균값 | 일별 `평균기온_C`, 당일 평균습도 | `시점_기온_C`, `직전24h_평균기온_C`, `직전24h_평균습도`, `직전48h_평균습도` |
| 당일 전체 합계값 | 일별 `강수량_mm`, 발생일 강수량 | `직전24h_강수량합`, `직전48h_강수량합`, `D-1_강수량합_mm` |

EDA 산출물이나 설명문에서 기존 일단위 변수를 인용한 경우, 변수명과 해석도 함께 수정해야 한다. 특히 `당일`, `발생일`, `일별`이라는 표현이 들어간 동적 기상 변수는 누수 여부를 우선 점검한다.

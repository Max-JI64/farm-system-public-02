# 캐나다 산불지수 모델 성능 종합 분석

## 1. 분석 목적

이 문서는 다음 두 분석 결과를 함께 검토하고, 현재 모델이 실제 산불 예측에 사용할 수 있는지 평가한 보고서다.

1. 강원도 선행연구의 `Indexed_FFMC` 단변량 로지스틱 모델 재현
2. 캐나다 FWI 시스템의 `FFMC`, `DMC`, `DC`, `ISI`, `BUI`, `FWI` 위험지수 평가

추가로 다음 사항을 검토했다.

- 산불 발생과 비발생을 현재처럼 약 1:10으로 구성한 영향
- 비발생 표본 비율을 낮출 때 각 성능지표가 어떻게 변하는지
- 랜덤 Train/Test 분할 결과가 미래 시점에도 유지되는지
- FWI와 FFMC만으로 산불 발생 여부를 예측할 수 있는지

## 2. 데이터와 평가 조건

### 2.1 데이터 구성

- 입력 데이터: `data/학습데이터/학습데이터_최종_캐나다지수.csv`
- 전체 표본: 17,045건
- 산불 발생 `Target 1`: 1,553건
- 비발생 `Target 0`: 15,492건
- 산불 발생 비율: 약 9.11%

비발생 표본은 다음 세 종류로 구성된다.

| 샘플유형 | 건수 | Target 1 대비 배수 | 의미 |
|---|---:|---:|---|
| `Target_0A` | 7,738 | 약 5배 | 실제 산불 위치에서 월과 시간대를 맞춘 비발생 시점 |
| `Target_0B1` | 4,652 | 약 3배 | 산불의 기후·시간 분포를 반영한 공간 대조군 |
| `Target_0B2` | 3,102 | 약 2배 | 시간대를 균등 무작위로 부여한 전역 공간 대조군 |

따라서 전체 데이터는 의도적으로 `Target 1 : Target 0 = 1:10`에 가깝게 만들어진 사례-대조군 데이터다. 이 9.11%는 강원도 전체 시공간에서 산불이 발생할 실제 확률을 의미하지 않는다.

### 2.2 기존 평가 방식

두 분석은 모두 다음 방식으로 평가되었다.

- `Target` 비율을 유지한 랜덤 70:30 Train/Test 분할
- `random_state=42`
- Train 11,931건
- Test 5,114건
- Test 산불 발생 비율 9.1122%

FFMC 재현 모델은 확률 임계값 0.5를 사용했다. FWI 지수 평가는 Train에서 Youden J가 최대가 되는 임계값을 찾고 Test에 적용했다.

## 3. FFMC 선행연구 재현 모델

### 3.1 모델 구조

모든 모델은 `FFMC_10일평균`을 네 단계로 구분한 `Indexed_FFMC` 변수 하나만 사용한다.

| 모델 | 방법 |
|---|---|
| 논문식 FFMC | `sigmoid(-0.529 + 0.422 × Indexed_FFMC)` |
| 재학습 FFMC | L2 로지스틱 회귀, `class_weight="balanced"` |
| L1 LogisticCV | L1 규제 강도를 교차검증으로 선택 |
| L2 LogisticCV | L2 규제 강도를 교차검증으로 선택 |

### 3.2 기존 랜덤 분할 성능

| 모델 | AUROC | AUPRC | Accuracy | Balanced Accuracy | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 논문식 FFMC | 0.5543 | 0.1019 | 0.1828 | 0.5437 | 0.0991 | 0.9850 | 0.1801 |
| 재학습 FFMC | 0.5543 | 0.1019 | 0.5301 | 0.5388 | 0.1045 | 0.5494 | 0.1756 |
| L1 LogisticCV | 0.5543 | 0.1019 | 0.3322 | 0.5332 | 0.0988 | 0.7790 | 0.1753 |
| L2 LogisticCV | 0.5543 | 0.1019 | 0.5301 | 0.5388 | 0.1045 | 0.5494 | 0.1756 |

### 3.3 해석

`Indexed_FFMC`가 높을수록 산불 발생 가능성이 증가한다는 방향은 선행연구와 동일하게 나타났다. 그러나 판별력은 매우 약하다.

- AUROC 0.554는 무작위 분류의 0.5보다 조금 높은 수준이다.
- AUPRC 0.102는 Test 발생률 0.091과 차이가 작다.
- 논문식은 산불의 98.5%를 탐지하지만 비발생 4,648건 중 4,172건을 산불로 잘못 경보한다.
- 입력 변수가 하나이고 모든 모델이 그 변수의 단조 변환이므로 규제를 조정해도 AUROC와 AUPRC가 개선되지 않는다.
- 4단계 지수화 과정에서 연속형 FFMC 정보가 크게 축약된다.

따라서 FFMC 선행연구 재현 모델은 최종 예측 모델이 아니라 비교 기준선으로 사용하는 것이 적절하다.

## 4. FFMC 확률 보정 문제

재학습 모델은 클래스 불균형을 보완하기 위해 `class_weight="balanced"`를 사용했다. 이 설정은 분류 경계를 조정하는 데는 사용할 수 있지만, 모델 출력값을 실제 산불 발생확률로 해석하기 어렵게 만든다.

추가 검증 결과는 다음과 같다.

| 항목 | 결과 |
|---|---:|
| Test 실제 발생률 | 0.0911 |
| Balanced 모델 평균 예측확률 | 0.4945 |
| Balanced 모델 Brier Score | 0.2467 |
| 항상 9.11%를 예측하는 기준선 Brier Score | 0.0828 |
| 가중치 없는 로지스틱 Brier Score | 0.0825 |

Balanced 모델의 평균 예측확률은 약 49.4%로 실제 Test 발생률 9.1%와 크게 다르다. Brier Score도 단순 기준선보다 훨씬 나쁘다.

따라서 다음과 같이 해석해야 한다.

- 현재 FFMC 모델의 출력값은 실제 산불 발생확률이 아니다.
- 0.5는 실제 위험 50%를 뜻하는 임계값이 아니다.
- README에서 가장 낮은 Brier Score를 가진 모델을 “확률 보정이 가장 양호하다”고 표현하더라도, 이는 비교한 FFMC 모델들 사이의 상대 평가일 뿐이다.
- 실제 확률이 필요하다면 현실적인 발생률을 반영한 검증데이터에서 별도 확률 보정이 필요하다.

## 5. FWI 계열 지수 결과

### 5.1 Target별 차이

모든 FWI 계열 지수에서 산불 발생 표본의 평균이 비발생 표본보다 높았다.

| 지수 | Target 0 평균 | Target 1 평균 | 평균비 |
|---|---:|---:|---:|
| FFMC | 75.6253 | 82.6494 | 1.0929 |
| DMC | 19.2927 | 28.8690 | 1.4964 |
| DC | 86.2663 | 143.3724 | 1.6620 |
| ISI | 3.5016 | 4.7988 | 1.3705 |
| BUI | 23.1858 | 35.9558 | 1.5508 |
| FWI | 6.1669 | 10.0692 | 1.6328 |

FWI 계열 지수가 산불에 유리한 건조·강풍 조건을 포착하고 있다는 방향성은 확인된다.

### 5.2 기존 랜덤 분할 성능

| 지수 | AUROC | AUPRC | AUPRC / 기준 발생률 |
|---|---:|---:|---:|
| FFMC | 0.6164 | 0.1385 | 1.5200 |
| DMC | 0.6415 | 0.1341 | 1.4717 |
| DC | 0.6713 | 0.1419 | 1.5570 |
| ISI | 0.6307 | 0.1402 | 1.5382 |
| BUI | 0.6558 | 0.1374 | 1.5084 |
| FWI | 0.6507 | 0.1500 | 1.6465 |

- AUROC는 DC가 0.6713으로 가장 높았다.
- AUPRC는 FWI가 0.1500으로 가장 높았다.
- 상위 10% ISI 구간의 산불 비율은 약 18.2%로 전체 9.1%의 약 2배였다.

따라서 FWI 계열은 위험한 시기와 위치를 정렬하는 데는 유용하다. 그러나 최고 성능도 강한 분류 모델 수준은 아니다.

### 5.3 임계값 기반 결과

대표적으로 BUI 임계값 결과는 다음과 같다.

| 지표 | 값 |
|---|---:|
| Precision | 0.1380 |
| Recall | 0.6931 |
| F1 | 0.2301 |
| Balanced Accuracy | 0.6295 |
| TP | 323 |
| FP | 2,018 |

산불 323건을 탐지하는 동안 비발생 2,018건을 산불로 잘못 경보했다. 양성 경보 중 실제 산불은 약 13.8%이며, 나머지 약 86.2%는 오경보다.

이 결과는 FWI를 단독 산불 발생 판정기로 사용하기 어렵다는 것을 의미한다.

## 6. 랜덤 분할과 미래 예측 성능

### 6.1 랜덤 분할의 한계

현재 랜덤 분할에서는 다음 중복이 확인되었다.

- Test에 포함된 90개 기상셀 모두 Train에도 포함
- Test의 `기상셀ID × 연도` 그룹 179개 모두 Train에도 포함
- Test `기상셀ID × 날짜` 조합의 약 37.4%가 Train에도 포함

FWI 지수 자체는 학습되는 변수가 아니므로 이것을 직접적인 Target 누수라고 단정할 수는 없다. 그러나 Train과 Test가 유사한 공간과 기상일을 공유하기 때문에 완전히 독립적인 미래 예측 평가보다 쉬운 조건이다.

### 6.2 2020년 기준, 2021년 평가

2020년 데이터에서 임계값을 정하고 2021년 데이터에 적용한 추가 검증 결과다.

| 지수 | 기존 랜덤 분할 AUROC | 2021년 홀드아웃 AUROC | 2021년 AUPRC |
|---|---:|---:|---:|
| FFMC | 0.6164 | 0.5627 | 0.1679 |
| DMC | 0.6415 | 0.5591 | 0.1557 |
| DC | 0.6713 | 0.5907 | 0.1617 |
| ISI | 0.6307 | 0.5826 | 0.1697 |
| BUI | 0.6558 | 0.5687 | 0.1586 |
| FWI | 0.6507 | 0.5809 | 0.1895 |

2021년의 발생률은 약 12.59%로 랜덤 Test의 9.11%보다 높기 때문에 AUPRC 절대값은 직접 비교할 때 주의해야 한다. 반면 AUROC는 모든 지수에서 낮아졌다.

특히 `Indexed_FFMC` 로지스틱 모델은 다음과 같았다.

- 기존 랜덤 분할 AUROC: 0.5543
- 2020년 학습, 2021년 평가 AUROC: 0.4671

2021년에는 점수 순위가 무작위보다도 낮게 나타났다. 이는 FFMC 4단계 모델이 연도 간 기상 및 발생 분포 변화에 매우 취약하다는 증거다.

| DMC | 0.6303 | 0.1365 | 0.6039 |

공간·날짜 그룹 분할에서는 기존 랜덤 분할보다 소폭 낮아졌지만 위험 신호가 유지되었다. 반면 연도 홀드아웃에서는 감소 폭이 더 컸다.

현재 결과에서 가장 큰 일반화 위험은 새로운 기상셀보다 새로운 연도와 계절 분포 변화다.

## 7. 대조군 유형별 성능

모든 산불 표본과 한 종류의 비발생 표본만 비교한 결과다. AUPRC는 각 비교 데이터의 발생률이 다르므로 AUROC를 중심으로 비교해야 한다.

| 대조군 | 발생률 | FFMC AUROC | DC AUROC | FWI AUROC |
|---|---:|---:|---:|---:|
| `Target_0A` | 16.7% | 0.615 | 0.683 | 0.645 |
| `Target_0B1` | 25.0% | 0.609 | 0.667 | 0.637 |
| `Target_0B2` | 33.4% | 0.654 | 0.624 | 0.667 |

해석은 다음과 같다.

- DC는 실제 산불 위치에서 월·시간대를 맞춘 `Target_0A`와 산불 분포를 반영한 `Target_0B1` 구분에서 상대적으로 강했다.
- FFMC와 FWI는 균등 무작위 시간 대조군인 `Target_0B2`를 더 쉽게 구분했다.
- 네거티브 비율뿐 아니라 어떤 네거티브를 줄이는지도 성능에 영향을 준다.
- 쉬운 `Target_0B2`를 많이 남기고 어려운 `Target_0A`를 줄이면 모델이 실제보다 좋아 보일 수 있다.

## 8. 1:10 비율을 낮출 때의 의미

### 8.1 “일부 지표는 원칙적으로 크게 변하지 않는다”의 조건

이 표현은 다음 조건을 전제로 한다.

> 이미 학습된 같은 모델과 같은 임계값을 유지하고, 각 네거티브 유형의 대표성을 보존하면서 비발생 평가 표본만 무작위로 줄이는 경우

이 조건에서는 다음 지표가 비교적 안정적이다.

- Recall 또는 Sensitivity
- Specificity
- Balanced Accuracy
- AUROC

Recall은 전체 산불 중 탐지한 산불의 비율이고, Specificity는 전체 비발생 중 정확히 비발생으로 판정한 비율이다. 각 클래스 내부의 비율이므로 대표성 있는 무작위 축소라면 기대값이 크게 바뀌지 않는다.

Balanced Accuracy는 다음 식으로 계산되므로 두 값이 유지되면 함께 유지된다.

```text
Balanced Accuracy = (Recall + Specificity) / 2
```

AUROC는 임의의 산불 표본이 임의의 비발생 표본보다 높은 점수를 받을 확률로 해석할 수 있다. 비발생 표본 수만 대표성 있게 줄이면 이 순위 관계의 기대값은 유지된다.

### 8.2 비율에 크게 영향을 받는 지표

다음 지표는 데이터의 산불 발생 비율에 직접 영향을 받는다.

- Precision
- F1
- AUPRC
- Accuracy
- 예측확률과 확률 보정

Precision은 다음 식으로 계산된다.

```text
Precision = TP / (TP + FP)
```

같은 모델이라도 비발생 표본을 줄이면 FP의 절대 개수가 줄어들기 때문에 Precision이 높아진다. 이것은 반드시 모델의 구분 능력이 향상되었다는 뜻은 아니다.

### 8.3 비율별 예상 성능

기존 Test에서 측정한 Sensitivity와 Specificity가 그대로 유지된다고 가정한 계산이다.

#### FFMC 재학습 모델

| 산불:비발생 | Precision | F1 | Accuracy |
|---|---:|---:|---:|
| 1:10 | 0.104 | 0.175 | 0.530 |
| 1:5 | 0.189 | 0.281 | 0.532 |
| 1:3 | 0.280 | 0.371 | 0.534 |
| 1:1 | 0.538 | 0.544 | 0.539 |

#### BUI 임계값

| 산불:비발생 | Precision | F1 | Accuracy |
|---|---:|---:|---:|
| 1:10 | 0.138 | 0.230 | 0.577 |
| 1:5 | 0.242 | 0.359 | 0.587 |
| 1:3 | 0.347 | 0.463 | 0.598 |
| 1:1 | 0.615 | 0.652 | 0.629 |

#### DC 임계값

| 산불:비발생 | Precision | F1 | Accuracy |
|---|---:|---:|---:|
| 1:10 | 0.157 | 0.241 | 0.707 |
| 1:5 | 0.272 | 0.355 | 0.691 |
| 1:3 | 0.384 | 0.438 | 0.673 |
| 1:1 | 0.651 | 0.573 | 0.619 |

네거티브를 줄이면 Precision과 F1은 높아진다. 그러나 DC처럼 Accuracy가 낮아질 수도 있다. Accuracy는 다수 클래스의 비율과 어느 클래스를 더 잘 맞히는지에 크게 좌우되기 때문이다.

### 8.4 “원칙적으로”가 적용되지 않는 경우

다음 경우에는 AUROC, Recall, Specificity, Balanced Accuracy도 달라질 수 있다.

1. 비발생 비율을 변경한 뒤 모델을 다시 학습하는 경우
2. `Target_0A`, `Target_0B1`, `Target_0B2` 구성 비율이 달라지는 경우
3. 특정 월, 지역 또는 쉬운 네거티브만 선택적으로 제거하는 경우
4. 평가 임계값을 다시 최적화하는 경우
5. 표본 수가 너무 작아져 통계적 변동이 커지는 경우
6. 클래스 가중치나 샘플 가중치를 변경하는 경우

따라서 “비발생 비율을 낮춰도 성능이 유지된다”고 일반화해서는 안 된다. 정확한 표현은 다음과 같다.

> 동일한 모델과 임계값을 유지하고 대표성 있게 비발생 평가 표본만 줄이면 AUROC, Recall, Specificity, Balanced Accuracy의 기대값은 비교적 안정적이다. 모델을 재학습하거나 네거티브 구성이 바뀌면 이 지표들도 달라질 수 있다.

## 9. 실제 운영 발생률에서의 문제

현재 데이터의 9.11% 발생률은 샘플링으로 만든 값이다. 실제 운영에서는 수많은 위치와 시간 중 산불이 발생하는 비율이 훨씬 낮을 가능성이 크다.

기존 Sensitivity와 Specificity가 유지된다고 가정했을 때 예상 Precision은 다음과 같다.

| 모델 또는 지수 | 발생률 9.11% | 발생률 2.3% | 발생률 1% | 발생률 0.1% |
|---|---:|---:|---:|---:|
| FFMC 재학습 | 10.45% | 2.67% | 1.16% | 0.12% |
| BUI | 13.80% | 3.62% | 1.59% | 0.16% |
| DC | 15.77% | 4.21% | 1.85% | 0.19% |

예를 들어 실제 발생률이 1%라면 DC 경보 100건 중 실제 산불은 약 2건에 불과할 수 있다. 이 계산은 현재 표본에서 측정한 성능이 운영 환경에서도 유지된다는 낙관적 가정을 사용한 결과다.

따라서 운영 모델을 평가하기 전에 예측 단위를 명확히 정의해야 한다.

- 강원도 전체의 일별 산불 발생 여부
- 기상셀별 일별 발생 여부
- 기상셀별 시간 단위 발생 여부
- 개별 공간점별 발생 여부

예측 단위가 세밀해질수록 실제 발생률은 낮아지고, 같은 모델의 Precision도 낮아진다.

## 10. 두 접근만으로 산불을 예측할 수 있는가

### 10.1 FFMC 단변량 모델

단독 예측 모델로 사용할 수 없다.

- 연속형 기상 정보를 4단계로 축약한다.
- AUROC와 AUPRC가 기준선에 가깝다.
- 연도 홀드아웃에서 AUROC가 0.467까지 하락했다.
- 산불의 발화 원인이 되는 인위적·공간적 요인을 포함하지 않는다.
- Balanced 학습 확률은 실제 발생확률로 해석할 수 없다.

### 10.2 FWI 계열 지수

단독 확정 예측 모델보다는 기상 위험 우선순위 지표로 사용할 수 있다.

- 산불 발생 표본에서 모든 지수가 높아지는 방향성이 확인된다.
- 고위험 분위에서 발생률이 상승한다.
- DC, BUI, FWI는 FFMC 단변량보다 높은 판별력을 가진다.
- 그러나 Precision과 AUPRC가 낮고 미래 연도 성능이 감소한다.

FWI는 기온, 습도, 풍속, 강수량을 이용해 연료 건조도와 확산 가능성을 나타낸다. FWI가 높다는 것은 불이 나기 쉬운 기상·연료 조건이라는 의미이지, 실제 점화원이 발생한다는 의미가 아니다.

산불 발생에는 다음 요인이 함께 작용한다.

- 도로, 임도, 등산로 및 생활권 접근성
- 농업·소각·입산 등 인위적 점화 가능성
- 산림과 토지피복
- 지형과 경사
- 계절 및 지역별 발생 특성
- 장·단기 기상 상태

따라서 FWI만으로 실제 발생 여부를 결정하는 것은 구조적으로 한계가 있다.

## 11. FWI 구현상 추가 검토 사항

현재 FWI 구현은 다음 조건을 사용한다.

- 각 기상셀 첫 날짜 초기값: `FFMC=85`, `DMC=6`, `DC=15`
- 정오 기상값을 일 대표값으로 사용
- 2020년 1월 1일부터 2021년 12월 31일까지 연속 계산
- DC overwintering 공식 미적용

DC overwintering을 적용하지 않은 것은 겨울의 수분 상태가 다음 산불철 DC 초기값에 전달되는 방식에 영향을 줄 수 있다. 특히 봄철 산불 위험을 평가할 때 결과 민감도를 확인할 필요가 있다.

또한 운영 목적에 따라 다음 사항을 검토해야 한다.

- 한국 표준시 정오가 표준 FWI 관측시각과 목적상 적절한지
- 적설·결빙 기간에 FWI 계산을 계속하는 것이 적절한지
- 산불철 시작 시 DMC와 DC를 재초기화할지
- 강원도 기후에 맞는 overwintering 또는 계절 초기화가 필요한지

## 12. 권장 모델링 방향

### 12.1 현재 두 분석의 역할

| 분석 | 권장 역할 |
|---|---|
| FFMC 선행연구 재현 | 문헌 재현 및 최소 기준선 |
| FWI 계열 지수 | 기상 기반 위험 신호 및 모델 입력 변수 |
| 최종 예측 모델 | FA·공간·인위·기상·FWI를 결합한 별도 모델 |

### 12.2 권장 평가 설계

1. 학습에서는 현재 확보한 15,492개 네거티브를 모두 유지한다.
2. 네거티브를 줄여야 한다면 `0A:0B1:0B2 = 5:3:2` 구성을 유지한 반복 층화 추출을 사용한다.
3. 랜덤 분할 결과는 보조 결과로만 사용한다.
4. 최소한 `2020 → 2021` 같은 시간 순서 홀드아웃을 주 평가로 사용한다.
5. 같은 `기상셀ID × 날짜`와 같은 원본 산불에서 파생된 표본이 Train/Test에 나뉘지 않도록 그룹 분할한다.
6. 여러 랜덤 시드 또는 반복 그룹 분할로 평균과 표준편차를 보고한다.
7. AUROC뿐 아니라 AUPRC, Recall, Specificity, Precision, 경보 수를 함께 보고한다.
8. 실제 운영 발생률을 반영한 별도 검증세트를 만든다.

### 12.3 권장 변수와 모델 비교

다음 모델을 같은 분할에서 비교하는 것이 적절하다.

1. `Indexed_FFMC` 기준선
2. 연속형 `FFMC`
3. `DMC`, `DC`, `ISI`, `BUI`, `FWI`
4. FA 요인점수만 사용하는 모델
5. 공간·지형·접근성 변수 모델
6. `FA + FWI`
7. `FA + FWI + 공간·접근성 + 계절·지역`

모델 선택은 로지스틱 회귀 기준선과 비선형 모델을 함께 비교하되, 모델 복잡도보다 시간 홀드아웃 일반화 성능을 우선해야 한다.

### 12.4 발생과 확산 위험 분리

두 문제를 분리하는 것이 타당하다.

1. **산불 발생 가능성 모델**
   - 기상, 접근성, 토지피복, 지형, 계절, 인위적 점화 요인을 결합
2. **발생 후 확산·강도 위험 모델**
   - FWI, ISI, BUI, 풍속, 연료 및 지형을 중심으로 구성

FWI는 두 번째 문제와 더 직접적으로 연결되며, 첫 번째 문제에서는 중요한 입력 변수 중 하나로 사용하는 편이 적절하다.

## 13. 최종 결론

1. 강원도 선행연구 FFMC 단변량 모델은 위험 방향성은 재현하지만 판별력이 약하다.
2. FWI 계열 지수는 FFMC 단변량보다 유용하며, 위험 순위화 신호가 확인된다.
3. 현재 최고 AUROC 약 0.67과 낮은 Precision은 단독 운영 예측에 충분하지 않다.
4. 랜덤 분할보다 연도 홀드아웃 성능이 낮아 미래 일반화 위험이 확인된다.
5. 비발생 표본을 줄이면 Precision, F1, AUPRC가 좋아 보일 수 있지만 모델 자체가 개선된 것은 아닐 수 있다.
6. 같은 모델과 임계값에서 네거티브를 대표성 있게 줄이는 경우에만 Recall, Specificity, Balanced Accuracy, AUROC가 비교적 안정적이라고 말할 수 있다.
7. 실제 발생률이 현재 사례-대조군 데이터보다 낮으면 운영 Precision은 크게 하락한다.
8. FFMC는 기준선, FWI는 기상 위험 보조지표로 두고 FA·공간·인위 요인과 결합한 최종 모델을 개발하는 것이 타당하다.

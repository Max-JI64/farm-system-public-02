# Van Wagner(1987) 캐나다 산불기상지수(FWI) 원문 정리

## 1. 논문 개요

- **문헌**: Van Wagner, C.E. (1987). *Development and Structure of the Canadian Forest Fire Weather Index System*. Forestry Technical Report 35. Canadian Forestry Service, Ottawa.
- **주제**: 캐나다 산불기상지수 시스템(FWI, Fire Weather Index System)의 개발 배경과 계산 구조
- **성격**: 산불 발생확률을 직접 예측하는 통계모형 논문이 아니라, 기상 조건으로부터 산불 위험도를 나타내는 일련의 지수들을 계산하는 **화재기상지수 산출 체계 설명서**
- **입력 자료**: 일 단위 기온, 상대습도, 풍속, 강수량
- **핵심 산출물**: `FFMC`, `DMC`, `DC`, `ISI`, `BUI`, `FWI`

이 문헌은 캐나다 산불위험평가시스템(CFFDRS, Canadian Forest Fire Danger Rating System)의 핵심 구성요소인 **FWI 시스템**을 설명한다. FWI 시스템은 특정 지역에서 산불이 실제로 발생했는지 여부를 맞히는 모델이라기보다, 매일의 기상 조건이 산림 연료의 건조 상태와 화재 확산 가능성을 얼마나 높이는지를 지수화하는 체계이다.

## 2. 이 논문이 다루는 핵심 질문

Van Wagner(1987)의 핵심 질문은 다음과 같이 정리할 수 있다.

첫째, 매일 관측되는 기상자료만으로 산림 연료의 건조 상태를 어떻게 수치화할 수 있는가.

둘째, 표면의 가는 연료, 중간 깊이의 부식층, 깊은 유기물층처럼 서로 반응 속도가 다른 연료층의 수분 상태를 어떻게 별도 지수로 표현할 수 있는가.

셋째, 연료의 건조 상태와 풍속을 결합해 초기 화재 확산 가능성과 최종 화재강도 위험을 어떻게 계산할 수 있는가.

즉, 이 논문은 “산불이 난다/안 난다”를 직접 예측하는 확률모형이 아니라, **기상 조건 → 연료 수분 상태 → 확산 가능성 → 최종 화재기상위험도**로 이어지는 지수 계산 체계를 제시한 문헌이다.

## 3. FWI 시스템의 전체 구조

FWI 시스템은 크게 6개 지수로 구성된다.

```text
기상자료
├─ FFMC: 미세연료수분지수
│   └─ ISI: 초기확산지수
├─ DMC: 부식층수분지수
├─ DC: 가뭄지수
│
DMC + DC → BUI: 누적연료건조도
ISI + BUI → FWI: 최종 화재기상지수
```

각 지수의 의미는 다음과 같다.

| 지수 | 이름 | 의미 |
|---|---|---|
| `FFMC` | Fine Fuel Moisture Code | 지표면의 미세연료가 얼마나 건조한지 나타내는 지수 |
| `DMC` | Duff Moisture Code | 중간 깊이 부식층의 누적 건조 상태를 나타내는 지수 |
| `DC` | Drought Code | 깊은 유기물층과 장기 가뭄 상태를 나타내는 지수 |
| `ISI` | Initial Spread Index | FFMC와 풍속을 결합한 초기 확산 가능성 지수 |
| `BUI` | Build Up Index | DMC와 DC를 결합한 누적 연료 건조도 지수 |
| `FWI` | Fire Weather Index | ISI와 BUI를 결합한 최종 화재기상위험 지수 |

이 구조에서 `FFMC`, `DMC`, `DC`는 연료 수분 상태를 나타내는 기본 지수이고, `ISI`, `BUI`, `FWI`는 이 기본 지수들을 조합해 화재 확산과 강도 측면의 위험도를 나타내는 파생 지수이다.

## 4. 입력 기상자료

FWI 시스템은 일 단위 기상자료를 입력으로 사용한다. 표준 계산에서는 보통 정오 관측값을 기준으로 하며, 주요 입력 변수는 다음 네 가지다.

| 입력 변수 | 의미 |
|---|---|
| 기온 | 연료의 건조·증발 조건을 반영 |
| 상대습도 | 공기 중 수분 상태와 연료의 건조 가능성을 반영 |
| 풍속 | 미세연료 건조와 화재 확산 가능성을 반영 |
| 강수량 | 연료 수분 증가와 건조 지수 감소를 반영 |

중요한 점은 이 시스템이 산림 내 연료 수분량을 매일 직접 실측해야만 작동하는 방식이 아니라는 것이다. 전날의 지수 상태를 내부 수분량으로 변환한 뒤, 당일 기상 조건을 반영해 지수를 갱신하는 **재귀적 계산 구조**를 사용한다.

## 5. 세 가지 연료수분 지수

### 5.1 FFMC

`FFMC`는 지표면의 낙엽, 잔가지, 마른 풀처럼 불이 붙기 쉬운 미세연료의 수분 상태를 나타낸다. 값이 높을수록 미세연료가 건조하고 발화 가능성이 높다고 해석한다.

FFMC는 기온, 상대습도, 풍속, 강수량, 전일 FFMC를 이용해 계산된다. 강수량이 일정 기준을 넘으면 먼저 강수에 의한 수분 증가를 반영하고, 이후 당일의 건조 또는 습윤 조건에 따라 미세연료 수분량을 갱신한다. 마지막으로 갱신된 수분량을 다시 FFMC 값으로 변환한다.

### 5.2 DMC

`DMC`는 지표 아래의 중간 깊이 부식층이 얼마나 건조한지를 나타낸다. FFMC보다 더 느리게 반응하며, 며칠에서 수 주 단위의 건조 누적 상태를 반영한다.

DMC는 기온, 상대습도, 강수량, 월별 보정 계수, 전일 DMC를 이용한다. 강수량이 일정 기준 이상이면 부식층 수분 증가를 반영하고, 이후 당일 기상 조건에 따른 건조량을 더해 갱신한다.

### 5.3 DC

`DC`는 깊은 유기물층과 장기적인 가뭄 상태를 나타내는 지수이다. 세 수분 지수 중 가장 느리게 변하며, 장기간의 건조 누적과 큰 산불 가능성을 평가하는 데 중요하다.

DC는 기온, 강수량, 월별 보정 계수, 전일 DC를 이용한다. 강수 기준값이 FFMC나 DMC보다 크며, 상대적으로 장기적인 물 부족 상태를 반영한다. 원문에는 겨울철 이후 다음 시즌의 DC를 보정하는 overwintering 절차도 포함되어 있다.

## 6. 확산 및 화재강도 지수

### 6.1 ISI

`ISI`는 초기확산지수이다. 이는 FFMC와 풍속을 결합해 산불이 시작되었을 때 얼마나 빠르게 번질 수 있는지를 나타낸다.

FFMC가 높으면 미세연료가 건조하다는 뜻이고, 풍속이 높으면 화염 확산이 빨라질 수 있다. 따라서 ISI는 산불의 초기 확산 위험을 표현하는 데 중요한 지수다.

### 6.2 BUI

`BUI`는 누적연료건조도 지수이다. DMC와 DC를 결합해 연료층 전체의 건조도와 산불에 사용 가능한 연료량을 나타낸다.

DMC가 비교적 표층 아래 부식층의 건조 상태를, DC가 깊은 층의 장기 가뭄 상태를 반영하므로, BUI는 단기·중기·장기 건조 상태가 결합된 누적 위험도로 볼 수 있다.

### 6.3 FWI

`FWI`는 최종 화재기상지수이다. ISI와 BUI를 결합하여 산불의 확산 가능성과 연료 건조도를 함께 반영한다.

FWI 값은 0~1 확률이 아니다. 값이 높을수록 화재 기상위험이 크다는 의미의 지수 점수이며, 이를 그대로 산불 발생확률로 해석하면 안 된다. 발생확률 모델을 만들려면 FWI 계열 지수들을 설명변수로 사용해 별도의 통계·머신러닝 모델을 학습해야 한다.

## 7. 이 논문에서 중요한 해석

Van Wagner(1987)의 가장 중요한 의의는 산불 위험을 하나의 단순 기상 변수로 보지 않고, 연료층의 수분 반응 속도와 화재 확산 과정을 단계적으로 분해했다는 점이다.

정리하면 다음과 같다.

- `FFMC`는 오늘 불이 붙기 쉬운 표면 미세연료 상태를 반영한다.
- `DMC`는 며칠~수 주 단위의 부식층 건조 누적을 반영한다.
- `DC`는 장기 가뭄과 깊은 유기물층의 건조 상태를 반영한다.
- `ISI`는 미세연료 건조도와 풍속을 결합해 초기 확산 가능성을 나타낸다.
- `BUI`는 누적 연료 건조도와 가용 연료량을 나타낸다.
- `FWI`는 ISI와 BUI를 결합한 최종 화재기상위험 지수이다.

따라서 이 논문의 FWI 시스템은 산불 예측모형 그 자체라기보다, 산불 예측모형에 투입할 수 있는 **이론 기반 기상·연료 위험 지표 세트**로 이해하는 것이 적절하다.

## 8. 강원도 분석에서의 활용 방향

현재 프로젝트에서는 Van Wagner(1987)의 FWI 시스템을 강원도 기상 데이터에 적용하여 `FFMC`, `DMC`, `DC`, `ISI`, `BUI`, `FWI`를 산출했다.

이때 중요한 구분은 다음과 같다.

- 강원도 선행연구 재현 트랙은 `FFMC`만 사용해 로지스틱 산불발생확률을 계산한다.
- Van Wagner(1987) 기반 FWI 트랙은 `FFMC`, `DMC`, `DC`, `ISI`, `BUI`, `FWI` 전체 지수를 계산한다.
- FWI 트랙 자체는 `FWI_발생확률` 같은 확률값을 만들지 않는다.
- 산출된 FWI 계열 지수는 이후 FA 요인점수, 기상 파생변수, 공간 변수 등과 함께 모델 입력 후보로 사용한다.

즉, 이 문헌을 이용한 현재 분석의 목적은 “캐나다 FWI 시스템으로 산불확률식을 그대로 가져오는 것”이 아니라, **캐나다 표준 산불기상지수를 강원도 데이터에 계산한 뒤, 현재 프로젝트의 산불 예측모델과 비교 가능한 외부 이론 기반 지표로 활용하는 것**이다.

## 9. 핵심 요약

Van Wagner(1987)은 캐나다 FWI 시스템의 구조와 계산 방법을 제시한 문헌이다. 이 시스템은 기온, 습도, 풍속, 강수량으로부터 `FFMC`, `DMC`, `DC`를 계산하고, 이를 다시 `ISI`, `BUI`, `FWI`로 결합한다.

이 논문에서 제시된 FWI는 산불 발생확률이 아니라 **화재기상위험 점수**이다. 따라서 현재 강원도 분석에서는 이 지수들을 직접 확률처럼 해석하지 않고, 산불 예측모델의 설명변수 또는 성능 비교용 기준 지표로 사용한다.

## 10. FWI 지수를 이용한 현재 데이터 분석

Van Wagner(1987)의 FWI 시스템을 현재 강원도 학습데이터에 적용한 뒤, 산출된 `FFMC`, `DMC`, `DC`, `ISI`, `BUI`, `FWI`가 실제 산불 발생 샘플을 얼마나 잘 구분하는지 평가했다.

다만 이 단계에서는 로지스틱 회귀나 머신러닝 모델을 새로 학습하지 않았다. `FWI_발생확률` 같은 확률 컬럼도 만들지 않았다. 각 지수를 그대로 **산불위험 점수**로 보고, 점수가 높을수록 산불 위험이 높다고 가정했을 때의 분리 성능을 평가했다.

평균비 기준으로는 `DC`가 가장 크게 벌어졌다. Target 1의 `DC` 평균은 Target 0의 약 **1.66배**였고, `FWI`도 약 **1.63배**로 높았다. 이는 산불 발생 샘플에서 장기 건조 상태와 최종 화재기상위험이 더 높게 나타났다는 의미다.

## 11. FWI 지수 분석의 최종 결과

현재 강원도 데이터에서 FWI 계열 지수는 산불 발생 샘플에서 일관되게 더 높은 값을 보였다. 즉, Van Wagner(1987)의 FWI 시스템이 의도한 “건조하고 확산 위험이 큰 기상 조건일수록 산불 위험이 높다”는 방향성은 현재 데이터에서도 확인되었다.

핵심 결과는 다음과 같다.

| 관점 | 최고 지수 | 값 |
|---|---|---:|
| AUROC | `DC` | 0.671343 |
| AUPRC | `FWI` | 0.150029 |
| Balanced Accuracy | `BUI` | 0.629484 |
| 상위 10% Lift | `ISI` | 2.000815 |

해석하면 다음과 같다.

- `DC`는 산불/비산불을 순위로 구분하는 능력이 가장 좋았다.
- `FWI`는 희소한 산불 발생 샘플을 Precision-Recall 관점에서 가장 잘 끌어올렸다.
- `BUI`는 임계값 기반 이진 분류에서 균형 정확도가 가장 높았다.
- `ISI`는 상위 10% 위험구간에서 Target 1 비율을 가장 크게 높였다.

하지만 전체적으로 Precision과 AUPRC가 낮기 때문에, FWI 지수만으로 산불 발생 여부를 단독 예측하기에는 한계가 크다. FWI 계열 지수는 산불 위험을 정렬하고 고위험 기상 조건을 선별하는 보조 지표로는 유용하지만, 최종 예측모형으로 쓰려면 공간·지형·인위 요인, FA 요인점수, 다른 기상 파생변수와 결합한 별도 모델이 필요하다.

따라서 이 분석의 결론은 다음과 같다.

**캐나다 FWI 지수는 현재 강원도 데이터에서도 산불 위험 방향성은 뚜렷하게 보여주지만, 단독 예측 모델이라기보다 최종 산불 예측모형에 결합할 이론 기반 위험 지표로 활용하는 것이 적절하다.**

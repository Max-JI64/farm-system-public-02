# 캐나다 FFMC 기반 강원도 선행연구 재현 계획

이 문서는 `캐나다산불지수-강원도선행분석_raw.md`와 `캐나다산불지수-강원도선행분석.pdf`의 분석을 현재 강원도 학습데이터에 재현하기 위한 구현 설계서입니다. 이 트랙은 캐나다 FWI 시스템 전체가 아니라 **FFMC(Fine Fuel Moisture Code)만 사용한 로지스틱 발생확률 모형**을 재현합니다.

## 0. 이 문서의 결론

이 문서는 **강원도 선행연구 재현 트랙**입니다. Van Wagner(1987)의 전체 FWI 시스템을 모두 계산하는 문서가 아니라, 선행연구가 실제 예측모형에 사용한 `FFMC` 기반 로지스틱 흐름만 구현합니다.

고정된 해석은 다음과 같습니다.

- Van Wagner(1987) 원문은 `FFMC`, `DMC`, `DC`, `ISI`, `BUI`, `FWI` 같은 **지수 점수 산출 체계**를 제시한다.
- 강원도 선행연구는 그 전체 지수 중 **FFMC만 사용**하고, 봄철 산불조심기간의 10일 평균 FFMC를 4단계로 지수화한 뒤 로지스틱 회귀식으로 산불발생확률을 계산했다.
- 따라서 이 문서의 목표는 `FFMC → FFMC_10일평균 → Indexed_FFMC → FFMC_논문식_발생확률`을 만드는 것이다.
- `DMC`, `DC`, `ISI`, `BUI`, `FWI`는 이 문서에서 계산하지 않는다. 전체 FWI 지수 산출은 `캐나다산불지수-FWI.md`에서 다룬다.
- 산출된 확률은 선행연구식 재현값이다. 현재 프로젝트의 최종 산불 예측모형을 대체하지 않고, `주제에 대한 생각.md`의 FA 요인점수 기반 모델과 성능 비교하는 기준선으로 사용한다.

새 세션에서 이 문서를 이어받는 경우, 위 해석을 바꾸지 않는다.

## 1. 분석 범위

선행연구의 실제 모델링 흐름은 다음과 같습니다.

```text
기상자료
→ 기상셀별 일별 FFMC 계산
→ 봄철 산불조심기간 중심의 10일 평균 FFMC 산출
→ 10일 평균 FFMC를 4단계 Indexed_FFMC로 변환
→ logit(P) = -0.529 + 0.422 × Indexed_FFMC
→ 산불발생확률 산출
```

따라서 이 문서에서는 `DMC`, `DC`, `ISI`, `BUI`, 최종 `FWI`는 계산하지 않습니다. 이들은 `캐나다산불지수-FWI.md`의 전체 FWI 시스템 구현 트랙에서 다룹니다.

### 고정 구현 정책

- 원본 `학습데이터_최종.csv`는 수정하지 않는다.
- 기상 지수는 `기상_시간단위_파생.csv`에서 먼저 `기상셀ID × 날짜` 단위로 산출한다.
- 표준 FFMC는 전일 상태를 사용하는 재귀 지수이므로, `학습데이터_최종.csv`의 샘플 행만으로 직접 계산하지 않는다.
- `일시.hour == 12` 행을 일 대표 기상으로 사용한다.
- `날짜`는 정오 행의 `일시`에서 날짜만 추출한다.
- `시점_풍속_m_s`는 반드시 `km/h`로 변환한 뒤 FFMC 공식에 넣는다.
- 상대습도는 계산 전 0~100 범위로 제한한다.
- 강수량, 풍속은 음수가 나오면 0으로 보정한다.
- 각 `기상셀ID`의 첫 계산일에는 초기 FFMC를 `85`로 둔다.
- 최종 병합은 `학습데이터_최종.csv`의 `기상셀ID`와 `기준시각`에서 추출한 `날짜`를 기준으로 한다.

## 3. FFMC 계산식

전일 FFMC `F0`를 전일 미세연료 수분량 `m0`로 변환합니다.

```text
m0 = 147.2(101 - F0) / (59.5 + F0)
```

강수량이 `0.5mm`를 초과하면 건조/습윤 계산 전에 강수 보정을 적용합니다.

```text
rf = r0 - 0.5

Δm = 42.5 rf exp[-100 / (251 - m0)] [1 - exp(-6.93 / rf)]

if m0 > 150:
    Δm = Δm + 0.0015(m0 - 150)^2 rf^0.5

mr = min(m0 + Δm, 250)
```

`r0 <= 0.5`이면 `mr = m0`로 둡니다.

평형수분량은 건조 상황과 습윤 상황을 분리합니다.

```text
Ed = 0.942 H^0.679 + 11 exp[(H - 100) / 10]
     + 0.18(21.1 - T)(1 - exp[-0.115H])

Ew = 0.618 H^0.753 + 10 exp[(H - 100) / 10]
     + 0.18(21.1 - T)(1 - exp[-0.115H])
```

건조율과 습윤율은 다음과 같이 계산합니다.

```text
k0 = 0.424[1 - (H / 100)^1.7]
     + 0.0694 W^0.5 [1 - (H / 100)^8]

kw0 = 0.424[1 - ((100 - H) / 100)^1.7]
      + 0.0694 W^0.5 [1 - ((100 - H) / 100)^8]

kd = k0  × 0.581 exp(0.0365T)
kw = kw0 × 0.581 exp(0.0365T)
```

당일 수분량 `m`은 강수 보정 후 수분량 `mr`을 기준으로 분기합니다.

```text
if mr > Ed:
    m = Ed + (mr - Ed) × 10^(-kd)
elif mr < Ew:
    m = Ew - (Ew - mr) × 10^(-kw)
else:
    m = mr
```

마지막으로 당일 FFMC를 계산합니다.

```text
FFMC = 59.5(250 - m) / (147.2 + m)
```

초기값은 각 `기상셀ID`의 첫 날짜에 `F0 = 85`를 사용합니다.

이 문서에는 선행연구 트랙 구현에 필요한 FFMC 공식 전체가 들어 있습니다. 구현 시에는 이 섹션의 순서대로 `전일 FFMC 변환 → 강수 보정 → 평형수분량 계산 → 건조/습윤 단계 → 당일 FFMC 변환`을 적용합니다.

## 4. 선행연구 지수화 및 로지스틱 확률

선행연구는 10일 평균 FFMC를 4단계 지수로 변환한 뒤 로지스틱 회귀식에 투입합니다.

| `FFMC_10일평균` | `Indexed_FFMC` |
|---:|---:|
| 0.00 ~ 58.00 | 1 |
| 58.01 ~ 70.50 | 2 |
| 70.51 ~ 80.00 | 3 |
| 80.01 이상 | 4 |

현재 프로젝트에서는 `FFMC_10일평균`을 기상셀별 날짜순 최근 10일 이동평균으로 계산합니다.

```text
FFMC_10일평균 = 기상셀ID별 날짜순 FFMC의 trailing 10일 평균
```

v1 구현에서는 최종 병합 결측을 만들지 않기 위해 `min_periods=1` 정책을 사용합니다. 즉, 각 기상셀의 첫 9일은 확보된 일수만으로 평균을 계산합니다. 선행연구의 순기 평균을 엄격히 재현하는 별도 실험을 할 경우에는 `min_periods=10` 또는 고정 순기 구간 평균을 추가 비교할 수 있지만, 기본 산출물 컬럼명은 유지합니다.

로지스틱 식은 다음을 사용합니다.

```text
logit(P) = -0.529 + 0.422 × Indexed_FFMC

P = exp(logit(P)) / [1 + exp(logit(P))]
```

계수는 선행연구 정리본의 Table 2 기준 `Indexed FFMC = 0.422`, 상수항 `-0.529`를 사용합니다. 본문 수식 이미지에 `0.421`처럼 보이는 표기가 있더라도, 기본 재현값은 표 계수인 `0.422`로 고정합니다.

이 확률은 선행연구 재현용 참고 확률이며, 최종 강원도 FA 기반 예측모형의 확률과 직접 같은 의미로 해석하지 않습니다.

이 확률은 `Indexed_FFMC`만 사용한 단변량 로지스틱 결과입니다. FA 요인점수, DMC, DC, ISI, BUI, FWI를 이 식에 추가하지 않습니다.

## 6. 분석 단계

1. `기상_시간단위_파생.csv`에서 정오 행만 추출한다.
2. `기상셀ID`별 날짜순으로 표준 FFMC를 재귀 계산한다.
3. `FFMC_10일평균`, `Indexed_FFMC`, `FFMC_논문식_발생확률`을 생성한다.
4. 일단위 산출물을 `캐나다_FFMC_선행연구_일단위.csv`로 저장한다.
5. `학습데이터_최종.csv`에 `기상셀ID + 날짜` 기준으로 병합하여 `학습데이터_최종_캐나다지수.csv`를 생성한다.
6. `Target`, `샘플유형`, `기후지형유형`별 FFMC 분포와 로지스틱 확률 분포를 비교한다.
7. FA 요인점수 기반 모델과 `FFMC-logistic` 기준 성능을 AUROC, AUPRC, F1, 샘플유형별 성능으로 비교한다.

### 구현 의사코드

```text
weather = read_csv("data/학습데이터/기상_시간단위_파생.csv")
weather["일시"] = datetime(weather["일시"])
daily = weather[weather["일시"].hour == 12].copy()
daily["날짜"] = date(daily["일시"])
daily["기온_C"] = daily["시점_기온_C"]
daily["습도_pct"] = clip(daily["시점_습도_pct"], 0, 100)
daily["풍속_km_h"] = max(daily["시점_풍속_m_s"], 0) * 3.6
daily["강수량_mm"] = max(daily["직전24h_강수량합"], 0)

for each 기상셀ID:
    sort by 날짜
    F0 = 85
    for each 날짜:
        FFMC = calc_ffmc(F0, 기온_C, 습도_pct, 풍속_km_h, 강수량_mm)
        save FFMC
        F0 = FFMC

daily["FFMC_10일평균"] = rolling_mean_by_cell(daily["FFMC"], window=10, min_periods=1)
daily["Indexed_FFMC"] = cut(FFMC_10일평균, [0, 58, 70.5, 80, infinity], labels=[1, 2, 3, 4])
daily["FFMC_논문식_발생확률"] = logistic(-0.529 + 0.422 * Indexed_FFMC)

train = read_csv("data/학습데이터/학습데이터_최종.csv")
train["날짜"] = date(train["기준시각"])
merged = left_join(train, daily[캐나다 FFMC 컬럼], on=["기상셀ID", "날짜"])
write_csv(merged, "data/학습데이터/학습데이터_최종_캐나다지수.csv")
```

## 7. 검증 기준

- `캐나다_FFMC_선행연구_일단위.csv`는 `기상셀ID × 날짜` 기준 중복이 없어야 한다.
- `학습데이터_최종_캐나다지수.csv` 병합 후 FFMC 계열 컬럼 결측률은 0%여야 한다.
- 비가 온 날에는 전후 일자 대비 FFMC가 하락하는 표본이 확인되어야 한다.
- `Indexed_FFMC`는 1~4 범위만 가져야 한다.
- `FFMC_논문식_발생확률`은 0~1 범위만 가져야 한다.

## 8. 새 세션 작업자가 지켜야 할 주의사항

- 이 문서는 선행연구 재현 트랙이므로 `DMC`, `DC`, `ISI`, `BUI`, `FWI`를 추가하지 않는다.
- `캐나다산불지수-FWI.md`의 전체 FWI 산출 결과와 컬럼명이 겹치는 `FFMC`는 같은 표준 FFMC 계산 함수를 공유해야 한다.
- 이 문서에서 만든 `FFMC_논문식_발생확률`은 최종 예측모형의 정답 확률이 아니라, 선행연구식 기준선이다.
- `학습데이터_최종.csv`는 원본 학습데이터로 유지한다. 캐나다 지수 병합 결과는 반드시 새 파일로 저장한다.
- 요인분석을 다시 수행하지 않는다. `FFMC`, `FFMC_10일평균`, `Indexed_FFMC`, `FFMC_논문식_발생확률`은 FA 외부의 이론 기반 파생지표로 관리한다.

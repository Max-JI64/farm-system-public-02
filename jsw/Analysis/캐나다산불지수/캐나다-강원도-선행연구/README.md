# 캐나다 FFMC 선행연구 모델 학습 결과

이 문서는 `모델학습.ipynb`에서 수행하도록 구성한 캐나다 FFMC 기반 강원도 선행연구 재현 모델의 학습/평가 결과를 정리한 것이다.

## 실행 개요

- 기준일: 2026-06-12
- 입력 데이터: `data/학습데이터/학습데이터_최종_캐나다지수.csv`
- 데이터 크기: 17,045행 x 68열
- Train/Test 분할: `Target` 층화 70:30, `random_state=42`
- Train: 11,931행
- Test: 5,114행
- Test 양성 비율: 9.1122%
- 평가 임계값: 0.5
- 출력 정책: 모든 표와 그림은 `모델학습.ipynb` 셀 출력에서 생성하며, `model_outputs` 같은 외부 산출물 디렉터리는 사용하지 않는다.
- 모델 제약: 캐나다 FFMC 선행연구 재현 목적이므로 모든 학습 모델은 로지스틱 회귀이며, 입력 변수는 반드시 `Indexed_FFMC` 1개로 고정한다.

## 모델 정의

두 모델은 모두 `Indexed_FFMC` 1개 변수만 사용한다.

| 모델 | 학습 여부 | 입력 변수 | 식/방법 |
|---|---:|---|---|
| `논문식_FFMC` | 없음 | `Indexed_FFMC` | `sigmoid(-0.529 + 0.422 * Indexed_FFMC)` |
| `재학습_FFMC_Logistic` | 있음 | `Indexed_FFMC` | L2 규제 기본값 `C=1.0` 로지스틱 회귀 |
| `규제튜닝_L1_LogisticCV` | 있음 | `Indexed_FFMC` | L1 규제 로지스틱 회귀, 5-fold CV로 `C` 선택 |
| `규제튜닝_L2_LogisticCV` | 있음 | `Indexed_FFMC` | L2 규제 로지스틱 회귀, 5-fold CV로 `C` 선택 |

`FFMC`, `FFMC_10일평균`은 `Indexed_FFMC`를 만들기 위한 선행 파생 변수이고, `FFMC_논문식_발생확률`은 논문식의 예측 결과값이다. 재학습 모델 입력에는 넣지 않았다.

## 전체 성능

| 모델 | AUROC | AUPRC | Accuracy | Balanced Accuracy | Precision | Recall | F1 | Brier Score | TN | FP | FN | TP |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| `논문식_FFMC` | 0.554322 | 0.101893 | 0.182831 | 0.543694 | 0.099115 | 0.984979 | 0.180106 | 0.434350 | 476 | 4,172 | 7 | 459 |
| `재학습_FFMC_Logistic` | 0.554322 | 0.101893 | 0.530113 | 0.538770 | 0.104532 | 0.549356 | 0.175643 | 0.246738 | 2,455 | 2,193 | 210 | 256 |
| `규제튜닝_L1_LogisticCV` | 0.554322 | 0.101893 | 0.332225 | 0.533203 | 0.098776 | 0.778970 | 0.175320 | 0.255167 | 1,336 | 3,312 | 103 | 363 |
| `규제튜닝_L2_LogisticCV` | 0.554322 | 0.101893 | 0.530113 | 0.538770 | 0.104532 | 0.549356 | 0.175643 | 0.246737 | 2,455 | 2,193 | 210 | 256 |

두 모델은 같은 단일 변수의 단조 변환을 사용하므로 순위 기반 지표인 AUROC와 AUPRC는 동일하다. 차이는 확률 스케일과 0.5 임계값에서 나타난다.

- 논문식은 평균 예측확률이 0.679412로 높아 대부분을 산불 발생으로 예측한다.
- 논문식은 Recall이 0.984979로 매우 높지만 FP가 4,172건으로 많고 Accuracy가 낮다.
- `재학습_FFMC_Logistic`과 `규제튜닝_L2_LogisticCV`는 거의 같은 분류 결과를 보이며, L2 CV가 Brier Score를 0.246737로 아주 미세하게 개선한다.
- `규제튜닝_L1_LogisticCV`는 Recall을 0.778970까지 높이지만 FP가 3,312건으로 늘어 Accuracy와 Brier Score가 나빠진다.
- 현재 단일 변수 구조에서는 L1/L2 규제를 추가해도 AUROC/AUPRC는 개선되지 않는다. 동일 변수의 단조 로지스틱 변환이므로 순위 기반 지표는 그대로 유지된다.

## 해석

`Indexed_FFMC` 단변량 모델은 선행연구의 방향성은 재현하지만, 현재 강원도 학습데이터에서 단독 예측력은 제한적이다. L1/L2 규제 강도를 바꿔도 AUROC 0.554322와 AUPRC 0.101893은 개선되지 않았다.

따라서 이 결과는 최종 산불 예측모형이라기보다, 캐나다 FFMC 선행연구식을 현재 데이터에 적용했을 때의 기준선으로 해석해야 한다. 선행연구 재현 조건을 지키는 한, 로지스틱 회귀의 규제 조정만으로는 성능 개선 여지가 크지 않다.

## 최종 분석

### 성능 수준 판단

현재 `Indexed_FFMC` 단변량 로지스틱 계열의 핵심 성능은 다음과 같다.

| 관점 | 대표값 | 해석 |
|---|---:|---|
| AUROC | 0.554322 | 무작위 0.5보다 약간 높지만 분류력이 약함 |
| AUPRC | 0.101893 | Test 양성 비율 0.091122와 큰 차이가 없어 희소 양성 탐지력이 약함 |
| 최고 Accuracy | 0.530113 | `재학습_FFMC_Logistic`, `규제튜닝_L2_LogisticCV` 기준 |
| 최고 Balanced Accuracy | 0.543694 | `논문식_FFMC` 기준 |
| 최고 Recall | 0.984979 | `논문식_FFMC` 기준이나 FP가 4,172건으로 과다 |
| 최저 Brier Score | 0.246737 | `규제튜닝_L2_LogisticCV` 기준, 확률 보정은 가장 양호 |

결론적으로 이 모델은 **단독 산불 예측 모델로 쓰기에는 성능이 부족하다**. `Indexed_FFMC`가 높을수록 산불 발생 가능성이 증가한다는 방향성은 확인되지만, 산불/비산불을 실무적으로 구분할 만큼의 판별력은 나오지 않았다. 특히 AUROC가 0.55 수준이고 AUPRC가 양성 기준선과 거의 붙어 있어, 단일 FFMC 지수만으로 산불 발생 여부를 안정적으로 예측하기 어렵다.

### 어떤 모델이 가장 나은가

현재 제약 조건 안에서는 `규제튜닝_L2_LogisticCV`가 가장 무난하다.

- `재학습_FFMC_Logistic`과 분류 결과는 동일하다.
- Brier Score가 0.246737로 가장 낮아 확률 스케일은 가장 조금 낫다.
- L1 CV는 Recall을 높이지만 Target 0을 너무 많이 양성으로 예측하므로 오경보가 크다.
- 논문식은 Target 1을 거의 다 잡지만 Target 0도 대부분 양성으로 예측해 현재 데이터에는 과민한 기준선이다.

다만 `규제튜닝_L2_LogisticCV`도 성능 개선 폭은 사실상 미미하다. 입력 변수가 `Indexed_FFMC` 하나이기 때문에, L1/L2 규제로 조정할 수 있는 것은 계수 크기와 확률 스케일뿐이다. 순위 기반 성능인 AUROC/AUPRC는 개선되지 않았다.

### 선행분석 PDF와의 비교

`캐나다산불지수-강원도선행분석.pdf`의 선행분석은 봄철 산불조심기간의 10일 평균 FFMC를 4단계 `INDEX`로 만든 뒤 로지스틱 회귀를 적용했고, 판별율을 약 63.6%로 보고했다. 본 재현 결과와 비교하면 다음과 같다.

| 비교 항목 | 선행분석 | 현재 재현 결과 |
|---|---|---|
| 입력 변수 | 4단계 Indexed FFMC | 동일하게 `Indexed_FFMC` |
| 모델 형태 | 단변량 로지스틱 회귀 | 단변량 로지스틱 회귀 |
| 계수 방향 | 양수 | 양수 |
| 보고 성능 | 분류 정확도 63.6% | 최고 Accuracy 53.0%, AUROC 0.554 |
| 해석 | FFMC index가 높을수록 산불 위험 증가 | 같은 방향성은 재현되나 예측력은 약함 |

방향성은 선행분석과 비슷하게 나왔다. 즉, `Indexed_FFMC`가 높아질수록 산불 발생 확률이 증가한다는 결론은 현재 데이터에서도 유지된다.

하지만 성능 수준은 선행분석보다 낮게 보인다. 선행분석의 63.6% 판별율과 현재 Accuracy 53.0%는 직접적으로 완전히 같은 지표라고 보기는 어렵다. 현재 데이터는 실제 산불 1,553건과 네거티브 대조군 15,492건으로 구성된 불균형 학습데이터이고, Test 양성 비율도 9.1122%다. 이 구조에서는 단순 Accuracy가 데이터 구성과 임계값에 크게 좌우된다. 따라서 선행분석과의 비교는 “같은 방향성이 재현되었는가”를 중심으로 보는 것이 더 타당하다.

### 최종 결론

캐나다 FFMC 선행연구 모델은 현재 강원도 데이터에서도 **위험 방향성은 재현되지만, 예측 모델로는 약하다**. `Indexed_FFMC` 단일 변수는 산불 발생 가능성을 설명하는 참고 지표로 의미가 있으나, 실제 예측 성능은 낮다.

따라서 이 모델은 최종 예측모형이 아니라 **비교 기준선(baseline)** 으로 사용하는 것이 적절하다. 이후 모델링에서는 선행연구 재현 트랙은 여기서 고정하고, 별도 비교 트랙에서 FA 요인점수, FWI 전체 지수, 공간·기상 파생변수를 결합한 모델과 성능을 비교해야 한다.

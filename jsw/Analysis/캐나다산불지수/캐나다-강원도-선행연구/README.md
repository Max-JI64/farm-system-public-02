# 캐나다 FFMC 선행연구 모델 학습 결과

이 문서는 `모델학습.ipynb`에서 수행하도록 구성한 캐나다 FFMC 기반 강원도 선행연구 재현 모델의 학습/평가 결과를 정리한 것이다.

## 실행 개요

- 기준일: 2026-06-12
- 입력 데이터: `data/학습데이터/학습데이터_최종_캐나다지수.csv`
- 데이터 크기: 17,045행 x 68열
- Train/Test 분할: `Target` 층화 70:30, `random_state=42`
- Train: 11,931행
- Test: 5,114행
- Test 양성 비율: 9.1122%
- 평가 임계값: 0.5
- 출력 정책: 모든 표와 그림은 `모델학습.ipynb` 셀 출력에서 생성하며, `model_outputs` 같은 외부 산출물 디렉터리는 사용하지 않는다.

## 모델 정의

두 모델은 모두 `Indexed_FFMC` 1개 변수만 사용한다.

| 모델 | 학습 여부 | 입력 변수 | 식/방법 |
|---|---:|---|---|
| `논문식_FFMC` | 없음 | `Indexed_FFMC` | `sigmoid(-0.529 + 0.422 * Indexed_FFMC)` |
| `재학습_FFMC_Logistic` | 있음 | `Indexed_FFMC` | 현재 train split으로 `LogisticRegression(class_weight="balanced")` 재추정 |

`FFMC`, `FFMC_10일평균`은 `Indexed_FFMC`를 만들기 위한 선행 파생 변수이고, `FFMC_논문식_발생확률`은 논문식의 예측 결과값이다. 재학습 모델 입력에는 넣지 않았다.

## 전체 성능

| 모델 | AUROC | AUPRC | Accuracy | Balanced Accuracy | Precision | Recall | F1 | Brier Score | TN | FP | FN | TP |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| `논문식_FFMC` | 0.554322 | 0.101893 | 0.182831 | 0.543694 | 0.099115 | 0.984979 | 0.180106 | 0.434350 | 476 | 4,172 | 7 | 459 |
| `재학습_FFMC_Logistic` | 0.554322 | 0.101893 | 0.530113 | 0.538770 | 0.104532 | 0.549356 | 0.175643 | 0.246738 | 2,455 | 2,193 | 210 | 256 |

두 모델은 같은 단일 변수의 단조 변환을 사용하므로 순위 기반 지표인 AUROC와 AUPRC는 동일하다. 차이는 확률 스케일과 0.5 임계값에서 나타난다.

- 논문식은 평균 예측확률이 0.679412로 높아 대부분을 산불 발생으로 예측한다.
- 논문식은 Recall이 0.984979로 매우 높지만 FP가 4,172건으로 많고 Accuracy가 낮다.
- 재학습 모델은 평균 예측확률이 0.494491로 낮아져 FP를 줄였지만 Recall은 0.549356으로 감소한다.
- Brier Score는 재학습 모델이 0.246738로 논문식 0.434350보다 낮아, 현재 샘플링 데이터의 확률 스케일에는 재학습 모델이 더 잘 맞는다.

## 계수 비교

| 모델 | 항 | 계수 | 현재 데이터 학습 여부 |
|---|---|---:|---:|
| `논문식_FFMC` | intercept | -0.529000 | False |
| `논문식_FFMC` | `Indexed_FFMC` | 0.422000 | False |
| `재학습_FFMC_Logistic` | intercept | -0.743063 | True |
| `재학습_FFMC_Logistic` | `Indexed_FFMC` | 0.232003 | True |

재학습 결과에서도 `Indexed_FFMC` 계수는 양수다. 즉, `Indexed_FFMC`가 높을수록 산불 발생 예측확률이 증가하는 방향은 선행연구와 동일하다. 다만 현재 데이터에서는 기울기가 논문식보다 작게 추정되어 예측확률 증가 폭이 완만하다.

## 노트북 출력 구성

`모델학습.ipynb`는 다음 순서로 실행된다.

| 단계 | 내용 |
|---|---|
| 1 | 환경 설정 및 한글 폰트 설정 |

| 3 | Target 층화 train/test 분할 |

| 6 | 전체 성능표, 샘플유형별 요약표, 예측 샘플 출력 |
| 7 | ROC, PR, 혼동행렬, 확률분포, 샘플유형별 확률분포, 주요 성능 비교 그래프 출력 |

## 해석

`Indexed_FFMC` 단변량 모델은 선행연구의 방향성은 재현하지만, 현재 강원도 학습데이터에서 단독 예측력은 제한적이다. AUROC 0.554322와 AUPRC 0.101893은 무작위보다는 약간 낫지만 강한 분류 모델이라고 보기 어렵다.

따라서 이 결과는 최종 산불 예측모형이라기보다, 캐나다 FFMC 선행연구식을 현재 데이터에 적용했을 때의 기준선으로 해석해야 한다. 이후 비교에서는 `FA-only`, `FWI-index-features`, `FA+Canadian-index` 모델과 성능을 나란히 비교하는 것이 적절하다.

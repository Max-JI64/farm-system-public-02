# 머신러닝 학습 계획

현재 활성 계획은 [머신러닝_파이프라인_재설계_계획.md](머신러닝_파이프라인_재설계_계획.md)를 따른다.

## 활성 단계

1. STEP 1 단일 모델 screening
2. STEP 2 하이퍼파라미터 튜닝
3. STEP 3 tuned LightGBM F2 threshold 선정과 recall 민감도 분석
4. STEP 4 tuned LightGBM 해석과 오류 분석

STEP 1과 STEP 2 결과는 기존 OOF와 선택 parameter를 재사용한다. STEP 2에서 AUPRC 기준 최종 선정된 `TUNE_LGBM_ALL_ALL_LC_NONE`의 raw OOF score에 대해 STEP 3에서 F2 threshold를 정한다.

Calibration과 앙상블은 활성 파이프라인에서 제외한다. Raw score는 실제 산불 발생확률로 해석하지 않고, 위험 순위와 운영 threshold를 위한 score로만 사용한다.

이전 ablation 기반 계획과 결과는 `archive/legacy_ablation_pipeline_20260623/`에 보존되어 있으며 활성 파이프라인에서 사용하지 않는다.

# 강원도 산불 로지스틱 모델링 계획

## 0. 단계별 진행 순서

모델 성능 비교보다 먼저 누수 없는 데이터와 고정된 검증 구조를 만든다. 전체 작업 순서는 다음과 같다.

### 1단계. 캐나다 지수 시간 누수 수정

- 현재 같은 날 12시 기준으로 병합된 캐나다 지수를 모델 입력에서 제거한다.
- 주 분석용 지수는 모든 표본에 D-1 정오 값을 적용한다.
- 필요하면 기준시각 이전 최신 정오 값을 적용한 민감도 데이터를 별도로 만든다.
- 행 수, Target 분포, 지수 결측, 병합 기준 날짜가 기준시각보다 이전인지 검증한다.

### 2단계. 그룹 ID 복원

- `학습데이터_병합.csv`에서 `fire_id`, `원본_fire_id`, `후보점ID`를 `샘플ID` 기준으로 복원한다.
- Target 1과 그 위치에서 파생된 0-A에 동일한 `source_fire_id`를 부여한다.
- 0-B1/0-B2는 `후보점ID`를 독립 그룹으로 사용한다.
- 동일 그룹이 train, validation, test에 나뉘지 않게 한다.

### 3단계. 모델 입력 변수 확정

- M1: 날씨·공간 + FA + 캐나다 지수
- M2: 날씨·공간 + 캐나다 지수
- M3: 날씨·공간
- ID, 좌표, 샘플 생성 메타데이터와 같은 누수성 변수는 입력에서 제외한다.
- 거리 변수 log 변환과 월·시간 순환형 변수를 생성한다.
- 세 모델의 변수 목록을 JSON manifest로 저장해 이후 비교에서 변경되지 않게 한다.

### 4단계. 검증 데이터 분할 고정

- 그룹 기준 약 20%를 최종 lockbox test로 분리한다.
- 나머지 개발 데이터에 grouped outer 5-fold를 만든다.
- 각 outer training 구간 안에 grouped inner 4-fold를 만든다.
- 모든 로지스틱 계열 통계모델이 동일한 분할 manifest를 사용한다.

### 5단계. 기준 모델 학습

- Dummy classifier와 L2 로지스틱을 먼저 실행한다.
- M1·M2·M3를 같은 fold에서 비교한다.
- AUPRC, AUROC, Brier score, calibration과 negative type별 성능을 산출한다.
- threshold 0.5, OOF F1 최적, Recall 90% 기준의 정확도·균형정확도·정밀도·재현율·특이도·F1·MCC·confusion matrix를 함께 보고한다.

### 6단계. 로지스틱 성능 개선

- 5단계 결과에 따라 FA 요인점수는 이후 주 모델 입력에서 제외하고, `날씨·공간 + D-1 캐나다 지수` 구성을 주 후보로 사용한다.
- L1, L2, Elastic Net을 비교한다.
- `C`, `l1_ratio`, class weight를 inner grouped CV에서 조정한다.
- fold 평균뿐 아니라 분산과 변수 선택 안정성을 확인한다.
- 캐나다 지수는 전체 지수, FWI 단독, FFMC·DMC·DC, FFMC·ISI·BUI, 미사용 구성을 비교해 중복 지수를 축소한다.

### 7단계. 변수 축소와 상호작용 검정

- 습도·풍속·강수·지형·접근성·FA·캐나다 지수 블록 제거 실험을 수행한다.
- 반복 CV에서 변수 선택 빈도와 계수 부호 일치율을 계산한다.
- EDA에서 사전 지정한 `영동×풍속`, `영동×서풍`, `습도×풍속` 등의 상호작용을 검정한다.
- 필요 변수에 spline을 적용해 비선형 임계치를 확인한다.

2026-06-18 실행 결과:

- 국지 저습, 6시간 풍속, 무강수 지속과 EDA 복합 플래그를 추가해 전체 AUPRC를 0.3339에서 0.3751, 0-A AUPRC를 0.3628에서 0.4088로 개선했다.
- 전체 상호작용까지 넣으면 AUPRC가 0.3759로 소폭 높아지지만 단순 세트 대비 이득이 0.0008뿐이고 fold 일관성도 약했다.
- 후속 주 모델은 `PLUS_CONTINUOUS_FLAGS`를 사용한다.
- 개선은 영동 해안형에서 뚜렷했고 영서·고지산간형에서는 거의 없었다.

### 7.5단계. 날짜·기상노출 단위의 엄격한 재검증

- 동일 `기상셀ID×기준시각` 노출이 train과 validation에 동시에 들어가지 않도록 분할 그룹을 보완한다.
- 2021년 2월 1~3일과 같은 집단발생 날짜가 여러 fold에 분산될 때의 낙관 편향을 확인한다.
- Step 6 기준모델과 Step 7 추천모델만 동일한 엄격 분할에서 재검증한다.
- AUPRC뿐 아니라 ROC AUC, Brier, calibration, F1 최적 운영점, Recall 90% 운영점을 모두 비교한다.
- lockbox는 이 재검증과 모델 확정이 끝날 때까지 사용하지 않는다.

### 8단계. 오즈비 분석

- 원본 변수 축소 모델, FA 중심 모델, 캐나다 지수 모델을 분리한다.
- 표준화 OR, 95% CI, 실무 단위 OR, 선택 빈도와 부호 안정성을 보고한다.
- 원변수와 그 선형결합인 FA를 동시에 넣은 모델의 개별 OR은 핵심 해석에 사용하지 않는다.

### 9단계. 로지스틱 계열 통계모델 확장

- 동일한 strict split으로 L1, L2, Elastic Net, class-weight/cost-sensitive logistic을 비교한다.
- 필요하면 같은 GLM 계열 안에서 spline/GAM logistic, GEE, 혼합효과 로지스틱을 별도 후보로 검토한다.
- AUPRC, calibration, hard-negative 성능, 운영 threshold, 오즈비 안정성을 함께 비교한다.

### 10단계. 최종 판단과 EDA 연결

- FA 파트를 최종 보고서에서 유지할지 제거할지 결정한다.
- 안전한 캐나다 지수가 추가 성능을 주는지 판단한다.
- 로지스틱 계열 통계모델 중 최종 모델을 선택한다.
- `final_eda.md`의 습도·강수·영동 강풍·도로 접근성 결론과 모델 결과의 일치·불일치를 정리한다.

## 1. 분석 목적

최종 학습데이터를 이용해 강원도 산불 발생 여부(`Target`)를 예측하고, 다음 세 변수 구성이 예측 성능과 해석력에 미치는 차이를 공정하게 비교한다.

| 모델 세트 | 공통 원본 날씨·공간 변수 | FA 요인점수 | 캐나다 산불지수 |
|---|---:|---:|---:|
| Set 1 | 포함 | 포함 | 포함 |
| Set 2 | 포함 | 제외 | 포함 |
| Set 3 | 포함 | 제외 | 제외 |

주요 판단 질문은 다음과 같다.

1. FA 요인점수가 원본 변수와 캐나다 지수에 추가적인 예측력을 주는가?
2. 캐나다 산불지수가 원본 날씨·공간 변수에 추가적인 예측력을 주는가?
3. 일반 L2 로지스틱보다 L1, Elastic Net, class-weight, spline/GAM logistic, GEE/혼합효과 로지스틱이 성능 또는 해석 안정성을 개선하는가?
4. 성능 차이가 작다면 가장 단순하고 보정 안정성이 높은 로지스틱 회귀를 선택할 수 있는가?
5. 모델 결과가 `jsw/final_eda.md`의 저습·무강수·영동 강풍·도로 초접경 결론과 일치하는가?

## 3. 모델 학습 전에 반드시 해결할 사항

### 3-1. 캐나다 지수의 시간 누수 수정

현재 캐나다 지수는 기상셀별 같은 날 12시 기상으로 계산한 일 단위 값을 `기상셀ID + 날짜`로 병합했다. 기준시각이 12:00 이전인 행은 같은 날 12시 값이 미래 정보가 된다.

- 전체 12:00 이전 행: 7,777행
- 12:00 이전 Target 1: 693행

따라서 현재 파일의 같은 날 `FFMC`, `FFMC_10일평균`, `Indexed_FFMC`, `FFMC_논문식_발생확률`, `DMC`, `DC`, `ISI`, `BUI`, `FWI`를 그대로 사용한 성능은 최종 성능으로 인정하지 않는다.

기본 정책은 다음 중 하나로 확정한다.

1. **엄격한 예측 모델 기본안:** 모든 행에 D-1 정오 캐나다 지수를 사용한다.
2. **최신 가용 관측 민감도:** 기준시각 이전에 이미 관측된 가장 최근 정오 값만 사용한다.
   - 기준시각이 12시 이하이면 D-1 정오
   - 기준시각이 12시 초과이면 당일 정오

최종 보고서의 주 결과는 가장 안전한 D-1 정책으로 작성한다. 같은 날 지수 모델은 시간 누수 영향 확인용 민감도 결과로만 남긴다.

### 3-2. Target 1과 0-A의 그룹 분할

`Target_0A`는 각 실제 산불 위치를 고정하고 다른 비발생 시각을 붙인 대조군이다. 무작위 행 분할을 하면 같은 실제 산불 위치의 Target 1은 test에, 동일 위치의 0-A는 train에 들어갈 수 있다. 공간 변수와 위치 특성이 사실상 복제되므로 성능이 과대평가된다.

최종 CSV에서는 `원본_fire_id`가 제거됐지만 `학습데이터_병합.csv`에는 남아 있다. 다음 방식으로 모델링 그룹 키를 복원한다.

- `샘플ID`로 `학습데이터_병합.csv`의 `fire_id`, `원본_fire_id`, `후보점ID`를 결합한다.
- `source_fire_id = 원본_fire_id`를 우선 사용하고, Target 1처럼 값이 없으면 `fire_id`로 보완한다.
- Target 1과 그에 대응하는 0-A는 같은 `source_fire_id` 그룹으로 묶는다.
- 0-B1/0-B2는 `후보점ID`별 독립 그룹으로 둔다.
- 이 그룹은 train/validation/test 중 하나에만 들어가게 한다.

### 3-3. 모델 입력에서 제외할 누수·식별자 변수

다음 변수는 모델 입력으로 사용하지 않는다.

- 식별자: `샘플ID`, `기준시각` 원문, `위도`, `경도`, `기상셀ID`
- 정답 또는 샘플 생성 정보를 직접 드러내는 변수:
  - `Target`
  - `샘플유형`
  - `실험안`
  - `시간샘플링방식`
  - `공간층`
  - `샘플가중치`
- 그룹 분할용 복원 변수:
  - `fire_id`
  - `원본_fire_id`
  - `후보점ID`

특히 `샘플유형`, `시간샘플링방식`, `공간층`은 실제 전신주 추론 시 알 수 없는 샘플 생성 메타데이터이므로 절대 피처로 넣지 않는다.

### 3-4. 절대 발생확률 해석 제한

현재 데이터의 1:10 비율은 실제 강원도 산불 발생률이 아니라 설계된 네거티브 샘플링 비율이다. 따라서 보정하지 않은 `predict_proba`는 실제 산불 발생확률이 아니다.

- 현재 단계에서 직접 해석 가능한 것은 동일한 샘플링 프레임 안의 상대 위험 순위와 분류 성능이다.
- 실제 확률로 사용하려면 실제 운영 모집단의 산불 발생률 또는 별도 시계열 검증 모집단으로 사전확률 보정과 calibration을 수행해야 한다.
- 오즈비도 “설계된 대조군과 비교한 조건부 오즈비”로 표현하고 모집단 절대위험 배수로 확대 해석하지 않는다.

## 4. 변수 세트 정의

세 모델 세트는 FA와 캐나다 지수 이외의 전처리, 학습 행, 분할, 평가 지표를 완전히 동일하게 유지한다.

### 4-1. 공통 날씨 변수

- 현재 또는 기준시각 기상:
  - `시점_기온_C`
  - `시점_풍속_m_s`
  - `시점_습도_pct`
  - `풍향_sin`, `풍향_cos`
  - `서풍계열_여부`
  - `시점_현지기압_hPa`
  - `시점_해면기압_hPa`
  - `기압변동_3h`
- 선행 풍속:
  - `직전24h_평균풍속`, `직전24h_최대풍속`
  - `직전48h_평균풍속`, `직전48h_최대풍속`
- 선행 기온:
  - `직전24h_평균기온_C`
- 선행 습도:
  - `직전24h_평균습도`, `직전24h_최소습도`
  - `직전48h_평균습도`, `직전48h_최소습도`
  - `D-1_평균습도_pct`, `D-1_최소습도_pct`
  - `D-2_최소습도_pct`, `D-3_최소습도_pct`
- 선행 강수:
  - `직전24h_강수량합`, `직전48h_강수량합`
  - `D-1_강수량합_mm`

### 4-2. 공통 공간 변수

- `기후지형유형`: one-hot encoding
- `고도(m)`
- `경사도(도)`
- `사면방향_sin`, `사면방향_cos`
- `TPI(지형위치지수)`
- 거리 변수:
  - 도로, 시가화, 농업, 임도, 등산로, 산림 최단거리
  - 거리 변수는 `log1p` 변환 후 사용한다.
  - 원거리 극단값 영향을 줄이기 위해 필요하면 train fold의 상위 99.5%에서 winsorizing한다.

현재 데이터의 `시가화_최단거리_m`과 `농업_최단거리_m`의 절대 상관은 약 0.988이다. 두 변수를 동시에 사용한 비정규화 오즈비 모델은 불안정할 가능성이 높으므로, 성능 모델에서는 L2/Elastic Net으로 처리하고 축소 오즈비 모델에서는 EDA 우선순위가 높은 시가화 거리를 우선 유지한다.

### 4-3. 시간 문맥 변수

월과 시간대는 실제 운영 시점에 알 수 있는 변수이지만 0-B2의 균등 시간 샘플링을 쉽게 구분할 수 있다.

- 기본 모델: `월_sin`, `월_cos`, `시간_sin`, `시간_cos` 포함
- 민감도 모델: 시간 문맥 변수 제외
- 전체 성능뿐 아니라 0-A, 0-B1, 0-B2별 성능을 따로 보고 시간 문맥이 쉬운 0-B2만 구분하는지 확인한다.

### 4-4. FA 요인점수

- `F1_score`
- `F2_score`
- `F3_score`
- `F4_score`
- `F5_score`

FA 점수는 원본 날씨·공간 변수의 선형결합이다. 원변수와 FA 점수를 함께 넣으면 새 정보가 거의 추가되지 않으며 다중공선성이 커질 수 있다.

- Set 1의 성능 비교에는 요청대로 원변수와 FA를 함께 사용한다.
- Set 1은 L2 또는 Elastic Net으로만 안정적으로 적합한다.
- Set 1의 개별 원변수와 FA 오즈비를 동시에 해석하지 않는다.
- 오즈비 해석은 `원변수 축소 모델`과 `FA 중심 압축 모델`을 별도로 만든다.

### 4-5. 캐나다 산불지수

시간 누수를 수정한 다음 아래 연속형 지수를 사용한다.

- `FFMC`
- `FFMC_10일평균`
- `DMC`
- `DC`
- `ISI`
- `BUI`
- `FWI`

`Indexed_FFMC`와 `FFMC_논문식_발생확률`은 같은 단계값의 결정적 변환이라 동시에 넣지 않는다. 두 변수는 선행연구 식 재현용 단변량 benchmark에서만 사용한다.

## 5. 기본 비교 실험

### 5-1. 요청한 세 모델

## 6. 로지스틱 회귀 후보

### 6-1. L2 로지스틱

- 기본 성능 모델
- 다중공선성이 강한 날씨 시간창과 거리 변수의 계수를 안정화한다.
- `C`를 inner grouped CV로 조정한다.
- 예상상 가장 안정적인 로지스틱 기준 모델이다.

### 6-2. L1 로지스틱

- 중요도가 낮거나 중복된 변수 계수를 0으로 만들어 희소 모델을 만든다.
- 변수 선택 결과는 단일 split이 아니라 반복 grouped CV의 선택 빈도로 평가한다.
- 상관이 높은 변수 중 하나를 임의로 선택할 수 있으므로 “선택되지 않음 = 중요하지 않음”으로 단정하지 않는다.

### 6-3. Elastic Net 로지스틱

- L1의 변수 선택과 L2의 안정화를 절충한다.
- `C`와 `l1_ratio`를 inner grouped CV로 조정한다.
- 최종 성능·간결성 균형 후보로 우선 검토한다.

### 6-4. 비정규화 축소 로지스틱

- 오즈비, 95% CI, 계수 부호를 명확하게 보고하기 위한 해석 모델이다.
- L1/Elastic Net 안정성 선택과 EDA 사전가설을 통과한 축소 변수만 사용한다.
- 연속형 변수는 표준화하여 `1 SD 증가당 OR`을 기본 보고한다.
- 실무 단위가 중요한 변수는 추가로 `습도 5%p 감소`, `풍속 1m/s 증가`, `도로거리 10m 또는 log-distance 변화` 기준 OR을 변환해 제시한다.

### 6-5. 비선형·상호작용 로지스틱

선형 로지스틱이 놓칠 수 있는 임계치와 EDA 가설을 다음과 같이 제한적으로 추가한다.

- spline 후보:
  - `직전24h_최소습도`
  - `직전24h_강수량합`
  - `직전24h_최대풍속`
  - `log1p_도로_최단거리_m`
  - `FWI`
- 사전 지정 상호작용:
  - `기후지형유형 × 직전24h_평균풍속`
  - `기후지형유형 × 직전24h_최소습도`
  - `영동 해안형 × 서풍계열_여부`
  - `직전24h_최소습도 × 직전24h_최대풍속`

상호작용은 EDA에서 이미 확인한 메커니즘만 사용하고 전 변수 간 자동 조합은 하지 않는다. 비선형 모델의 해석은 단일 계수 OR 대신 예측확률 곡선과 기준값 대비 OR 곡선으로 제시한다.

## 7. 단계적 변수 축소 방법

단순 p-value 기반 stepwise selection을 주 방법으로 사용하지 않는다. 같은 데이터에서 변수를 반복 제거하면 계수와 p-value가 낙관적으로 편향되고, 상관 변수 중 선택 결과가 불안정해진다.

다음 순서로 축소한다.

### 단계 0. 누수·식별자 제거

샘플 생성 메타데이터, ID, 좌표, 원문 시각, Target을 제거한다.

### 단계 1. 결정적 중복 제거

- 원거리 변수와 log 변환 변수를 동시에 사용하지 않는다.
- `Indexed_FFMC`와 `FFMC_논문식_발생확률`을 캐나다 연속 지수와 동시에 사용하지 않는다.
- 같은 날 미래 캐나다 지수를 제거한다.

### 단계 2. 상관 블록 정리

현재 확인된 높은 상관 예:

- `직전24h_평균풍속` vs `직전48h_평균풍속`: 0.929
- `직전24h_평균습도` vs `직전48h_평균습도`: 0.922
- `직전48h_평균습도` vs `D-1_평균습도_pct`: 0.959
- `시점_기온_C` vs `직전24h_평균기온_C`: 0.881
- `직전24h_최소습도` vs `D-1_최소습도_pct`: 0.879
- `직전24h_최대풍속` vs `직전48h_최대풍속`: 0.856

성능 모델에서는 L2/Elastic Net이 처리하도록 둘 수 있다. 오즈비 모델에서는 EDA와 예측시점 적합성을 기준으로 각 상관 블록에서 대표 변수를 선택한다.

### 단계 3. 블록 제거 비교

다음 블록을 하나씩 제거해 AUPRC, calibration, hard-negative 성능 변화를 측정한다.

- 현재 시점 날씨
- 선행 습도
- 선행 풍속
- 선행 강수
- 지형
- 접근성 거리
- 시간 문맥
- FA
- 캐나다 지수

이 비교는 “어떤 변수군이 실제 성능을 만드는가”를 보여주며 개별 변수 p-value보다 최종 보고서와 연결하기 쉽다.

### 단계 4. L1/Elastic Net 안정성 선택

- 반복 grouped CV에서 비영 계수 선택 빈도를 계산한다.
- 선택 빈도 70% 이상을 핵심 후보, 40~70%를 보조 후보, 40% 미만을 불안정 후보로 표시한다.
- 계수 부호가 fold마다 바뀌는 변수는 다중공선성 또는 상호작용 가능성으로 표시한다.

### 단계 5. 축소 모델 재적합

- 안정성 선택 변수와 EDA 필수 변수를 결합한다.
- VIF, 계수 부호, bootstrap CI를 확인한다.
- 변수를 제거했을 때 AUPRC가 유지되고 calibration이 개선되면 더 단순한 모델을 선택한다.

## 8. 데이터 분할과 검증

### 8-1. 금지 방식

- 단순 `train_test_split(..., stratify=Target)` 행 분할
- 전체 데이터에서 먼저 scaling한 뒤 CV
- 전체 데이터에서 변수 선택 후 test 평가
- train/test 분할 전에 SMOTE 또는 undersampling
- 동일 `원본_fire_id`의 Target 1과 0-A를 다른 fold에 배치

### 8-2. 기본 검증 구조

1. 최종 lockbox test: 그룹 기준 약 20%
2. 나머지 80%에서 grouped nested CV
   - outer CV: 5-fold `StratifiedGroupKFold`
   - inner CV: 4-fold `StratifiedGroupKFold`
3. scaling, one-hot encoding, winsorizing, feature selection, regularization 튜닝은 모두 inner train fold 안에서 수행한다.
4. 모델 세트와 알고리즘은 정확히 같은 fold를 사용해 paired comparison한다.

그룹 키:

- Target 1 및 0-A: `source_fire_id` (`원본_fire_id`와 `fire_id`를 결합해 생성)
- 0-B1/0-B2: `후보점ID`

### 8-3. 추가 스트레스 테스트

- 기후지형유형별 성능
- Target 1 vs 0-A
- Target 1 vs 0-B1
- Target 1 vs 0-B2
- 2020년/2021년별 성능
- 오전/오후별 성능
- 산불위험계절(11~5월)/기타계절별 성능
- 시간 문맥 변수 포함/제외
- class weight 적용/미적용
- 캐나다 D-1 정책/최신 가용 정오 정책

엄격한 미래연도 성능을 최종 검증하려면 향후 네거티브 샘플링을 연도 split 이후에 다시 수행해야 한다. 현재 0-A는 2020·2021 양쪽에서 추출돼 있어 단순 연도 분할만으로는 완전한 미래 검증이 되지 않는다.

## 9. 클래스 불균형 처리

기본 비교:

- `class_weight=None`
- `class_weight="balanced"`

두 결과를 모두 확인하되 최종 threshold는 validation 데이터에서 운영 목적에 맞게 선택한다.

SMOTE는 기본안에서 사용하지 않는다. 공간·시간·기상 변수를 임의 보간하면 존재하지 않는 시공간 조합을 만들 수 있고, grouped CV 전에 적용하면 누수가 생긴다. 필요하면 모든 기본 비교가 끝난 뒤 train fold 내부에서만 민감도로 검토한다.

## 10. 평가 지표

F1, 정확도, 정밀도, 재현율, AUROC만으로는 충분하지 않다.

### 10-1. 핵심 순위 성능

- **AUPRC(PR-AUC): 주 지표**
  - 클래스 불균형에 적합하다.
  - 전체 데이터의 무작위 기준 AUPRC는 양성 비율인 약 0.091이다.
- AUROC: 보조 지표

### 10-2. 확률 품질

- Log loss
- Brier score
- Calibration intercept
- Calibration slope
- Calibration curve

확률 기반 전신주 위험순위를 사용할 예정이므로 calibration 평가는 필수이다.

### 10-3. 임계값 기반 지표

- Accuracy
- F1-score
- Precision
- Recall
- Specificity
- Balanced accuracy
- MCC
- Confusion matrix

정확도는 보조값으로만 보고한다.

모든 단계별 결과 요약에는 다음 세 threshold의 전체 지표표를 반드시 포함한다.

- 고정 threshold 0.5
- development OOF에서 F1이 최대가 되는 threshold
- development OOF에서 Recall 90%를 만족하는 최대 threshold

각 표에는 Accuracy, Balanced accuracy, Precision, Recall, Specificity, F1, MCC와 `TN/FP/FN/TP`를 모두 적는다. ROC AUC와 AUPRC는 threshold와 무관한 별도 표에 적어 두 평가 종류를 혼합하지 않는다.

### 10-4. 운영 목적 지표

- Recall 90%를 만족하는 threshold에서 precision
- 고위험 상위 1%, 5%, 10%의 positive capture rate
- Precision@K 또는 Recall@K
- 필요하면 decision curve의 net benefit

threshold는 test에서 고르지 않고 validation fold에서 결정한 뒤 lockbox test에 고정 적용한다.

### 10-5. 불확실성

- outer fold별 평균, 표준편차
- grouped bootstrap 95% CI
- 같은 fold를 사용한 모델 간 paired metric difference

M1과 M2의 차이는 각각의 AUPRC만 나열하지 않고 `ΔAUPRC`, `ΔAUROC`, `ΔBrier`와 신뢰구간으로 판단한다.

## 11. Bias-Variance 확인

F1, 정확도, AUC만으로 bias-variance trade-off를 판단할 수 없다. 다음 진단을 함께 사용한다.

- train score와 validation score 차이
- 학습 표본 수에 따른 learning curve
- fold 및 반복 split 간 성능 분산
- regularization strength에 따른 validation curve
- L1/Elastic Net의 변수 선택 빈도
- 로지스틱 계수 부호와 크기의 bootstrap 안정성
- 기후지형유형·연도·negative type별 성능 편차

판단 예:

- train과 validation이 모두 낮음: 높은 bias 또는 피처 부족
- train은 높고 validation이 낮음: 높은 variance 또는 누수성 패턴 의존
- 평균 성능은 높지만 fold 분산이 큼: 특정 날짜·권역·샘플유형 의존
- AUC는 높지만 Brier/calibration이 나쁨: 순위는 맞지만 확률은 신뢰하기 어려움

## 12. 오즈비 분석 계획

### 12-1. 보고 모델 분리

1. `OR-Raw`: 축소 원본 날씨·공간 변수 모델
2. `OR-FA`: FA 점수 중심 압축 모델
3. `OR-Canadian`: 안전한 캐나다 지수 중심 모델
4. 사전 지정 상호작용 모델

원변수와 그 선형결합인 FA 점수를 한 모델에 모두 넣은 상태의 개별 OR은 핵심 결과로 보고하지 않는다.

### 12-2. 보고 항목

- 회귀계수
- OR
- bootstrap 또는 cluster-robust 95% CI
- 표준화 연속형 변수의 1 SD 증가당 OR
- 실무 단위 변환 OR
- L1/Elastic Net 선택 빈도
- fold별 부호 일치율
- 다중 검정이 필요한 경우 BH-FDR q-value

penalized logistic의 계수는 성능과 변수 안정성 평가에 사용하고, 전통적 p-value는 축소 비정규화 모델에서만 보조적으로 제시한다.

| 24~48시간 저습이 핵심 | 24/48h 평균·최소습도, D-1 최소습도, F1, FFMC | 습도가 낮을수록 위험 증가, 시간창 중 대표 변수가 안정적으로 선택되는지 확인 |
| 강수량보다 무강수·누적 건조 | 24/48h 강수, D-1 강수, F3, DMC/DC/BUI | 강수부족 블록 제거 시 AUPRC 저하 여부 |
| 영동 해안형에서 강풍 신호 | 기후지형유형×풍속, 영동×서풍, ISI/FWI | 전체 평균보다 영동 상호작용이 중요한지 확인 |
| 저습×강풍 결합 | 최소습도×최대풍속, ISI/FWI | 단순 주효과보다 상호작용·비선형 모델 개선 여부 |
| 영서 내륙형은 건조 주도 | 기후지형유형×습도/강수 | 영서에서 건조 변수 효과가 유지되는지 확인 |
| 고지·산간형은 최소습도 하강 | 기후지형유형×최소습도 | 고지·산간형의 조건부 건조 효과 확인 |
| 도로 초접경이 가장 강한 공간 신호 | log 도로거리, 시가화거리 | 거리가 가까울수록 위험 증가, 공간 블록 제거 시 성능 저하 |
| 저고도·완경사·하부 사면 편향 | 고도, 경사, TPI | 계수 방향과 비선형 곡선을 EDA와 비교 |
| 월·시간대 집중 | 월/시간 cyclic 변수 | 쉬운 0-B2 구분 효과인지 0-A에서도 남는지 확인 |

### 현재 학습데이터에 없는 EDA 핵심 변수

다음 EDA 변수는 현재 최종 학습데이터에 직접 들어 있지 않다.

- `rh_local_q05`
- `dry_spell_0p1_gt_24h`
- `dry_spell_5p0_gt_240h`
- 48~72시간 강수량
- 6시간 평균·최대풍속
- 24시간 최대풍속 시점의 서풍계열 여부
- 실제 토지피복과 WUI 접경 범주

1차 모델은 현재 변수로 수행하되, EDA 결론을 직접 모델링하려면 위 변수를 누수 없이 추가한 2차 피처 확장 모델을 별도로 비교한다. 특히 `rh_local_q05`, 무강수 지속, 6시간 최대풍속은 EDA에서 효과가 안정적이었으므로 우선 추가 후보이다.

## 14. 로지스틱 계열 통계모델 추가 비교

### 기본 비교 모델

- L2 로지스틱: 기준선
- L1 로지스틱: 변수 제거와 sparse 해석 후보
- Elastic Net 로지스틱: L1 변수선택과 L2 안정화 절충
- class-weight/cost-sensitive 로지스틱: 0-A 또는 재현율 중심 운영 후보
- spline/GAM logistic: 습도·풍속·거리 변수의 비선형 임계치 후보
- GEE 또는 cluster-robust GLM: 날짜·기상셀 군집 상관을 반영한 추론 후보
- 혼합효과 로지스틱: 기상셀/시군/날짜 random effect 후보

### 공정 비교 원칙

- 동일한 M1/M2/M3 변수 세트
- 동일한 grouped fold
- 동일한 lockbox test
- 동일한 누수 제거와 캐나다 지수 가용시점 정책
- 동일한 평가 지표와 threshold 선택 규칙
- 튜닝은 inner CV에서만 수행

### 통계모델 추가 진단

- 계수 부호 안정성
- 선택 빈도
- 표준화 OR과 실무 단위 OR
- cluster-robust 95% CI와 p/q-value
- calibration slope/intercept
- restricted cubic spline 또는 GAM smooth의 형태
- 0-A 전용/가중 로지스틱의 민감도

## 15. 최종 모델 선택 기준

### FA 파트 유지 여부

5단계 grouped nested CV에서 M1과 M2의 전체 OOF AUPRC 차이는 `-0.000036`, outer-fold paired AUPRC 차이는 평균 `+0.00026`으로 사실상 0이었다. 이에 따라 6단계 이후 주 모델에서는 FA 요인점수를 제외한다.

제외 근거:

- 전체 AUPRC, AUROC, Brier score가 M2와 실질적으로 동일했다.
- hard negative인 Target 0-A에서도 개선이 없었다.
- FA는 원본 변수의 선형결합이므로 원본 변수와 함께 투입하면 중복성과 계수 불안정만 늘릴 가능성이 있다.

M1 결과는 FA 추가 효과가 없었다는 비교 근거로만 보존하고, 이후 정규화·변수 축소·로지스틱 계열 확장은 M2와 M3 계열로 진행한다.

### 캐나다 지수 유지 여부

M2와 M3를 비교한다.

- 안전한 D-1 지수에서도 개선되는가?
- 0-A와 0-B1에서 개선되는가?
- FFMC/FWI 중 일부 지수만 안정적으로 선택되는가?
- calibration과 기후지형유형별 성능이 개선되는가?

같은 날 12시 누수 버전에서만 성능이 높으면 캐나다 지수의 유효성으로 인정하지 않는다.

### 최종 로지스틱 후보 선택

- AUPRC 개선이 있어도 0-A, calibration, 계수 안정성이 악화되면 주 모델로 채택하지 않는다.
- L1/Elastic Net이 성능을 유지하면서 변수 수를 줄이면 해석 모델 후보로 우선한다.
- class-weight 모델은 운영 threshold 후보로만 쓰고, 오즈비 해석은 비가중 모델을 우선한다.
- spline/GAM logistic이 비선형 임계치를 안정적으로 보이면 보고서의 임계치 해석에 활용한다.

최종 선택은 한 지표의 최고값이 아니라 성능, calibration, 안정성, 해석성의 교환비로 결정한다.

## 17. 실행 순서

1. `샘플ID`로 그룹 메타데이터 복원
2. 캐나다 지수를 D-1 또는 최신 가용 정오 기준으로 재병합
3. 누수 변수 제거 및 M1/M2/M3 feature manifest 고정
4. group lockbox와 nested CV split 저장
5. Dummy와 L2 logistic baseline 실행
6. L1/Elastic Net 튜닝과 변수 안정성 분석
7. 블록 제거 및 상호작용·spline 비교
8. 축소 OR 모델과 bootstrap CI 산출
9. class-weight/cost-sensitive/spline/GEE 후보를 같은 fold에서 비교
10. calibration 및 운영 threshold 평가
11. FA 제거 여부, 캐나다 지수 유지 여부, 최종 로지스틱 후보 확정
12. `final_eda.md` 결론과 일치·불일치·추가 발견을 최종 보고서에 연결

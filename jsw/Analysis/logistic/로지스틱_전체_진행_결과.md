# 강원도 산불 로지스틱 모델링 전체 진행 결과

이 문서는 `jsw/Analysis/logistic`에서 진행한 로지스틱 기반 이진분류 작업을 처음부터 Step17까지 한 번에 읽을 수 있도록 정리한 요약본이다. 상세 실행 로그는 `LOG.md`, 단계별 산출물은 `outputs/` 아래에 있다.

## 0. 전체 결론

최종적으로 로지스틱 모델은 두 역할로 분리했다.

| 용도 | 최종 모델 | 이유 |
|---|---|---|
| 머신러닝 모델과 성능 비교 | `PLUS_LANDCOVER_RULES_ANOVA` | strict CV 기준 대표 성능 모델. AUPRC 0.2398, ROC AUC 0.7768, F1 0.3047 |
| 최종 보고서 오즈비·해석 | `FINAL_REDUCED_WITH_FWI` | AUPRC 0.2590으로 높고 max VIF 2.27이라 계수 해석이 안정적 |

최종 판단은 다음과 같다.

- 요인점수는 최종 주 모델에서 제외한다.
- 캐나다 산불지수는 전체 지수를 동시에 넣지 않고 `D1_FWI` 단독을 해석용 보조 종합지수로 사용한다.
- 토지피복 세부 범주는 성능에는 도움을 줄 수 있지만 공선성·희소범주 문제가 있어 최종 오즈비 해석에는 쓰지 않는다.
- 로지스틱은 산불 발생을 “정확히 맞히는 운영 예측기”라기보다, 산불 발생 노출에서 반복적으로 나타나는 건조도·무강수·풍속·도로접근성·FWI의 조건부 연관성을 정량화하는 통계 모델로 해석한다.
- 최종 lockbox test는 열지 않았다. 모든 결과는 development 내부 OOF 또는 development 전체 적합 기준이다.

## 1. 초기 계획 수립

처음에는 사용자가 요청한 세 변수 구성을 비교하는 것에서 출발했다.

| 비교 세트 | 구성 | 목적 |
|---|---|---|
| Set 1 | 날씨·공간 + 요인점수 + 캐나다 산불지수 | 요인점수가 추가 성능을 주는지 확인 |
| Set 2 | 날씨·공간 + 캐나다 산불지수 | 요인점수 제거 가능성 확인 |
| Set 3 | 날씨·공간 | 캐나다 지수의 추가 기여 확인 |

평가 지표는 처음부터 AUPRC를 주 지표로 두었다. 이유는 Target 1 비율이 약 9.1%인 불균형 자료라 accuracy만 보면 산불을 거의 못 잡아도 좋아 보일 수 있기 때문이다. 동시에 ROC AUC, Brier, log loss, F1, precision, recall, accuracy, balanced accuracy를 함께 산출하도록 계획했다.

또한 성능 모델과 해석 모델은 분리하기로 했다. 성능이 가장 높은 정규화/선택 모델의 계수를 바로 오즈비로 해석하면 안 되기 때문이다.

## 2. Step1. 캐나다 지수 시간 누수 수정

### 수행 내용

- 원본 `학습데이터_최종_캐나다지수.csv`에는 같은 날 12시 캐나다 지수가 날짜 기준으로 병합되어 있었다.
- 기준시각이 12시 이전인 행에서는 같은 날 12시 지수가 미래 정보가 될 수 있으므로 시간 누수 가능성이 있었다.
- 기존 같은 날 캐나다 지수 9개는 모델 입력에서 제거했다.
- 모든 표본에 D-1 정오 기준 `FFMC`, `FFMC_10일평균`, `DMC`, `DC`, `ISI`, `BUI`, `FWI`를 다시 병합했다.

### 결과

- 전체 행 수: 17,045
- Target 1: 1,553
- Target 0: 15,492
- D-1 지수 결측: 0
- 모든 지수 기준 날짜가 기준 날짜보다 정확히 1일 이전임을 확인했다.

### 판단

최종 로지스틱 모델에서는 같은 날 12시 캐나다 지수를 사용하지 않고 D-1 지수만 사용한다.

## 5. Step4. 그룹 기반 검증 분할 고정

### 수행 내용

- 전체 데이터를 development와 lockbox test로 분리했다.
- lockbox는 이후 어떤 모델 선택에도 사용하지 않았다.
- development 내부에는 grouped outer 5-fold를 만들고, 각 outer training 안에 grouped inner 4-fold를 만들었다.

### 결과

| 구분 | 행 수 | Target 1 | 양성률 | 그룹 수 |
|---|---:|---:|---:|---:|
| development | 13,632 | 1,242 | 9.1109% | 7,444 |
| lockbox test | 3,413 | 311 | 9.1122% | 1,863 |

Outer fold 양성률도 약 9.09~9.13%로 균형이 맞았다.

검증 결과:

- development와 lockbox 그룹 중복: 0
- outer fold 간 그룹 분할 위반: 0
- inner fold 간 그룹 분할 위반: 0

### 판단

이 분할은 이후 초기 모델링의 기본 분할이 되었지만, 나중에 날짜·기상노출 단위 누수 가능성을 확인하면서 Step7.5에서 더 엄격한 CV를 추가했다.

## 6. Step5. L2 로지스틱 기준 모델 학습

### 수행 내용

- development 13,632행만 사용했다.
- lockbox는 열지 않았다.
- Dummy, M1, M2, M3를 grouped outer 5-fold OOF로 비교했다.
- inner fold에서 `C ∈ {0.01, 0.1, 1, 10}`을 선택했다.

### 전체 OOF 성능

| 모델 | AUPRC | ROC AUC | Brier | Log loss |
|---|---:|---:|---:|---:|
| Dummy | 0.0910 | 0.4995 | 0.08281 | 0.30510 |
| M1 원본+FA+캐나다 | 0.3335 | 0.7877 | 0.07200 | 0.25624 |
| M2 원본+캐나다 | 0.3335 | 0.7877 | 0.07200 | 0.25623 |
| M3 원본 | 0.2765 | 0.7661 | 0.07494 | 0.26562 |

### 핵심 결과

- M1과 M2의 AUPRC 차이: -0.000036
- M2는 M3보다 AUPRC가 +0.0570 높았다.
- M2는 M3보다 Brier도 낮았다.
- M2의 F1 최적 threshold는 0.2258, precision 0.3440, recall 0.3720, F1 0.3574였다.

### 판단

- FA 요인점수는 원본 변수와 캐나다 지수가 있을 때 추가 예측력을 거의 만들지 못했다.
- D-1 캐나다 지수는 날씨·공간만 쓴 모델보다 성능을 분명히 개선했다.
- 기준모델은 M2로 두고 Step6에서 L1/L2/Elastic Net/class weight를 비교했다.

## 7. Step6. 정규화·class weight·캐나다 지수 조합 비교

### 수행 내용

- FA 요인점수는 제외하고 진행했다.
- L1, L2, Elastic Net, class weight, 캐나다 지수 조합을 비교했다.

### 결과

- `L2_none`이 AUPRC와 Brier 기준 가장 안정적이었다.
- L1과 Elastic Net의 AUPRC 차이는 약 0.0015 이내로 작았다.
- class-weight balanced 모델은 ROC AUC는 조금 높았지만 AUPRC와 Brier가 크게 악화됐다.
- 전체 7개 D-1 캐나다 지수는 캐나다 지수 미사용보다 AUPRC +0.0576, 0-A AUPRC +0.0594 개선을 보였다.

### 판단

- 정규화 방식을 바꿔도 성능 개선 폭은 작았다.
- class weight 조정만으로는 성능이 좋아지지 않고 확률 보정이 악화됐다.
- 이후 주 모델에서는 FA 요인점수를 제외하고 `날씨·공간 + D-1 캐나다 지수` 흐름을 유지했다.
- 성능 한계는 정규화 방식보다 비선형성, 권역별 이질성, 부족한 EDA 기반 피처에서 올 가능성이 크다고 판단했다.

## 8. Step7. EDA 기반 피처 확장

### 수행 내용

EDA 결론을 반영해 다음 피처를 추가했다.

- 국지 저습 조건
- 6시간 풍속 요약
- 무강수 지속
- 저습×풍속
- 영동×풍속
- 도로접근성 관련 조건
- 일부 EDA 기반 상호작용

FA 요인점수는 계속 제외했다.

### 결과

| 모델 | AUPRC | ROC AUC | Brier | Log loss |
|---|---:|---:|---:|---:|
| Step6 기준모델 | 약 0.3339 | - | - | - |
| Step7 추천모델 | 0.3751 | 0.7953 | 0.06982 | 0.24956 |

추가 결과:

- 기준모델 대비 AUPRC +0.0412
- F1 최적 threshold 0.2499
- precision 0.3976
- recall 0.3470
- F1 0.3706
- 0-A AUPRC 0.4088

### 판단

- EDA 기반 피처는 기존 L2 기준모델보다 위험순위화 성능을 개선했다.
- 전체 상호작용까지 넣은 모델은 AUPRC가 0.3759로 아주 조금 더 높았지만, 추천 세트 대비 +0.0008뿐이라 과도한 상호작용은 채택하지 않았다.
- 다만 이 시점의 CV는 동일 날짜·기상노출이 fold 사이에 나뉠 수 있어 성능이 낙관적일 수 있다고 판단했다.

## 9. Step8. D2/D3 토지피복·임상도 보강

### 수행 내용

- `학습데이터_로지스틱_D1.csv`에 토지피복 D2와 임상도 D3 보조 데이터를 붙여 `학습데이터_로지스틱_D2D3.csv`를 만들었다.

- 임상도 매칭:
  - 미매칭: 17,017

### 성능 결과

|---|---:|---:|---:|---:|
| STAGE7_RECOMMENDED | 0.3751 | 0.7953 | 0.06982 | 0.24956 |
| PLUS_LANDCOVER | 0.3952 | 0.8294 | 0.06818 | 0.23683 |

### 해석

- 임상도는 매칭이 28건뿐이라 실질적인 변수로 쓰기 어렵다.

- 토지피복은 0-B1/0-B2 같은 공간 배경 대조군 구분에는 매우 강했지만, 0-A처럼 같은 위치의 다른 시간대를 구분하는 데는 도움이 작았다.

### 판단

토지피복은 “어디가 산불 발생 공간에 가까운가”를 설명하는 데 유용하지만, “언제 발생하는가”를 설명하는 시간적 신호로는 제한적이다.

## 10. Step7.5. 날짜·기상노출 단위 strict CV 재검증

### 수행 내용

기존 grouped CV가 낙관적일 수 있어 더 엄격한 CV를 만들었다.

- `exposure_component_cv`: 같은 `기상셀ID × 기준시각`을 연결 성분으로 묶음
- `date_exposure_component_cv`: 날짜와 기상노출까지 함께 묶음

이후 주 검증 기준은 더 엄격한 `date_exposure_component_cv`로 잡았다.

### 결과

| CV 전략 | 모델 | AUPRC | ROC AUC | Brier | Log loss |
|---|---|---:|---:|---:|---:|
| 기존 grouped CV | STAGE7_RECOMMENDED | 0.3751 | 0.7953 | 0.06982 | 0.24956 |
| 기존 grouped CV | PLUS_LANDCOVER | 0.3952 | 0.8294 | 0.06818 | 0.23683 |
| strict date_exposure CV | STAGE7_RECOMMENDED | 0.1961 | 0.7315 | 0.07975 | 0.28293 |
| strict date_exposure CV | PLUS_LANDCOVER | 0.2300 | 0.7763 | 0.07757 | 0.26772 |

### 판단

- strict CV에서 성능이 크게 하락했다.
- 기존 점수에는 날짜·기상노출 공유 효과가 있었을 가능성이 크다.
- 그럼에도 토지피복 보강 모델 `PLUS_LANDCOVER`의 상대 우위는 유지됐다.
- 이후 성능 비교는 strict `date_exposure_component_cv`를 기준으로 진행했다.

## 11. Step9. 로지스틱 추가 개선 실험

### 수행 내용

- strict `date_exposure_component_cv`를 그대로 사용했다.
- `PLUS_LANDCOVER`를 기준으로 규칙 기반 파생변수, ANOVA 선택, 추가 상호작용 후보를 시험했다.

### 결과

- 최고 후보: `PLUS_LANDCOVER_RULES_ANOVA`
- AUPRC: 0.2398
- ROC AUC: 0.7768
- `PLUS_LANDCOVER` 대비 AUPRC 변화: +0.0098
- 0-A AUPRC: 0.2500

### 판단

strict CV 기준에서 추가 개선 폭은 크지 않았지만, `PLUS_LANDCOVER_RULES_ANOVA`가 대표 성능 후보로 올라왔다.

## 12. Step10. 경량 로지스틱 계열 통계모델 확장

### 수행 내용

- 비통계적 머신러닝 모델은 제외했다.
- strict CV 기준으로 L2, Elastic Net, class-weight, 0-A 가중, 경량 상호작용 모델을 비교했다.
- 오래 걸리는 spline/GAM은 제외하고 빠른 OOF 스크리닝만 수행했다.

### 결과

| 모델 | AUPRC | ROC AUC | Brier | Log loss |
|---|---:|---:|---:|---:|
| PLUS_LANDCOVER_RULES_ANOVA | 0.2398 | 0.7768 | 0.07697 | 0.26589 |
| PLUS_LANDCOVER | 0.2300 | 0.7763 | 0.07757 | 0.26772 |
| LOGIT_LIGHT_INTERACTIONS_L2_C1 | 0.2295 | 0.7742 | 0.07815 | 0.26943 |
| LOGIT_ELASTICNET_C1_L1R05 | 0.2286 | 0.7760 | 0.07776 | 0.26808 |
| LOGIT_BALANCED_L2_C1 | 0.2155 | 0.7767 | 0.20480 | 0.58947 |

F1은 `PLUS_LANDCOVER`가 0.3063으로 근소하게 가장 높았다. AUPRC, Brier, 0-A AUPRC는 `PLUS_LANDCOVER_RULES_ANOVA`가 가장 좋았다.

### 판단

- class-weight와 0-A 가중 모델은 확률 보정이 나빠져 최종 대표 모델로 쓰지 않았다.
- Elastic Net은 성능을 유지했지만 대표 모델을 대체할 정도의 개선은 없었다.

   - AUPRC, ROC AUC, Brier, log loss, F1, precision, recall, accuracy, balanced accuracy를 모두 제시한다.

   - `FINAL_REDUCED_WITH_FWI`의 OR, 95% CI, q-value를 사용한다.
   - 성능 모델의 계수를 오즈비로 해석하지 않는다.

3. EDA와 연결
   - 습도·무강수·풍속·도로접근성·FWI가 EDA와 로지스틱에서 같은 방향으로 남았다고 쓴다.
   - 서풍계열 단독은 유의하지 않았으므로 “서풍 자체”보다 “영동·저습·풍속 결합”으로 설명한다.

4. 한계
   - lockbox test는 아직 열지 않았다.
   - 표본은 음성이 많은 불균형 자료라 accuracy 단독 해석은 부적절하다.
   - F1 0.30 수준이므로 산불 발생 시점을 고정밀로 맞히는 모델이라고 쓰면 안 된다.
   - 로지스틱 결과는 관찰자료의 조건부 연관성이지 인과 효과가 아니다.

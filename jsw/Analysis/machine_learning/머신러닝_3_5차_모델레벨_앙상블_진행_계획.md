# 머신러닝 3.5차 모델 레벨 앙상블 진행 계획

## 1. 목적

3차에서 수행한 작업은 1차 OOF prediction을 재사용한 blending 진단이었다. 이 결과는 어떤 모델 조합이 유망한지 확인하는 데에는 유효하지만, lockbox에 바로 적용할 수 있는 최종 앙상블 파이프라인은 아니다.

3.5차의 목적은 base model을 실제로 다시 학습하고, 각 모델의 validation 예측을 결합하는 model-level ensemble 파이프라인을 만드는 것이다.

## 2. 핵심 차이

| 구분 | 3차 OOF blending | 3.5차 model-level ensemble |
|---|---|---|
| base model 학습 | 새로 하지 않음 | 각 outer fold에서 다시 학습 |
| 입력 | 1차 저장 OOF score | 원 데이터 + feature set + selected config |
| 앙상블 방식 | 저장된 score 결합 | 재학습 모델들의 validation score 결합 |
| lockbox 적용 가능성 | 직접 적용 어려움 | full development 재학습 후 적용 가능 |
| 해석 | 조합 가능성 진단 | 최종 후보 파이프라인 검증 |

## 3. 사용할 base model

1차 strict OOF에서 로지스틱 기준선을 명확히 넘고, 3차 blending에서도 유망했던 top5 primary 모델을 사용한다.

| candidate_id | feature_set | model | 역할 |
|---|---|---|---|
| `PL_HGB` | `PLUS_LANDCOVER` | `HistGradientBoosting` | 1차 최고 anchor |
| `RULES_HGB` | `PLUS_LANDCOVER_RULES_ANOVA_PROXY` | `HistGradientBoosting` | 규칙 proxy 계열 |
| `PL_LGBM` | `PLUS_LANDCOVER` | `LightGBM` | ROC/recall 보조 |
| `RULES_RF` | `PLUS_LANDCOVER_RULES_ANOVA_PROXY` | `RandomForest` | bagging 다양성 |
| `RULES_XGB` | `PLUS_LANDCOVER_RULES_ANOVA_PROXY` | `XGBoost` | boosting 다양성 |

각 모델의 하이퍼파라미터는 1차에서 fold별 inner CV로 선택된 `ml_stage1_v2_selected_configs.csv`를 그대로 사용한다. 3.5차에서는 Optuna 재튜닝을 하지 않는다.

## 4. 학습 구조

각 outer fold마다 다음을 수행한다.

1. outer train row로 base model 5개를 각각 학습한다.
2. outer validation row에 대해 base model별 확률 score를 만든다.
3. 같은 validation row에서 ensemble score를 만든다.
4. 모든 outer fold validation score를 합쳐 strict OOF 성능을 평가한다.

lockbox row는 학습, weight 선택, OOF 평가에 사용하지 않는다.

## 5. 앙상블 후보

3차 결과에서 실질적으로 성능이 좋았던 단순 조합을 중심으로 확인한다.

| ensemble_id | 방식 | 비고 |
|---|---|---|
| `model_level_top5_average` | 산술 평균 | 기본 후보 |
| `model_level_top5_geometric_mean` | 기하 평균 | 3차 보고서용 후보와 대응 |
| `model_level_top5_logit_average` | logit 평균 | 극단 확률 완화 |
| `model_level_top5_rank_average` | rank 평균 | 순위 성능 진단용, 확률 품질 해석 주의 |
| `model_level_top5_perf_weighted` | 1차 AUPRC 비례 가중 평균 | 고정 weight |
| `model_level_anchor50_lgbm30_xgb20` | HGB 0.50 + LGBM 0.30 + XGB 0.20 | 3차 상위 fixed weight 후보 |

## 6. 평가 지표

로지스틱 및 1차/3차와 같은 지표를 산출한다.

- AUPRC
- ROC AUC
- Brier
- log loss
- best-F1
- fixed 0.50
- recall >= 0.50 / 0.70 / 0.90
- top 5/10/20% capture
- hard-negative subgroup: 0A/0B1/0B2
- 기후지형유형 subgroup
- fold별 성능

## 7. 성공 기준

| 기준 | 값 |
|---|---:|
| 1차 최고 기준 | AUPRC 0.2984 |
| 최소 성공선 | AUPRC 0.3034 이상 |
| 강한 성공선 | AUPRC 0.3100 이상 |
| 보고서용 확률 후보 | AUPRC 0.3034 이상이면서 Brier/log loss가 1차 최고와 비슷하거나 개선 |

rank average가 AUPRC 최고가 되더라도, 확률 score 자체가 calibrated probability가 아니므로 최종 운영 후보는 geometric mean, average, weighted average 중에서 우선 검토한다.

## 8. full development 재학습

OOF 평가 후 lockbox-ready 상태를 만들기 위해 full development 전체로 base model 5개를 다시 학습한다.

산출:

- base model artifact
- feature set/config manifest
- 최종 ensemble recipe

단, lockbox 평가는 Step4/Step5에서 별도로 수행한다.

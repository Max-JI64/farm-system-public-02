## 10. 결과 해석

이번 1차 v2 결과는 로지스틱 대비 명확한 개선이 확인된 screening이다. 기준 로지스틱 `PLUS_LANDCOVER_RULES_ANOVA`의 AUPRC는 0.2398이었고, 최고 ML 후보인 `PLUS_LANDCOVER / HistGradientBoosting / raw`는 AUPRC 0.2984를 기록했다. 절대 개선폭은 +0.0586이고, 상대적으로는 약 24.4% 개선이다. ROC AUC도 0.7768에서 0.8123으로 올랐고, Brier와 log loss도 낮아져서 단순히 순위 지표만 오른 것이 아니라 확률 품질도 함께 좋아졌다.

개선의 핵심은 "모델만 ML로 바꾼 것"이 아니라 "로지스틱 최종 분석에서 유효했던 피처 구조를 비선형 모델이 더 잘 활용한 것"이다. M1/M2/M3 진단 실험에서는 M1 RandomForest가 AUPRC 0.2601로 기준선을 넘었지만 개선폭은 +0.0203에 그쳤다. 반면 Stage7 파생 피처에 토지피복을 더한 `PLUS_LANDCOVER`에서는 HistGradientBoosting이 +0.0586까지 올라갔다. 따라서 2차의 중심은 M1/M2/M3 재비교가 아니라 로지스틱 최종 결과에서 얻은 피처 자산을 ML이 어떻게 더 확장할지에 둬야 한다.

`PLUS_LANDCOVER_RULES_ANOVA_PROXY`도 좋은 후보였지만, 최고 성능은 `PLUS_LANDCOVER`가 냈다. 이는 로지스틱에서는 명시적인 규칙/ANOVA 축약이 도움이 되었더라도, 트리 부스팅 모델에서는 Stage7+토지피복 원 피처만으로도 임계값과 상호작용을 직접 학습할 수 있음을 뜻한다. 1차 기준으로는 규칙 피처를 무조건 추가하기보다 `PLUS_LANDCOVER`를 주 후보로 두고, 규칙/ANOVA proxy는 보조 후보로 유지하는 편이 타당하다.

모델별로는 HistGradientBoosting이 AUPRC 최상위이고, LightGBM은 ROC AUC와 best-F1/recall 쪽이 강하다. XGBoost는 누락된 것이 아니라 모든 피처셋에서 실행됐고, 특히 `PLUS_LANDCOVER_RULES_ANOVA_PROXY`에서 AUPRC 0.2801, ROC AUC 0.8138, Brier 0.07333, log loss 0.24817로 확률 지표가 좋았다. 다만 `PLUS_LANDCOVER`에서는 약했기 때문에 2차에서는 XGBoost를 버리기보다 규칙/ANOVA proxy 조합을 중심으로 튜닝 후보에 포함하는 것이 적절하다.

운영 관점에서는 fixed 0.50 임계값은 너무 보수적이다. precision은 0.7374로 높지만 recall이 0.0588에 그쳐 실제 양성의 대부분을 놓친다. best-F1 운영점은 threshold 0.1096에서 recall 0.5564, precision 0.2476이고, recall 0.70 운영점은 threshold 0.0743에서 recall 0.7005, precision 0.2216이다. 산불 위험 선별 목적이라면 0.50 고정값보다 best-F1 또는 recall 0.70 수준의 운영점이 더 현실적이다.

Top-risk capture는 모델이 순위화 도구로 의미가 있음을 보여준다. 개발셋 양성률은 9.1%인데, 상위 5% 위험군의 precision은 32.1%로 기본 양성률의 3.52배이고, 상위 10%만 보아도 전체 양성의 31.3%를 포착한다. 상위 20%에서는 양성의 54.3%를 포착하므로, 자원 제한 상황에서 우선 감시 지역을 정하는 용도로 활용 가능성이 있다.

Hard-negative에서는 `Target_0B1`, `Target_0B2` 구분 성능이 매우 높고, `Target_0A`가 여전히 가장 어렵다. 이는 모델이 쉬운 배경 음성은 잘 분리하지만, 실제 양성과 시간/공간적으로 가까운 0A 음성에서는 아직 혼동이 남아 있다는 뜻이다. 2차에서는 전체 AUPRC뿐 아니라 0A subgroup 성능을 함께 보면서, 단순 배경 분리 성능이 아니라 실제 발생 전조를 더 잘 잡는 방향으로 튜닝해야 한다.

Calibration 결과는 raw score가 AUPRC 기준으로 가장 좋고, calibrated score는 일부 Brier/log loss를 개선하더라도 ranking 성능은 낮아졌다. 1차 결론은 raw score를 모델 선택 기준으로 사용하고, calibration은 최종 후보가 정해진 뒤 3차에서 lockbox 평가와 함께 다시 결정하는 것이다.

따라서 2차 후보는 `PLUS_LANDCOVER / HistGradientBoosting`을 1순위로 두고, `PLUS_LANDCOVER / LightGBM`, `PLUS_LANDCOVER_RULES_ANOVA_PROXY / HistGradientBoosting`, `PLUS_LANDCOVER_RULES_ANOVA_PROXY / RandomForest`, `PLUS_LANDCOVER_RULES_ANOVA_PROXY / XGBoost`를 튜닝 후보로 유지한다. M1 RandomForest는 로지스틱 M1/M2/M3 비교의 진단 기준선으로 남기되, 최종 성능 개선의 주축으로 보기는 어렵다.

- Step6 최종 모델 `model_level_top5_geometric_mean / raw`가 어떤 방식으로 위험 샘플을 구분하는지 해석했다.
- 성능 개선이나 후보 재선택이 아니라 최종 보고서용 설명 근거를 만드는 단계다.
- lockbox 결과는 해석에만 사용했고, 추가 튜닝에는 사용하지 않았다.

## 2. Score decile

- lockbox top 10% decile은 341개 샘플 중 Target 1이 180개였다.
- top 10% positive rate는 0.5279, lift는 5.79, 누적 capture는 0.5788이다.
- lockbox top 30%까지 누적하면 Target 1 278/311개를 포착해 capture 0.8939를 기록했다.
- development OOF에서도 top 10% positive rate 0.2891, 누적 capture 0.3172로 risk ranking이 유지됐다.

## 3. Threshold 오류분석

- Step6 권장 threshold 0.09195를 그대로 적용했다.
- lockbox 결과는 TP 217, FP 329, FN 94, TN 2773이다.
- FP는 대부분 Target_0A에서 발생했다. 이는 실제 화재와 가장 가까운 hard negative이므로, 운영 threshold에서 어느 정도 남는 오탐으로 해석하는 것이 적절하다.

## 4. Base model agreement

- lockbox에서 5개 base model이 모두 threshold 이상으로 판단한 샘플은 259개였고, 양성률은 0.6139였다.
- 0개 base model만 threshold 미만인 샘플의 양성률은 0.0090이었다.
- 따라서 최종 앙상블의 고위험 판단은 단일 모델의 우연보다는 여러 base model의 합의가 강할수록 위험도가 높아지는 형태로 해석할 수 있다.

## 5. Native feature importance

- `feature_importances_`를 제공하는 LightGBM, RandomForest, XGBoost 3개 모델에서 원 피처 단위 중요도를 집계했다.
- HistGradientBoosting 2개 모델은 native feature importance를 제공하지 않아 제외했다.
- 상위 피처는 `D1_DC`, `토지피복_L1_NAME`, `D1_FFMC_10일평균`, `D-1_평균습도_pct`, `log1p_도로거리_m`, `비산림WUI_x_dry0p1`, `D-1_최소습도_pct`, `D1_BUI`, `직전24h_최소습도`, `rh_minus_local_q05` 순이었다.
- 이 중요도는 모델 내부 분할 중요도이므로 인과 효과나 독립적인 변수 영향으로 해석하지 않는다.

# 머신러닝 8차 전체결과 정리/해석/분석

## 1. 목적

- 지금까지 진행한 로지스틱 기준선 및 ML Step1~7 결과를 하나의 최종 분석 흐름으로 정리했다.
- 단계별 결과, 해석, 최종 선택 근거, 운영 방식, 오류분석, 중요 피처, 보고서 작성 시 주의점을 함께 정리했다.

## 2. 최종 결론

- 최종 보고서/운영 threshold 모델은 `model_level_top5_geometric_mean / raw`이다.
- 이 모델은 `PL_HGB`, `RULES_HGB`, `PL_LGBM`, `RULES_RF`, `RULES_XGB` 5개 base model의 예측을 geometric mean으로 결합한 model-level ensemble이다.
- development OOF AUPRC는 0.3034로, 로지스틱 비교 기준선 AUPRC 0.2398 대비 +0.0636 개선됐다.
- 1차 단일 ML 최고 AUPRC 0.2984 대비로도 +0.0050 개선됐다.
- lockbox test에서는 AUPRC 0.6288, ROC AUC 0.9105, Brier 0.05972, log loss 0.20333을 기록했다.

## 3. 단계별 판단

- 로지스틱 Stage17: ML 비교 기준선 AUPRC 0.2398 확정.
- ML Step1: `PLUS_LANDCOVER / HistGradientBoosting`이 단일 ML 최고 AUPRC 0.2984를 기록해 로지스틱 대비 개선 확인.
- ML Step2: Optuna 최고 후보 AUPRC 0.2687로 1차 최고보다 낮아 미채택.
- ML Step3: OOF prediction-level ensemble으로 앙상블 가능성 확인.
- ML Step3.5: 실제 model-level ensemble로 전환. `geometric_mean`은 확률/threshold 후보, `rank_average`는 순위 보조로 분리.
- ML Step4: calibration 비교 후 raw geometric mean을 최종 probability score로 고정.
- ML Step5: 고정 후보를 lockbox에 최초 적용. 추가 튜닝 없이 최종 성능으로 정리.
- ML Step6: 최종 보고서용 비교표와 운영 threshold 정리.
- ML Step7: score decile, 오류분석, base model agreement, native feature importance 산출.

## 4. 운영 해석

- 권장 threshold는 `recall_ge_0.70`, threshold 0.09195이다.
- lockbox 기준 precision 0.3974, recall 0.6977, selected rate 0.1600이다.
- lockbox top 10%에서는 Target 1 capture 0.5788, precision 0.5263을 기록했다.
- lockbox top 30% decile 누적 capture는 0.8939이다.

## 5. 해석상 주의점

- lockbox 성능이 development OOF보다 높지만, 이를 “일반화 성능이 OOF보다 높다”라고 단정하지 않는다.
- lockbox는 고정 후보의 최초 평가 결과이며, 후보 재선택이나 하이퍼파라미터 튜닝에 사용하지 않았다.
- `model_level_top5_rank_average / raw`는 AUPRC가 높지만 Brier/log loss가 나빠 확률 또는 threshold 운영에는 사용하지 않는다.
- native feature importance는 모델 내부 분할 중요도이므로 인과 효과로 해석하지 않는다.

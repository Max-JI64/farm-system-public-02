# 머신러닝 8차 전체결과 정리/해석/분석 계획

## 1. 목적

- 로지스틱 기준선부터 머신러닝 1차~7차까지의 결과를 하나의 최종 분석 문서로 정리한다.
- 단순 결과 나열이 아니라, 어떤 단계에서 무엇을 확인했고 왜 다음 단계로 넘어갔는지 해석한다.
- 최종 모델 선택 근거, 성능 의미, 운영 threshold, top-risk 활용, 오류분석, 중요 피처, 보고서 작성 시 주의점을 함께 정리한다.

## 2. 정리 범위

- 로지스틱 Stage17 기준선
- 머신러닝 1차: M1/M2/M3 및 전체 모델 스크리닝
- 머신러닝 2차: Optuna 튜닝 결과와 미채택 이유
- 머신러닝 3차: OOF prediction-level ensemble 진단
- 머신러닝 3.5차: 실제 model-level ensemble
- 머신러닝 4차: calibration 및 최종 후보 고정
- 머신러닝 5차: lockbox 최초 평가
- 머신러닝 6차: 최종 보고서용 비교표 정리
- 머신러닝 7차: 최종 모델 해석/오류분석

## 3. 핵심 질문

1. 로지스틱 대비 머신러닝이 실제로 개선됐는가?
2. 1차 스크리닝에서 어떤 모델/피처셋이 강했는가?
3. 2차 Optuna 튜닝은 왜 최종 모델로 이어지지 않았는가?
4. 앙상블은 어떤 형태가 최종 후보가 되었는가?
5. lockbox 결과를 어떻게 해석해야 하는가?
6. 운영 threshold와 top-risk screening 중 어떤 방식이 보고서에 적합한가?
7. 최종 모델은 어떤 신호를 주로 사용했는가?
8. 최종 보고서에서 조심해서 써야 할 표현은 무엇인가?

## 4. 출력

- `outputs/ml_stage8_comprehensive_analysis.md`
- `머신러닝_8차_전체결과_정리_해석_분석.md`
- `outputs/metrics/ml_stage8_stage_timeline.csv`
- `outputs/metrics/ml_stage8_key_metric_summary.csv`
- `outputs/metrics/ml_stage8_report_claims.csv`
- `outputs/metrics/ml_stage8_validation_checks.csv`

## 5. 검증

- 최종 모델 의사결정 파일이 존재하는지 확인한다.
- development OOF와 lockbox 최종 성능이 모두 포함됐는지 확인한다.
- 1차~7차 핵심 산출물의 필수 입력 파일을 모두 읽었는지 확인한다.
- 보고서에서 lockbox를 재튜닝 근거로 해석하지 않도록 주의 문구를 포함한다.

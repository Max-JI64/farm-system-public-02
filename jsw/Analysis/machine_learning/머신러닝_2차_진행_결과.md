# 머신러닝 2차 결과

## 1. 실행 목적

- 1차에서 성능 근거가 확인된 후보를 Optuna로 집중 튜닝했다.
- lockbox test는 사용하지 않았고, 1차와 같은 strict development OOF 기준으로 평가했다.
- 주 지표는 raw AUPRC이며, hard-negative 0A, top-risk capture, Brier/log loss를 보조 판단축으로 사용했다.

## 2. 실행 설정

- main 후보 pilot trials per outer: 4
- auxiliary 후보 trials per outer: 2
- focused top-N: 2
- focused 추가 trials per outer: 4
- calibration top-N: 3

## 3. 기준선

- 로지스틱 기준선 AUPRC: 0.2398
- 1차 최고 AUPRC: 0.2984
- 2차 성공선 AUPRC: 0.3034

## 4. 2차 최고 후보

- `PLUS_LANDCOVER_RULES_ANOVA_PROXY / HistGradientBoosting / raw`
- AUPRC 0.2200, ROC AUC 0.7467, Brier 0.13507, log loss 0.40192

## 12. 결과 해석

full 2차 최고 후보는 `PLUS_LANDCOVER_RULES_ANOVA_PROXY / HistGradientBoosting`이지만, AUPRC는 0.2200으로 로지스틱 기준선 0.2398보다 낮고 1차 최고 0.2984보다도 크게 낮다. 로지스틱 기준선 대비 AUPRC 변화는 -0.0198이고, 1차 최고 대비 변화는 -0.0784이다. 따라서 2차 Optuna 튜닝 결과는 성공으로 채택하지 않는다. 현재까지의 최종 최고 모델은 1차의 `PLUS_LANDCOVER / HistGradientBoosting / raw`로 유지한다.

2위 후보는 `PLUS_LANDCOVER / XGBoost`이며 AUPRC 0.2181로 1위와의 차이는 0.0020이다. 후보 간 차이는 작지만 전체적으로 1차 상위 모델군보다 낮다. 특히 1차에서 강했던 `PLUS_LANDCOVER / HistGradientBoosting`이 2차 튜닝 후 AUPRC 0.2033까지 떨어졌기 때문에, 이번 Optuna 탐색 공간과 inner-CV 선택 방식이 1차 기본 설정보다 좋은 방향으로 작동하지 않았다고 해석한다.

Top 10% 위험군에서는 전체 양성의 29.1%를 포착했고, precision은 26.5%, lift는 2.91배였다. 1차 최고 모델의 top 10% capture가 31.3%였으므로, 위험도 순위화 관점에서도 2차 full 결과가 1차를 넘지 못했다. 0A hard-negative AUPRC는 0.2356으로, 1차 최고 모델의 0A AUPRC 0.3069보다 낮다.

결론적으로 2차 full 실행은 파이프라인과 Optuna 실행 자체는 검증했지만, 성능 개선에는 실패했다. 다음 단계는 이 결과를 3차로 바로 넘기는 것이 아니라, 2차 재설계로 보는 것이 맞다. 재설계 방향은 1차 최고 설정을 중심으로 탐색 공간을 좁히고, 1차 기본 파라미터를 Optuna 후보에 seed로 포함하며, fold별 inner objective와 outer OOF 괴리를 줄이는 것이다.

# 머신러닝 2차 진행 계획

## 1. 기본 방향

2차의 목적은 1차에서 확인한 최고 후보를 넓게 다시 비교하는 것이 아니라, 성능이 나온 후보를 집중 튜닝해서 strict development OOF AUPRC를 더 끌어올리는 것이다.

1차 최고 결과는 `PLUS_LANDCOVER / HistGradientBoosting / raw`이고 AUPRC는 0.2984였다. 2차의 1차 목표는 이 값을 넘기는 것이며, 최종 로지스틱 기준선 AUPRC 0.2398 대비 개선폭을 더 안정적으로 확보하는 것이다.

핵심 원칙은 다음과 같다.

1. lockbox test는 열지 않는다.
2. 데이터, split, 평가 지표는 1차와 동일하게 유지한다.
3. Optuna 기반 하이퍼파라미터 튜닝을 도입한다.
4. 모든 모델을 다시 전수 탐색하지 않고, 1차에서 성능 근거가 있는 후보만 튜닝한다.
5. AUPRC를 주지표로 하되, `Target_0A` hard-negative, top-risk capture, Brier/log loss를 함께 본다.
6. calibration은 최종 선택 기준이 아니라 보조 비교로만 유지한다.

## 2. 1차 결과에서 가져올 판단

| 구분 | 1차 결과 | 2차 반영 |
|---|---:|---|
| 기준 로지스틱 AUPRC | 0.2398 | 모든 ML 개선폭의 기준선 |
| 1차 최고 AUPRC | 0.2984 | 2차에서 넘어야 할 내부 기준선 |
| 최고 조합 | `PLUS_LANDCOVER / HistGradientBoosting` | 2차 1순위 튜닝 후보 |
| LightGBM | AUPRC 0.2878, ROC AUC 0.8163, recall 강함 | 2차 주요 튜닝 후보 |
| 규칙/ANOVA proxy HGB | AUPRC 0.2902 | 보조 주력 후보 |
| 규칙/ANOVA proxy RF | AUPRC 0.2826, Brier 0.0739 | 안정적인 bagging 후보 |
| 규칙/ANOVA proxy XGBoost | AUPRC 0.2801, log loss 0.2482 | XGBoost 대표 튜닝 후보 |

1차 결과상 성능 개선은 M1/M2/M3 자체보다 로지스틱 최종 분석에서 얻은 Stage7 파생 피처와 토지피복을 ML이 비선형으로 활용할 때 크게 발생했다. 따라서 2차의 중심은 M1/M2/M3 재비교가 아니라 `PLUS_LANDCOVER`와 `PLUS_LANDCOVER_RULES_ANOVA_PROXY`의 튜닝이다.

| feature_set | model | 목적 |

## 5. Optuna 튜닝 구조

각 후보는 1차와 같은 strict nested CV 구조를 유지한다.

1. outer validation fold는 최종 OOF 평가 구간으로 보존한다.
2. outer-train 내부의 inner CV에서 Optuna를 수행한다.
3. trial objective는 inner fold 평균 AUPRC로 둔다.
4. Optuna가 선택한 best params로 outer-train 전체를 재학습한다.
5. outer-validation에 대해 raw OOF score를 만든다.
6. 모든 outer fold 예측을 합쳐 development OOF 지표를 산출한다.

튜닝 budget은 계산 시간을 고려해 2단계로 나눈다.

| 단계 | 대상 | trial 수 | 목적 |
|---|---|---:|---|
| 2A pilot | 주 후보 5개 | outer fold당 25~40 | 넓은 탐색, 비효율 후보 제거 |
| 2B focused | 2A 상위 2~3개 | outer fold당 60~100 | 최종 후보 성능 극대화 |
| 보조 확인 | M1 RF, PL XGBoost | outer fold당 15~25 | 참고 성능 확인 |

2A 결과에서 1차 최고 AUPRC 0.2984를 넘지 못하더라도 바로 중단하지 않는다. fold별 성능 분산, 0A subgroup, top-risk capture가 좋아졌다면 2B 후보로 유지한다.

## 6. 모델별 탐색 공간

### 6-1. HistGradientBoosting

탐색 대상:

- `learning_rate`
- `max_iter`
- `max_leaf_nodes`
- `max_depth`
- `min_samples_leaf`
- `l2_regularization`
- `max_bins`
- `class_weight`
- `early_stopping`

튜닝 방향:

- 1차 최고 후보이므로 가장 넓게 탐색한다.
- 과적합을 막기 위해 `min_samples_leaf`, `l2_regularization`, `max_leaf_nodes`를 적극적으로 조절한다.
- raw AUPRC가 1차보다 높아지는지 우선 확인한다.

### 6-2. LightGBM

탐색 대상:

- `n_estimators`
- `learning_rate`
- `num_leaves`
- `max_depth`
- `min_child_samples`
- `subsample`
- `colsample_bytree`
- `reg_alpha`
- `reg_lambda`
- `min_split_gain`
- `class_weight` 또는 `scale_pos_weight`

튜닝 방향:

- 1차에서 ROC AUC와 recall이 좋았으므로 AUPRC를 올리면서 recall 장점을 유지하는 방향으로 탐색한다.
- `num_leaves`, `min_child_samples`, `reg_lambda`를 통해 fold 안정성을 확인한다.
- early stopping은 inner validation fold 기준으로만 사용한다.

### 6-3. XGBoost

탐색 대상:

- `n_estimators`
- `learning_rate`
- `max_depth`
- `min_child_weight`
- `subsample`
- `colsample_bytree`
- `gamma`
- `reg_alpha`
- `reg_lambda`
- `scale_pos_weight`
- `max_delta_step`

튜닝 방향:

- 1차에서 `PLUS_LANDCOVER_RULES_ANOVA_PROXY` 조합의 log loss와 Brier가 좋았으므로 이 조합을 주로 튜닝한다.
- `PLUS_LANDCOVER` 조합은 보조 확인으로만 둔다.
- `eval_metric`은 `aucpr`와 `logloss`를 함께 저장하되 objective 선택은 AUPRC로 한다.

### 6-4. RandomForest

탐색 대상:

- `n_estimators`
- `max_depth`
- `min_samples_split`
- `min_samples_leaf`
- `max_features`
- `bootstrap`
- `max_samples`
- `class_weight`

튜닝 방향:

- 극단적인 성능 최고점보다는 안정적인 bagging 기준선으로 활용한다.
- `PLUS_LANDCOVER_RULES_ANOVA_PROXY`를 주 튜닝 대상으로 둔다.
- M1 RandomForest는 낮은 budget으로 진단 기준선만 갱신한다.

## 7. 피처 확장 계획

2차의 주 작업은 하이퍼파라미터 튜닝이지만, 1차 해석을 반영한 제한적 피처 확장도 함께 검토한다. 새 피처는 모두 기존 development 데이터에서 계산 가능한 것만 사용하고, lockbox 정보나 target 정보를 사용하지 않는다.

### 7-1. 기본 피처셋

우선 다음 두 세트를 그대로 튜닝한다.

- `PLUS_LANDCOVER`
- `PLUS_LANDCOVER_RULES_ANOVA_PROXY`

### 7-2. 제한적 확장 피처셋

튜닝이 끝난 뒤, 상위 모델 1~2개에 대해서만 다음 확장 버전을 비교한다.

| feature_set | 구성 | 목적 |
|---|---|---|
| `PLUS_LANDCOVER_TUNED_BASE` | 1차 `PLUS_LANDCOVER` 그대로 | 튜닝 효과만 분리 확인 |
| `PLUS_LANDCOVER_INTERACTIONS_V1` | 캐나다지수·FWI류 × 토지피복, 날씨 rolling × 건조/바람 지표 | 비선형 상호작용 보강 |
| `PLUS_LANDCOVER_0A_FOCUSED` | 0A hard-negative에서 유효한 피처 중심으로 축약/확장 | 쉬운 배경 음성 분리 의존도 완화 |

피처 확장은 모델 튜닝보다 후순위다. 튜닝으로 1차 최고 AUPRC를 충분히 넘으면 확장 피처는 2차 후반부 또는 3차 후보로 넘긴다.

## 9. 선택 기준

2차 최종 후보는 raw strict OOF AUPRC가 가장 높은 조합으로 정한다.

다만 AUPRC 차이가 `0.005` 이내면 다음 순서로 판단한다.

1. `Target_1 vs Target_0A` AUPRC
2. top 10%, top 20% capture
3. Brier와 log loss
4. fold별 AUPRC 표준편차
5. best-F1와 recall 0.70 운영점
6. calibration 이후 확률 품질

2차 목표선은 다음과 같이 둔다.

| 기준 | 값 | 의미 |
|---|---:|---|
| 로지스틱 기준선 | AUPRC 0.2398 | 반드시 넘어야 하는 외부 기준 |
| 1차 최고 | AUPRC 0.2984 | 2차에서 넘어야 할 내부 기준 |
| 2차 성공선 | AUPRC 0.3034 이상 | 1차 대비 +0.005 이상 |
| 2차 강한 성공선 | AUPRC 0.3100 이상 | 최종 후보로 강하게 채택 가능 |

## 10. Calibration 방침

2차의 모델 선택 기준은 raw AUPRC다.

Calibration은 다음 방식으로만 보조 비교한다.

- 2차 상위 2~3개 조합에만 적용
- `sigmoid`, `isotonic` 비교
- calibrated score와 raw score를 모두 저장
- AUPRC 순위가 크게 낮아지면 calibrated score를 최종 ranking score로 사용하지 않음
- 최종 calibration 확정은 3차 lockbox 직전 또는 lockbox 평가 단계로 넘김

## 11. 해석 산출물

2차는 성능 튜닝 단계지만, 최종 보고서에 쓸 수 있는 해석 자료도 같이 만든다.

- permutation importance 또는 모델별 built-in importance
- 상위 후보의 fold별 성능 분포
- top-risk 구간별 실제 양성 포착 사례 요약
- 0A hard-negative에서 높은 점수를 받은 false positive 진단
- 1차 최고 후보 대비 score 변화 분포

SHAP은 계산 시간이 크면 2차 필수 산출물로 두지 않는다. 필요하면 3차 최종 후보 1~2개에 대해서만 별도 계산한다.

## 14. 3차로 넘길 기준

2차 종료 후 3차 후보는 최대 2~3개로 줄인다.

3차로 넘길 후보:

- 2차 raw AUPRC 1위
- 2차 AUPRC가 1위와 `0.005` 이내이면서 0A 또는 top-risk가 더 좋은 후보
- calibration 후 Brier/log loss가 뚜렷하게 좋은 후보

3차에서는 최종 후보 앙상블, calibration 확정, lockbox test 평가, 최종 보고서 표 생성을 진행한다.

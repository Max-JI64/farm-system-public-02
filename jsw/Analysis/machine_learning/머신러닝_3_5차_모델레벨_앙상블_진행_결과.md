# 머신러닝 3.5차 모델 레벨 앙상블 결과

## 1. 실행 목적

- 3차 OOF blending 진단을 실제 재학습 가능한 model-level ensemble 파이프라인으로 전환했다.
- 각 outer fold에서 base model 5개를 다시 학습한 뒤, 해당 validation fold 예측을 합쳐 strict OOF 앙상블 성능을 계산했다.
- lockbox test는 사용하지 않았다.

## 2. 기준선

- 로지스틱 Stage17 기준선 AUPRC: 0.2398
- 1차 ML 최고 AUPRC: 0.2984

## 3. 최고 결과

- AUPRC 최고: `ENSEMBLE_MODEL_LEVEL / model_level_top5_rank_average / raw`
- AUPRC 0.3068, ROC AUC 0.8187, Brier 0.27510, log loss 0.80025
- 1차 최고 대비 ΔAUPRC +0.0084, 로지스틱 대비 ΔAUPRC +0.0670

rank average는 순위 성능 진단용이다. 확률 품질까지 고려한 보고서용 후보는 다음으로 둔다.

- 보고서용 후보: `ENSEMBLE_MODEL_LEVEL / model_level_top5_geometric_mean / raw`
- AUPRC 0.3034, ROC AUC 0.8178, Brier 0.07328, log loss 0.24994
- 1차 최고 대비 ΔAUPRC +0.0050

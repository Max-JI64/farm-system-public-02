# 강원_재_EDA 진행 계획

이 문서는 데이터 누수 문제를 해결하고 새로 산출된 캐나다 산불위험지수(CFFDRS)를 포함하여 강원도 산불 탐색적 데이터 분석(EDA)을 재진행하기 위한 세부 계획입니다. 

## 1. 개요 및 배경

- **데이터 누수 문제 해결**: 이전 EDA에서는 산불 발생일 전체를 요약한 일단위 기상 변수(`당일_최대순간풍속_m_s`, `평균기온_C` 등)를 사용하여 산불 발생 시점 이후의 미래 정보가 포함되는 누수가 있었습니다. 재_EDA에서는 기준시각 이전의 관측값만을 사용하여 이 문제를 완전히 해결합니다.
- **캐나다 산불위험지수 도입**: 강원도 기상 특성에 맞춰 생성된 캐나다 산불지수(FFMC, DMC, DC, ISI, BUI, FWI)를 핵심 파생 변수로 추가해, 단순 기상 변수와 비교하며 산불 발생 위험과의 연관성을 탐색합니다.

## 2. 데이터 누수 방지 원칙 및 변수 교체 가이드

이전 노트북에서 사용하던 당일/일단위 요약 기상 변수는 아래와 같이 기준시각 이전 또는 정각 관측 시간단위 변수로 전면 교체하여 EDA를 수행합니다.

| 분류          | 누수 가능 변수 (사용 금지)      | 대체 변수 (재 EDA 적용)                                                          |
| ------------- | ------------------------------- | -------------------------------------------------------------------------------- |
| **기온**      | `평균기온_C`, `최저/최고기온_C` | `시점_기온_C`, `직전24h_평균기온_C`                                              |
| **풍속/풍향** | `당일_최대순간풍속_m_s`         | `시점_풍속_m_s`, `직전24h_최대풍속`, `직전24h_평균풍속`, `직전48h_최대/평균풍속` |
| **습도**      | 일별 `평균습도`, 당일 최저습도  | `시점_습도_pct`, `직전24h_최소습도`, `직전24h_평균습도`, `D-1_최소습도_pct`      |
| **강수량**    | 발생일 당일 `강수량_mm`         | `직전24h_강수량합`, `직전48h_강수량합`, `D-1_강수량합_mm`                        |

## 3. 캐나다 산불위험지수 활용 방안

- **캐나다 지수 체계의 의미**
  - **FFMC (미세연료수분지수)**: 표면의 낙엽, 잔가지 등 미세연료의 건조도. 산불의 **발화(Ignition) 가능성**을 직접적으로 나타냅니다.
  - **DMC (부식층수분지수)**: 중간 깊이 유기물층의 누적 건조도를 나타냅니다.
  - **DC (가뭄지수)**: 깊은 유기물층의 장기 건조도를 나타내며, 장기 가뭄 지표로 쓰입니다.
  - **ISI (초기확산지수)**: FFMC와 풍속을 결합해 산불 발생 초기의 **확산 속도**를 나타냅니다.
  - **BUI (누적연료건조도)**: DMC와 DC를 결합해 연소 가능한 전체 연료량을 나타냅니다.
  - **FWI (화재기상지수)**: ISI와 BUI를 결합해 산불의 최종적인 예상 **강도(Intensity)** 및 종합적 위험을 나타냅니다.

- **활용 변수 선택**: 
  6가지 변수(`FFMC`, `DMC`, `DC`, `ISI`, `BUI`, `FWI`)를 EDA에서 모두 활용하여 기후지형유형별/계절별 분포를 확인합니다. 하지만 주요 분석 및 임계치 도출은 산불 발생 가능성을 가장 직관적으로 보여주는 **`FFMC` (발화 위험)**, 바람 효과가 결합된 **`ISI` (초기 확산 속도)**, 그리고 종합 산불 위험을 나타내는 **`FWI` (종합 위험도)** 세 가지에 집중할 계획입니다.

## 4. 재_EDA에 사용될 통합 변수 목록 (기상 및 공간 전체)

데이터 누수가 제거된 전체 EDA 대상 변수 풀은 다음과 같습니다.

- **[기상 변수 - 시점 관측]** `시점_기온_C`, `시점_습도_pct`, `시점_풍속_m_s`, `시점_현지기압_hPa`, `시점_해면기압_hPa`, `시점_풍향_deg`, `풍향_sin`, `풍향_cos`, `서풍계열_여부`, `기압변동_3h`
- **[기상 변수 - 누적/최소/최대 (누수 해결)]** 
  - 풍속: `직전24h_평균풍속`, `직전24h_최대풍속`, `직전48h_평균풍속`, `직전48h_최대풍속`
  - 기온: `직전24h_평균기온_C`
  - 습도: `직전24h_최소습도`, `직전24h_평균습도`, `직전48h_최소습도`, `직전48h_평균습도`, `D-1_최소습도_pct`, `D-1_평균습도_pct`, `D-2_최소습도_pct`, `D-3_최소습도_pct`
  - 강수: `직전24h_강수량합`, `직전48h_강수량합`, `D-1_강수량합_mm`
- **[캐나다 산불지수]** `FFMC`, `DMC`, `DC`, `ISI`, `BUI`, `FWI`
- **[공간 및 지형 변수]**
  - 속성: `기상셀ID`, `기후지형유형`(영동해안형/영서내륙형/고지산간형), `번지유형`(임야번지/일반번지), `토지피복_중분류`(발화 지점의 토지피복 중분류)
  - 지형: `고도(m)`, `경사도(도)`, `사면방향_sin`, `사면방향_cos`, `TPI`(지형위치지수), `TWI`(지형다습지수)
  - 인프라 접근성(최단거리): `도로_최단거리_m`, `시가화_최단거리_m`, `농업_최단거리_m`, `임도_최단거리_m`, `등산로_최단거리_m`, `산림_최단거리_m` (필요시 `log1p` 변환 변수 병행)

## 5. 노트북 구성 및 진행 단계 (세부 데이터 결합 방식 포함)

재_EDA 폴더 내에 순차적으로 노트북을 생성하여 분석을 체계적으로 진행합니다. 

### 📍 `Step1_강원도_날씨및산불지수_기본분석.ipynb`
- **목적**: 누수 없는 기상 파생 변수 및 캐나다 산불지수를 이용해 강원도 기후지형유형별 기후 특성을 재확인
- **데이터 결합 방식**:
  - `data/강원도_날씨데이터/강원도날씨_격자_시간단위.csv` 등 원천 데이터를 불러온 뒤, 시간 순 정렬 후 `shift`와 `rolling` 연산을 직접 적용하여 `직전24h_최소습도`, `직전24h_평균풍속` 등의 파생 변수를 산출한다.
  - `data/강원도_날씨데이터/강원도날씨_기후지형유형_셀분류.csv`를 병합하여 기후지형유형을 부여한다.
  - 단, 캐나다 산불지수는 계산 복잡도를 고려해 예외적으로 `data/학습데이터/캐나다_FWI_일단위.csv` 및 `캐나다_FFMC_선행연구_일단위.csv`를 `기상셀ID + 날짜` 기준으로 병합하여 가져온다.
- **주요 분석 내용**:
  - 강원도 3대 기후지형유형 간 계절적 패턴 차이 재검증
  - 캐나다 산불지수 6종(특히 FFMC, FWI)의 분포 탐색 및 기상 변수와의 상관관계 분석

### 📍 `Step2_강원도_산불발생_누수수정_재분석.ipynb`
- **목적**: 기상 이상성 및 캐나다 산불지수가 실제 산불 발생과 비발생(대조군)을 얼마나 잘 구분하는지 검정
- **데이터 결합 방식 (기존 강원_EDA와 동일한 로직 적용)**:
  - `data/강원도_데이터/강원도_산불발생.csv`를 불러와 산불 좌표를 만들고, `강원도날씨_격자.geojson`과 공간 결합(`sjoin`)하여 `기상셀ID`를 매핑한다.
  - 기존 EDA와 완벽히 동일하게 **전체 비발생**과 **매칭 비발생(동일 기상셀, 월, 시간대 무작위 5개)** 대조군을 노트북 내에서 동적으로 추출한다.
  - 산불 및 대조군 시점에 맞춰 시간단위 기상 원천 데이터(롤링 연산 포함)와 캐나다 산불지수를 병합한다. (누수 방지를 위해 발생일 당일 요약 변수는 제외)
- **주요 분석 내용**:
  - 산불 시점의 기상이 매칭 비발생 시점과 비교해 얼마나 위험한 방향으로 이상성을 띠는지 위험방향 효과크기 계산
  - 누수가 제거된 기상 변수와 `FFMC`, `FWI` 간의 산불 분리 능력 상호 비교

### 📍 `Step3_산불발생_기후공간융합_심화분석.ipynb`
- **목적**: 지형 및 공간 변수와 캐나다 산불지수를 교차하여 복합 산불 발생 임계치 도출
- **데이터 결합 방식 (기존 강원_EDA와 동일한 로직 적용)**:
  - Step 2의 결합 로직에 추가로, 산불 원천 데이터의 `발생지역번지` 문자열을 통해 `임야번지(산)`과 `일반번지`를 구분한다.
  - `data/강원도_데이터/산불_공간데이터/강원도_산불_지형특성계산.csv`를 `fire_id` 기준으로 결합하여 `고도`, `경사도`, `TPI`, `TWI`를 가져온다.
  - 필요시 도로, 임도, 등산로 등의 원천 공간 데이터를 불러와 공간 인덱스(STRtree) 연산을 통해 최단거리를 직접 계산한다.
- **주요 분석 내용**:
  - 임야/일반 번지별 누수 없는 기상 임계치와 캐나다 산불지수 임계치 심층 비교
  - 지형 요인(TPI, TWI)과 산불지수 간의 상호 작용 및 위험 증폭 시너지 분석

- **데이터 추출 방식 원상 복구**: 파이프라인에서 만들어둔 통합 데이터셋(`학습데이터_최종.csv`)을 일괄로 부르지 않습니다. 대신 과거 `강원_EDA`에서 작성한 **"원천 데이터를 하나씩 직접 공간/시간 결합하고 매칭 비발생 대조군을 노트북에서 동적으로 생성하는 코드 로직"**을 그대로 복사하여 사용합니다.

## ⚠️ 공통 필수 규칙: Matplotlib 한글 폰트 설정

모든 EDA 노트북의 첫 번째 코드 셀에는 반드시 아래 코드를 작성하여 한글 깨짐 현상을 방지해야 합니다. 
설정 이후에 `sns.set_theme()`를 단독으로 다시 실행하면 `font.family` 설정이 덮어씌워져 한글이 깨지므로 주의합니다.

```python
import pandas as pd
import matplotlib.pyplot as plt
import matplotlib.font_manager as fm
import seaborn as sns
from pathlib import Path

font_path = "C:/Windows/Fonts/malgun.ttf"
fm.fontManager.addfont(font_path)
font_name = fm.FontProperties(fname=font_path).get_name()

sns.set_theme(
    style="whitegrid",
    font=font_name,
    rc={
        "font.family": font_name,
        "font.sans-serif": [font_name],
        "axes.unicode_minus": False
    }
)

plt.rcParams["font.family"] = font_name
plt.rcParams["font.sans-serif"] = [font_name]
plt.rcParams["axes.unicode_minus"] = False

pd.set_option("display.max_columns", None)
print("현재 matplotlib font.family:", plt.rcParams["font.family"])
print("현재 matplotlib font.sans-serif:", plt.rcParams["font.sans-serif"][:3])
```

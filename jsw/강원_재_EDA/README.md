### 순차 진행 원칙

재 EDA는 **시각화 중심 탐색**으로 진행한다. 각 분석 질문에 대해 분포, 시간 변화,
공간 패턴, 집단 간 겹침과 이상치를 가장 잘 보여주는 핵심 플롯을 먼저 설계하고,
통계표와 검정은 시각적으로 발견한 패턴의 크기와 불확실성을 확인하는 근거로 사용한다.

각 로그의 분석 ID를 다음 순서로 처리한다.

```text
1. 분석 질문과 확인할 시각적 패턴 정의
2. 핵심 플롯과 보조 결과표 코드 작성
3. 코드 실행, 플롯 저장 및 error output 0건 확인
4. 플롯 이미지 직접 검토
5. 결과표·통계검정으로 시각적 패턴의 크기와 불확실성 확인
6. 플롯과 결과표를 함께 사용한 해석 작성
7. 추가 심화 분석 필요 여부 결정
8. 필요하면 현재 ID 아래에 심화 분석 ID를 추가하고 먼저 수행
9. 한계와 다음 분석 코드 반영사항 기록
10. 다음 기본 분석 ID 코드 작성
```

결과표만 검토했거나 플롯만 생성한 상태는 해석 완료로 처리하지 않는다. 현재 분석의 로그에서 `해석`과 `반영`이 완료된 뒤에만 다음 분석 ID로 넘어간다.

### 결과 기반 심화 분석 원칙

초기 계획에 없는 분석이라도 다음 신호가 플롯 또는 결과표에서 확인되면 대응 로그의
`결과 기반 추가 심화 분석 큐`에 새 ID를 추가할 수 있다.

- 분포의 다봉성, 긴 꼬리, 극단값 또는 바닥·천장 효과
- 전체 결과와 권역·계절·번지·고도 층화 결과의 방향 불일치
- 비선형 관계, 임계점, 구간별 기울기 변화
- 지도에서 나타나는 공간 군집, 경계 효과 또는 미매칭 집중
- 결과표의 효과크기는 크지만 분포 겹침도 큰 경우
- 통계적으로 유의하지만 플롯상 실질 차이가 작은 경우
- 대조군 정의, 임계거리, 시간창 변경에 민감한 결과
- 데이터 품질이나 프록시 타당성에 대한 새로운 의문

추가 심화 분석은 `S1-A01`, `S2-A01`과 같이 Step별 `A` ID를 사용하고, 어떤 기본
분석에서 파생되었는지, 추가 이유, 확인할 플롯, 중단 조건을 먼저 기록한다. 단순히
유의한 결과를 더 찾기 위한 반복 검정은 추가 이유로 인정하지 않는다.

## 1. 재 EDA의 핵심 목표

1. 과거 EDA에서 확인한 기후, 날씨, 공간, 지형, 접근성, 원인 프록시 분석을 누락 없이 재현한다.
2. 산불 발생 기준시각 이후의 정보를 포함할 수 있는 당일 전체 기상 집계를 제거한다.
3. `FFMC`, `DMC`, `DC`, `ISI`, `BUI`, `FWI`와 선행연구용 `Indexed_FFMC`를 기존 기상 변수와 비교한다.
4. 동일 기상셀·월·시간대 매칭 비발생 대조군과 공간 대조군을 구분하여 사용한다.
5. 지역별·공간별 임계치 후보와 프록시를 탐색하되, EDA 결과를 인과관계나 확정 원인으로 확대 해석하지 않는다.

## 2. 공통 데이터 계약

### 2-1. 관측 단위와 기준시각

- 산불 및 비발생 비교의 기본 관측 단위는 **`공간점 1개 × 기준시각 1개`**이다.
- 기준시각은 `YYYY-MM-DD HH:00` 단위로 통일한다.
- 산불 사례의 기준시각은 원 발생시각을 정각으로 내림한 값이다.
- 비발생 사례도 같은 형식의 기준시각을 가져야 한다.
- 모든 시간 기상 파생은 `기상셀ID`, `일시` 순으로 정렬한 뒤 계산한다.

### 2-2. 미래 정보 누수 방지

산불 발생 또는 비발생 기준시각을 분석할 때 같은 날짜 전체를 요약한 기상값은 사용하지 않는다.

| 금지 대상 | 문제 | 재 EDA 대체 변수 |
| --- | --- | --- |
| 발생일 전체 평균·최저·최고기온 | 기준시각 이후 기온 포함 가능 | `시점_기온_C`, `직전24h_평균기온_C`, `D-1_*` |
| 발생일 전체 최대순간풍속 | 기준시각 이후 돌풍 포함 가능 | `시점_풍속_m_s`, `직전24h_평균풍속`, `직전24h_최대풍속`, `직전48h_*` |
| 발생일 전체 강수량 | 기준시각 이후 강수 포함 가능 | `직전24h_강수량합`, `직전48h_강수량합`, `D-1_강수량합_mm` |
| 발생일 최저·평균습도 | 기준시각 이후 습도 포함 가능 | `시점_습도_pct`, `직전24h_최소/평균습도`, `직전48h_*`, `D-1~D-3_*` |

공통 허용 변수는 다음과 같다.

- 시점: `시점_기온_C`, `시점_습도_pct`, `시점_풍속_m_s`, `시점_풍향_deg`, `시점_현지기압_hPa`, `시점_해면기압_hPa`
- 직전 시간창: `직전24h_*`, `직전48h_*`, `직전72h_*`
- 이전 날짜: `D-1_*`, `D-2_*`, `D-3_*`
- 정적 공간: 고도, 경사도, 사면방향, TPI, TWI, 토지피복, 인프라 최단거리

`rolling` 변수는 현재 행을 제외하기 위해 반드시 `shift(1)` 후 계산한다. `D-1~D-3`는 시간단위 자료를 날짜별로 집계한 뒤 기준일 이전 날짜만 병합한다.

Step 1의 순수 배경 기후 분석은 산불 기준시각과 결합하지 않는다. 이 단계에서 완결된 날짜의 기후 특성을 설명하기 위한 일교차를 산출할 수 있지만, 해당 값은 Step 2 이후의 산불·비발생 비교 변수로 전달하지 않는다.

### 2-3. 캐나다 지수의 시점 안전 병합

캐나다 지수 산출물은 정오 관측을 기준으로 한 `기상셀ID × 날짜` 자료이다.

- `data/학습데이터/캐나다_FFMC_선행연구_일단위.csv`
- `data/학습데이터/캐나다_FWI_일단위.csv`

산불 및 비발생 기준시각에 같은 날짜의 지수를 무조건 병합하지 않는다. 다음의 as-of 규칙을 적용한다.

```text
기준시각 시 < 12:00  -> 전날 정오 지수
기준시각 시 >= 12:00 -> 당일 정오 지수
```

병합 후 다음 감사 컬럼을 반드시 유지한다.

- `캐나다지수_기준날짜`
- `캐나다지수_기준시각` (`기준날짜 12:00`)
- `캐나다지수_시차시간`
- `캐나다지수_시차일`
- `캐나다지수_당일사용여부`

검증 조건은 `캐나다지수_기준시각 <= 기준시각`이다. 이 조건을 위반한 행이 1건이라도 있으면 분석을 중단한다.

Step 1의 날짜별 배경 분포 분석에서는 정오 날짜 자체를 사용한다. Step 2~6의 사건·대조군 분석에서는 위 as-of 규칙만 사용한다.

### 2-4. 캐나다 지수 해석

| 변수 | 주요 의미 | 재 EDA 역할 |
| --- | --- | --- |
| `FFMC` | 표면 미세연료 건조도와 발화 용이성 | 습도·강수 파생 변수와 비교 |
| `FFMC_10일평균` | FFMC의 최근 10일 누적 상태 | 단기 변동과 지속 건조 구분 |
| `Indexed_FFMC` | 선행연구 기준 4단계 FFMC | 단변량 비교 기준선 |
| `DMC` | 중간 깊이 유기물층 건조 | 중기 누적 건조 |
| `DC` | 깊은 유기물층 장기 건조 | 장기 무강수·가뭄 |
| `ISI` | FFMC와 풍속을 결합한 초기 확산 가능성 | 강풍형 지역 비교 |
| `BUI` | 연소 가능한 누적 연료량 | 지형·연료 건조 비교 |
| `FWI` | ISI와 BUI를 결합한 종합 화재기상 강도 | 종합 위험 지수 비교 |

`Indexed_FFMC`와 `FFMC_논문식_발생확률`은 최종 예측 모델이 아니라 선행연구 재현 기준선으로만 해석한다. 기존 검증에서 `Indexed_FFMC` 단변량 모델의 판별력이 제한적이었으므로, 높은 확률값을 실제 산불 발생확률로 직접 해석하지 않는다.

### 2-5. 공통 범주와 프록시

- 기후지형유형 순서: `영동 해안형 → 영서 내륙형 → 고지·산간형`
- 번지유형 순서: `임야번지(산) → 일반번지`
- 번지유형은 `발생지역번지`를 공백 정리한 뒤 **`산`으로 시작하는지**로 통일한다.
- `임야번지(산)`은 실제 지목·산림 여부의 확정값이 아니다.
- `생활권프록시`, `입산활동 발화 후보`, `기타 인간활동 발화 후보`, `강수 후 푄 급건조 프록시`는 탐색 라벨이다.
- 프록시는 발생원인, 양간지풍, 등산객 실화를 확정하는 근거로 사용하지 않는다.

### 2-6. 공통 대조군

| 대조군 | 정의 | 사용 목적 |
| --- | --- | --- |
| 전체 비발생 | 산불이 없었던 전체 셀-시각 | 전체 배경 분포 비교 |
| 매칭 비발생 | 동일 기상셀·월·시간대에서 산불당 최대 5개 | 지역·계절·시간 통제 기상 비교 |
| 동일셀 랜덤 공간 | 산불이 속한 기상셀 내부 랜덤 포인트 | 같은 기상 배경 내 공간 편향 |
| 동일셀 랜덤 산림 | 동일셀 랜덤 포인트 중 산림 토지피복 | 임야 산불과 산림 배경 비교 |
| 선형 공간 대조 | 등산로·임도 선형을 500m 간격으로 샘플링 | 입산 경로 전체 대비 발생점 편향 |

매칭 비발생은 산불 시각과 중복되지 않아야 한다. 공간 대조군은 실제 비발생 사건 기록이 아니라 배경 공간 표본이므로 인과 대조군으로 해석하지 않는다.

### 2-7. 공통 통계 원칙

- 독립 두 집단: Welch t-test, Mann-Whitney U, Cohen's d, Cliff's delta
- 대응 비교: paired t-test, Wilcoxon signed-rank, Cohen's dz, 평균차 95% CI
- 3개 이상 집단: ANOVA 또는 Kruskal-Wallis, epsilon squared
- 범주형: chi-square, Cramer's V
- 원형 자료: Rayleigh, Kuiper permutation
- 상관: Spearman
- 다중검정: Benjamini-Hochberg FDR
- 표본 수가 작은 층은 결과표에 `해석 제외`로 표시한다.
- p-value만으로 결론을 내리지 않고 효과크기와 표본 수를 함께 보고한다.

## 13. 공통 Matplotlib 한글 폰트 설정

모든 EDA 노트북의 첫 번째 코드 셀에는 다음 설정을 사용한다. 이후 `sns.set_theme()`를 단독으로 다시 호출하지 않는다.

import pandas as pd
import matplotlib.pyplot as plt
import matplotlib.font_manager as fm
import seaborn as sns
from pathlib import Path

font_path = "C:/Windows/Fonts/malgun.ttf"
fm.fontManager.addfont(font_path)
font_name = fm.FontProperties(fname=font_path).get_name()

sns.set_theme(
    style="whitegrid",
    font=font_name,
    rc={
        "font.family": font_name,
        "font.sans-serif": [font_name],
        "axes.unicode_minus": False,
    },
)

plt.rcParams["font.family"] = font_name
plt.rcParams["font.sans-serif"] = [font_name]
plt.rcParams["axes.unicode_minus"] = False

pd.set_option("display.max_columns", None)
print("현재 matplotlib font.family:", plt.rcParams["font.family"])
print("현재 matplotlib font.sans-serif:", plt.rcParams["font.sans-serif"][:3])

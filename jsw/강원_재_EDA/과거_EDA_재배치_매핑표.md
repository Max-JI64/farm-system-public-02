# 과거 강원 EDA 재배치 매핑표

이 문서는 `jsw/강원_EDA`의 과거 8개 최종 노트북에서 수행한 분석을 `jsw/강원_재_EDA/README.md`의 6단계 재 EDA 구조로 옮긴 위치를 기록한다.

## 1. 매핑 원칙

- 과거 노트북의 최종 저장본에 존재하는 장·절을 최소 한 번 이상 매핑한다.
- 동일 분석이 여러 노트북에 반복되면 새 구조에서는 한 Step을 주 담당으로 정하고, 다른 Step은 결과를 입력으로만 사용한다.
- 산불 기준시각과 결합된 당일 전체 기상 변수는 재사용하지 않는다.
- 캐나다 지수는 산불·비발생 분석에서 정오 시점 안전 as-of 병합을 적용한다.
- 프록시, 공간 대조군, 초기 모델링 이력은 확정 원인이나 최종 예측 결과로 확대하지 않는다.

- VIF 기반 변수 선택
- 기상 복합 지수 WFRI

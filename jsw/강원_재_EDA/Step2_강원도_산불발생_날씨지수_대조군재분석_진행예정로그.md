# Step 2 진행예정로그

- 실행 노트북: `Step2_강원도_산불발생_날씨지수_대조군재분석.ipynb`
- 역할: 산불과 전체·매칭 비발생의 누수 없는 날씨·캐나다 지수 비교
- 해석 기록 위치: 이 파일
- 노트북 역할: 코드 작성과 실행만 수행

## 운영 규칙

1. 분석 ID 순서대로 진행하며 앞 ID의 해석이 끝나기 전에 다음 코드를 작성하지 않는다.
2. 모든 실질 분석은 결과표와 플롯을 한 쌍으로 검토한다.
3. p-value만 기록하지 않고 표본 수, 효과크기, 신뢰구간과 분포 겹침을 함께 해석한다.
4. 전체 비발생과 매칭 비발생의 결론이 다르면 매칭 결과를 우선하고 차이 원인을 기록한다.
5. 노트북 Markdown에는 결과 해석을 작성하지 않는다.
6. 기본 산출물 경로는 `outputs/Step2/tables`, `outputs/Step2/plots`이다.
7. EDA는 시각화 중심으로 진행하며 ECDF, 분포 겹침, 효과크기와 신뢰구간 플롯을 먼저 검토한다.
8. 대조군별 방향 차이, 분포 꼬리, 권역별 이질성이 보이면 다음 기본 ID 전에 추가 심화 분석 ID를 등록한다.

- 표본 수와 매칭 품질: 총 3,405건 중 3,401건 매칭 완료, 미매칭 4건. 매칭률 99.88%.
- 결과표의 핵심 수치·효과크기·신뢰구간: 미매칭 4건 발생(고성군 토성면, 강릉시 견소동, 철원군 2건).
- 플롯의 분포 겹침·꼬리·층화 패턴: 매칭 지도 시각화 결과 대부분의 산불 발생 좌표가 강원도 기상격자 경계 내에 잘 매칭됨. 미매칭 4건은 해안선이나 북쪽 경계 밖으로 벗어난 소수 케이스임.
- 표와 플롯의 통합 해석: 99.88%의 매우 높은 매칭률을 보이며 기상격자 셀과 산불 발생 위치가 거의 완벽히 일치함. 미매칭 4건은 해상 및 접경지 등 공간적 외곽 오차로 볼 수 있음.
- 추가 심화 분석 필요 여부와 근거: 미매칭 건수가 극소수이므로 추가 심화 분석은 불필요함.
- 추가 ID 또는 추가하지 않은 이유: S2-A01 추가 안 함 (영향력이 매우 미미함).
- 전체 대조와 매칭 대조 결론 차이: 해당 없음
- 한계: 미매칭된 4건에 대해 임의로 최근접 기상 데이터를 부여하지 않고 그대로 누락(결측) 처리하는 점.
- 다음 분석 코드에 반영할 사항: S2-02에서는 기상셀 할당이 완료된 3,401건의 데이터를 기준으로 전체 산불 발생 지도와 시간/월별 발생 빈도를 그리는 코드를 작성할 것. S2-02 코드는 아직 작성하지 않음.

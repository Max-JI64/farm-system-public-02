- 실행 노트북: `Step2_강원도_산불발생_날씨지수_대조군재분석.ipynb`
- 역할: 산불과 전체·매칭 비발생의 누수 없는 날씨·캐나다 지수 비교
- 해석 기록 위치: 이 파일
- 노트북 역할: 코드 작성과 실행만 수행

## 운영 규칙

1. 분석 ID 순서대로 진행하며 앞 ID의 해석이 끝나기 전에 다음 코드를 작성하지 않는다.
2. 모든 실질 분석은 결과표와 플롯을 한 쌍으로 검토한다.
3. p-value만 기록하지 않고 표본 수, 효과크기, 신뢰구간과 분포 겹침을 함께 해석한다.
4. 전체 비발생과 매칭 비발생의 결론이 다르면 매칭 결과를 우선하고 차이 원인을 기록한다.
5. 노트북 Markdown에는 결과 해석을 작성하지 않는다.
6. 기본 산출물 경로는 `outputs/Step2/tables`, `outputs/Step2/plots`이다.
7. EDA는 시각화 중심으로 진행하며 ECDF, 분포 겹침, 효과크기와 신뢰구간 플롯을 먼저 검토한다.
8. 대조군별 방향 차이, 분포 꼬리, 권역별 이질성이 보이면 다음 기본 ID 전에 추가 심화 분석 ID를 등록한다.

- 결과표의 핵심 수치·효과크기·신뢰구간: 누수 없이 전체 161만 건의 후보군이 생성되었으며, 산불 발생 시공간과 겹치는 1,150건이 정확히 제외됨.
- 플롯의 분포 겹침·꼬리·층화 패턴: 월별 및 시간대별 비발생 후보 분포는 예상대로 매우 균등한 분포를 보임 (특정 시간/월에 편중되지 않음). 1.6M 개 대비 1,150개가 제외되었기 때문에 전체 시계열 분포의 형태는 기상 격자의 원래 관측 구조(Uniform)를 그대로 유지함.
- 표와 플롯의 통합 해석: 산불이 없었던 대규모 백그라운드 "전체 비발생 후보" 집단 형성이 성공적으로 완료됨. 데이터 누수나 잘못된 시간 병합은 발견되지 않음.
- 추가 심화 분석 필요 여부와 근거: 산불 발생 시점이 일부 중복되어 고유 건수가 1,150건으로 나타났으므로, S2-04 1:5 매칭 시 이 1,150건의 고유 시점을 기준으로 대조군을 샘플링하는 것이 타당함.
- 추가 ID 또는 추가하지 않은 이유: 해당 없음
- 전체 대조와 매칭 대조 결론 차이: 해당 없음
- 한계: 전체 비발생 후보군은 월/시간 분포가 균등(Uniform)한 반면, 산불 발생군은 봄/가을 및 낮 시간대에 심하게 집중되어 있어 단순 비교 시 계절/시간 효과가 기상 효과를 압도할 우려가 있음.

  - **계절 내 국지적 산불 위험의 핵심은 '장기 건조도'**: 산불 집중기인 봄철(3~5월) 내에서조차도, 산불이 발화하는 '그 날'은 주변 날들 평균보다 누적 가뭄 지표(BUI, DC, DMC)가 극도로 치솟아 있는 상태임. 
  - FWI(종합 지수)나 FFMC(단기 습도 지수)보다 깊은 토양의 수분 상태(DC)와 중형 목재의 건조 상태(DMC)를 나타내는 지수가 변별력이 더 높다는 것은 매우 중요한 발견임.
- 추가 심화 분석 필요 여부와 근거: 이제 전체적으로 어떤 기상/지수 변수가 중요한지 파악했으므로, S2-09에서는 이 효과들이 "영동(해안) vs 영서(내륙) vs 산간" 등 기후지형유형별로 다르게 나타나는지(이질성 검증) 확인해야 함.
- 추가 ID 또는 추가하지 않은 이유: 해당 없음
- 전체 대조와 매칭 대조 결론 차이: 전체 비교(S2-06)에서는 계절적 편향(여름 vs 봄)으로 인해 단기 지표인 FWI가 두드러졌으나, 계절을 통제한 매칭 비교(S2-08)에서는 진짜 발화의 방아쇠를 당기는 **장기 건조 지표(BUI, DMC, DC)의 위력**이 명확히 드러남.

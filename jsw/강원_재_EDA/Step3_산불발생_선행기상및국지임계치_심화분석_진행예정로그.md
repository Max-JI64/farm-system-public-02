# Step 3 진행예정로그

- 실행 노트북: `Step3_산불발생_선행기상및국지임계치_심화분석.ipynb`
- 역할: Step 1의 배경 기후와 Step 2의 고정 매칭 결과를 기반으로, 산불 발생 전 선행 기상·급변 조건·국지 임계치 후보를 탐색한다.
- 해석 기록 위치: 이 파일
- 노트북 역할: 코드 작성과 실행만 수행
- 현재 상태: S3-03 급건조·급변 프록시 완료

## 운영 규칙

1. Step 2에서 확정된 고유 `기상셀ID × 기준시각` 산불 노출 1,150개와 고정 매칭 대조군 `S2-04_matched_controls.csv.gz`만 사용한다.
2. 원본 산불 사건 1,558행을 기상 비교 표본으로 직접 쓰지 않는다. 사건 수는 보조 감사값으로만 유지한다.
3. 절대 임계치, 국지 상대 분위수, 매칭 대조군 대비 delta를 구분해 저장한다.
4. `시점_*` 변수는 Step 2 원칙대로 동시상태 기술값이며, 선행 예측 변수나 누수 없는 임계치 후보로 승격하지 않는다.
5. 모든 rolling·누적·변화량 변수는 기준시각 현재 값을 제외하고 과거 값만 사용한다.
6. 날짜 block bootstrap을 기본 불확실성으로 사용하고, 반복 셀 영향은 기상셀 block bootstrap 민감도로 확인한다.
7. 전체 비발생 후보와의 비교는 배경 탐색이고, 주 해석은 동일 셀·연도·월·시각 매칭 대조군 대비 결과로 작성한다.
8. 푄, 양간지풍, 점화원, 입산활동, 연료수분, 피해·확산 규모는 직접 관측 라벨이 없으므로 프록시로만 서술한다.
9. 희소 조합은 별도 표시한다. 기본적으로 산불 노출 30개 미만, 날짜 10개 미만, 셀 5개 미만인 층화 결과는 결론 문장에 쓰지 않는다.
10. 노트북 Markdown에는 결과 해석을 작성하지 않는다.
11. 기본 산출물 경로는 `outputs/Step3/tables`, `outputs/Step3/plots`이다.
12. 하나의 이미지 파일에는 하나의 핵심 플롯만 저장한다.
13. 기존 Step 3 결과표·플롯·해석은 새 분석에 사용하지 않는다.

## Step 1·Step 2에서 고정해 가져올 내용

### Step 1 배경

1. 분석 범위는 강원도 기상셀 92개와 2020~2021년이다.
2. 시간기상 1,614,048행과 캐나다 지수 67,252행은 셀·시각 키 기준으로 완전하다.
3. 11~5월은 6~10월보다 저온·저습·강풍·큰 일교차의 배경 기후를 보인다.
4. 영동 해안형은 겨울철 저습·서풍계열·상대적 강풍, 영서 내륙형은 봄철 큰 일교차가 특징이다.
5. 영동 해안형은 겨울, 영서 내륙형과 고지·산간형은 봄에 배경 FWI 평균이 상대적으로 높다.
6. 3개 기후지형유형은 설명·층화 변수이지 자연 군집이나 산불 위험등급이 아니다.
7. YS_0071은 품질검토 대상이다. 자동 제외하지 않고 관련 층화 결과에서 포함/제외 민감도를 병기한다.
8. FWI 계열 지수는 기상 입력에서 계산된 파생지수이므로, 기상 변수와 서로 독립적인 증거라고 해석하지 않는다.

### Step 2 결과

1. 정제 산불은 1,558개 사건이지만, 기상·지수 비교 표본은 고유 `기상셀ID × 기준시각` 1,150개다.
2. 고정 매칭 대조군은 5,632행이다. 매칭 키는 동일 기상셀, 동일 연도, 동일 월, 동일 hour이며 산불 동일 노출과 동일 셀 전후 48시간을 제외했다.
3. 5개 대조군 확보율은 96.52%다. 5개 미만 40개 노출은 모두 2월에 있으며, 영동 해안형 21개와 고지·산간형 19개다.
4. S2-07 주 분석에서 산불 노출은 매칭 대조군보다 직전24h·D-1 습도가 낮고 강수가 적었다. 풍속은 전체 강원도 단위에서는 평균 delta가 작고 날짜 bootstrap CI가 0을 포함했다.
5. S2-08 주 분석에서 FFMC, ISI, FWI는 매칭 후에도 양의 delta가 남았다. DMC, DC, BUI는 전체 단위에서 날짜 bootstrap CI가 0을 포함하고 중앙값 delta가 음수라 강건한 단기 판별 신호로 보지 않는다.
6. S2-09 층화 분석에서 영동 해안형은 풍속·ISI delta가 상대적으로 크고, 영서 내륙형은 DMC/DC/BUI 평균과 양의 꼬리가 영동보다 높으며, 고지·산간형은 직전24h 및 D-1 최소습도 하강이 상대적으로 크다.
7. S2-10의 현재 유효 결과는 delta 상관과 복합분포 중심이다. 영동 해안형은 평균풍속-최소습도 delta 상관이 -0.570이고, 풍속 delta > 0.5 m/s 및 최소습도 delta < -5.0% 결합 비중이 31.6%다. 원값 상관 산출물은 Step 2 로그에 기록한 대로 재실행 확인 전까지 해석에 사용하지 않는다.

## Step 3의 분석 목표

Step 3는 새로운 원인을 확정하는 단계가 아니다. 목표는 다음 모델링·보고 단계에 넘길 수 있는 **선행 시간창**, **급변 프록시**, **국지 상대 임계치 후보**, **층화별 후보 변수 묶음**을 만드는 것이다.

따라서 각 단계는 다음 질문에 답해야 한다.

1. 산불 발생 전 몇 시간 또는 며칠의 조건이 매칭 대조군과 가장 잘 구분되는가?
2. 절대값 기준과 해당 셀·월·시간대의 상대 분위수 기준 중 어느 쪽이 더 안정적인가?
3. 영동·영서·고지의 Step 2 이질성이 선행 시간창에서도 유지되는가?
4. 단일 변수 임계치보다 습도×풍속, 무강수×FFMC, 급건조×ISI 같은 복합 조건이 더 일관적인가?
5. 희소 조합과 특정 날짜 군집에 의존하지 않는 후보만 Step 4·Step 5로 넘길 수 있는가?

## 공통 입력과 파생 기준

### 입력 파일

- 산불 노출: `outputs/Step2/tables/S2-01_unique_weather_exposures.csv` 또는 Step 2에서 재사용한 고유 노출 테이블
- 고정 대조군: `outputs/Step2/tables/S2-04_matched_controls.csv.gz`
- 시간기상 원자료 및 Step 2 rolling 변수
- 캐나다 지수 원자료 및 Step 2 as-of 결합 로직
- 기후지형유형/셀 메타, YS_0071 플래그

### 공통 파생

- 선행 시간창: 1h, 3h, 6h, 12h, 24h, 48h, 72h
- 일 단위 lag: D-1, D-2, D-3, 필요 시 D-7까지 보조
- 습도: 최소, 평균, 하위 10분위, 급락량
- 풍속: 평균, 최대, 상위 90분위, 강풍 지속시간
- 강수: 누적 강수량, 무강수 시간, 마지막 강수 후 경과시간
- 풍향: sin/cos, 서풍계열 여부, 강풍 시 서풍계열 여부
- 캐나다 지수: FFMC, ISI, FWI를 주 지수로 두고 DMC/DC/BUI는 층화 보조로만 사용
- 상대 분위수 기준: 동일 셀×월×hour를 기본, 표본이 부족하면 셀×월 또는 기후지형유형×월로 완화하되 완화 여부를 표에 기록

## ID별 상세 진행 계획

### S3-02. 선행 시간창별 delta 스캔

- 무엇을 할지:
  - 습도, 강수, 풍속, FFMC, ISI, FWI의 1/3/6/12/24/48/72h 또는 as-of 선행 차이를 매칭 대조군 평균과 비교한다.
  - Step 2에서 강했던 24h·D-1 건조 신호가 더 짧은 시간창에서 강화되는지 확인한다.
  - 전체, 영동, 영서, 고지·산간형을 나눠 본다.
- 어떻게 할지:
  - 각 산불 노출별 `산불 선행값 - 매칭 대조군 선행값 평균`을 계산한다.
  - 평균 delta, 중앙값 delta, Cohen's d_paired, 방향 일치율, 날짜 block bootstrap CI, 셀 block CI를 산출한다.

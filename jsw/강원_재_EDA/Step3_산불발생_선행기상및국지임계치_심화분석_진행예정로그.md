# Step 3 진행예정로그

- 실행 노트북: `Step3_산불발생_선행기상및국지임계치_심화분석.ipynb`
- 역할: 선행 기상, 급건조, 풍향과 지역·번지별 임계치 탐색
- 해석 기록 위치: 이 파일
- 노트북 역할: 코드 작성과 실행만 수행
- 현재 상태: 기존 분석을 폐기하고 Step 2 완료를 기다리는 초기 상태

## 운영 규칙

1. Step 2에서 확정된 산불 분석 단위와 고정 매칭 대조군만 사용한다.
2. Step 2가 완료되기 전에는 Step 3의 세부 변수, 임계치, 검정 방법을 확정하지 않는다.
3. 각 분석 ID는 코드·실행·결과표·플롯·해석·다음 코드 반영 순으로 닫는다.
4. 절대 임계치와 매칭 대조군 대비 상대 이상성을 구분한다.
5. 표본 수와 희소 영역을 함께 확인하고 희소 조합은 확정 해석에서 제외한다.
6. 푄, 입산활동, 강풍 피해 등은 직접 관측 라벨이 없으면 프록시로만 서술한다.
7. 노트북 Markdown에는 결과 해석을 작성하지 않는다.
8. 기본 산출물 경로는 `outputs/Step3/tables`, `outputs/Step3/plots`이다.
9. 하나의 이미지 파일에는 하나의 핵심 플롯만 저장한다.
10. 기존 Step 3 결과표·플롯·해석은 새 분석에 사용하지 않는다.

# Step 1 진행예정로그

- 실행 노트북: `Step1_강원도_기후지형및캐나다지수_기본분석.ipynb`
- 역할: 산불 Target을 사용하지 않은 기후·지형·캐나다 지수 배경 분석
- 해석 기록 위치: 이 파일
- 노트북 역할: 코드 작성과 실행만 수행

## 운영 규칙

1. 분석 ID 순서대로 진행한다.
2. 현재 분석의 코드 실행이 끝나도 결과표와 플롯을 모두 검토하기 전에는 해석 완료로 처리하지 않는다.
3. 해석에는 결과표의 수치 근거와 플롯의 형태·방향·이상치를 동시에 기록한다.
4. 해석과 한계를 작성한 뒤 `다음 코드 반영`을 체크해야 다음 분석 ID로 넘어간다.
5. 노트북 Markdown에는 결과 해석을 작성하지 않는다.
6. 표와 플롯 경로는 각각 `outputs/Step1/tables`, `outputs/Step1/plots`를 기본으로 한다.
7. EDA는 시각화 중심으로 진행한다. 핵심 플롯을 먼저 설계하고 통계표는 시각적 패턴의 크기와 불확실성을 확인하는 보조 근거로 사용한다.
8. 플롯에서 다봉성, 비선형성, 이상치, 공간 군집 또는 층화 방향 차이가 발견되면 다음 기본 ID로 넘어가기 전에 추가 심화 분석 ID를 등록할 수 있다.

## 완료 판정

- `코드`: 분석 코드 작성 완료
- `실행`: error output 없이 실행 완료
- `표`: 표본 수, 결측, 검정통계량, p-value, 효과크기를 검토
- `플롯`: 축, 범례, 단위, 분포, 이상치와 공간 패턴을 직접 검토
- `해석`: 표와 플롯을 함께 근거로 이 로그에 해석 작성
- `반영`: 해석 결과가 다음 분석 코드의 변수·층화·검정 선택에 반영됨

### S1-02. 영동/영서 DEM·기후 기본 비교

- 작성일: 2026-06-13
- 실행 범위: Step 1 노트북 S1-02 코드 실행 완료.
- 결과표 파일:
  - `outputs/Step1/tables/S1-02_descriptive_stats.csv`
  - `outputs/Step1/tables/S1-02_region_tests.csv`
- 플롯 파일:
  - `outputs/Step1/plots/S1-02_region_boxplots.png`
  - `outputs/Step1/plots/S1-02_region_dem_map.png`
  - `outputs/Step1/plots/S1-02_region_ecdf.png`
  - `outputs/Step1/plots/S1-02_region_effect_sizes.png`
- 결과표에서 확인한 핵심 수치: 영동(21개 셀)과 영서(71개 셀) 간의 통계적 차이가 모든 변수에서 유의미함(FDR < 0.05). DEM 고도는 영동(평균 129m)이 영서(평균 502m)보다 낮음. 기온(평균기온, 일최저기온), 풍속, 강수량은 영동이 높고, 습도와 일교차는 영서가 높음. 특히 일최저기온(Cohen's d 2.85, Cliff's delta 0.99)과 평균기온(Cohen's d 1.70)의 효과크기가 가장 두드러짐.
- 플롯에서 확인한 패턴·이상치:
  - Boxplot과 ECDF에서 일최저기온과 평균기온은 두 권역의 분포가 거의 겹치지 않고 확연히 분리됨.
  - 영서는 면적이 넓고 지형이 다양해 고도와 강수량 등에서 영동보다 큰 분산과 긴 꼬리(다수의 이상치)를 가짐.

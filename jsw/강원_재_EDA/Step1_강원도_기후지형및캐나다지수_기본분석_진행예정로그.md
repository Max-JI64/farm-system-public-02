# Step 1 진행예정로그

- 실행 노트북: `Step1_강원도_기후지형및캐나다지수_기본분석.ipynb`
- 역할: 산불 Target을 사용하지 않은 기후·지형·캐나다 지수 배경 분석
- 해석 기록 위치: 이 파일
- 노트북 역할: 코드 작성과 실행만 수행
- 해석 사용 원칙: 과거 EDA의 결론은 사용하지 않으며, 현재 재 EDA의 모든 해석과 최종 판단은 이 파일만을 기준으로 한다.

## 운영 규칙

1. 분석 ID 순서대로 진행한다.
2. 현재 분석의 코드 실행이 끝나도 결과표와 플롯을 모두 검토하기 전에는 해석 완료로 처리하지 않는다.
3. 해석에는 결과표의 수치 근거와 플롯의 형태·방향·이상치를 동시에 기록한다.
4. 해석과 한계를 작성한 뒤 `다음 코드 반영`을 체크해야 다음 분석 ID로 넘어간다.
5. 노트북 Markdown에는 결과 해석을 작성하지 않는다.
6. 표와 플롯 경로는 각각 `outputs/Step1/tables`, `outputs/Step1/plots`를 기본으로 한다.
7. EDA는 시각화 중심으로 진행한다. 핵심 플롯을 먼저 설계하고 통계표는 시각적 패턴의 크기와 불확실성을 확인하는 보조 근거로 사용한다.
8. 플롯에서 다봉성, 비선형성, 이상치, 공간 군집 또는 층화 방향 차이가 발견되면 다음 기본 ID로 넘어가기 전에 추가 심화 분석 ID를 등록할 수 있다.

9. 분석의 용이성을 위하여 앞으로 하나의 이미지 파일에는 여러 플롯을 묶지 않고 하나의 플롯만 포함되도록 개별 파일로 생성한다.
## 완료 판정

- `코드`: 분석 코드 작성 완료
- `실행`: error output 없이 실행 완료
- `표`: 표본 수, 결측, 검정통계량, p-value, 효과크기를 검토
- `플롯`: 축, 범례, 단위, 분포, 이상치와 공간 패턴을 직접 검토
- `해석`: 표와 플롯을 함께 근거로 이 로그에 해석 작성
- `반영`: 해석 결과가 다음 분석 코드의 변수·층화·검정 선택에 반영됨

#### 발표용 상세 해석과 근거

- **이 단계의 질문**: 이후의 권역·계절·지수 비교가 데이터 누락이나 잘못된 공간 키 때문에 만들어진 결과가 아닌지 먼저 확인하는 입력 품질 감사 단계다. 산불 Target은 사용하지 않았으며, 분석에 사용할 배경 모집단 자체를 확정하는 것이 목적이다.
- **시간자료 완전성 근거**: 2020년 1월 1일 00시부터 2021년 12월 31일 23시까지는 윤일을 포함해 셀당 17,544시간이다. 실제 시간기상 행수 `92 × 17,544 = 1,614,048`이 정확히 일치했고, `기상셀ID × 일시` 중복과 누락 시간이 모두 0건이었다. 따라서 특정 권역이나 계절에서 관측시간이 적어 평균이 왜곡되는 구조는 확인되지 않았다.
- **캐나다 지수 완전성 근거**: 같은 기간은 셀당 731일이며 실제 행수 `92 × 731 = 67,252`가 정확히 일치했다. `기상셀ID × 날짜` 중복, 누락 날짜, 핵심 지수 결측이 모두 0건이므로 이후 월·계절별 지수 차이는 자료 가용일수 차이가 아니라 관측된 값의 차이로 비교할 수 있다.
- **공간 결합 근거**: 92개 기상셀 중심점은 모두 해당 셀 다각형 내부에 있었고 DEM 범위 밖 표본과 DEM 추출 실패가 없었다. 지도에서도 중심점과 셀 경계의 체계적인 위치 이동이 보이지 않아 좌표계 불일치 가능성을 배제했다.

## Step 1 최종 통합 해석

- **계절 차이**: 11~5월은 6~10월보다 평균기온 14.15°C, 최저기온 15.36°C, 습도 15.84%p 낮고 풍속은 0.53m/s 높으며 일교차는 2.00°C 크다. 이는 배경 기후 차이이며 산불 발생 효과가 아니다.
- **3개 기후지형유형**: 영동 해안형·고지산간형·영서 내륙형은 기후 차이를 요약하는 실용적 층화 변수다. K=3 군집과의 ARI는 0.430으로 완전 일치하지 않으며 일부 기상변수의 쌍별 차이도 유의하지 않다. 자연 군집이나 위험등급으로 사용하지 않는다.
- **월별 배경 기후**: 영동 해안형은 겨울철 저습·서풍계열·상대적 강풍, 영서 내륙형은 봄철 큰 일교차가 특징이다. 사용한 풍속은 `일최대시간풍속`이며 최대순간풍속이나 돌풍이 아니다.
- **고도 관계**: 고도는 평균기온 및 최저기온과 강한 음의 관계가 있다. 풍속과 일교차에서는 비선형 형태가 관찰되지만 해안·능선·분지 효과의 인과성을 확정하지 않는다.

- **기상-지수 관계**: 습도·강수는 FFMC·ISI·FWI와 음의 관계이고 풍속은 ISI·FWI와 양의 관계다. 입력 기상으로 계산된 파생지수이므로 독립적인 물리 검증이나 인과 증거로 보지 않는다.
- **품질검토 대상**: YS_0071은 기온·일교차·강수에서 동시 극단값을 보인다. 자동 제거하지 않고 전체 포함 결과와 제외 민감도 결과를 함께 사용한다.
- **해석 범위**: Step 1은 산불 Target을 사용하지 않은 배경 EDA다. 산불 발생 원인, 실제 위험확률, 피해 규모, 위험 시기 또는 정책 효과는 이 단계에서 결론 내리지 않는다.

### 발표 서사

1. **데이터 신뢰성 확보**: 92개 셀의 2년 연속 시간·일 자료에서 누락과 중복이 없음을 먼저 확인했다.
2. **거시적 공간 차이 확인**: 영동은 저고도·고온·저습·상대적 강풍, 영서는 큰 일교차와 높은 내부 변동성을 보였다.
3. **계절 교란 규모 확인**: 11~5월과 6~10월의 기온·습도 차이가 매우 커 산불 발생일과 연중 전체를 직접 비교하면 잘못된 결론이 생길 수 있음을 확인했다.
4. **층화 체계 검토**: 3개 기후지형유형은 주요 차이를 요약하지만 모든 변수에서 완전히 분리되지는 않아 분석용 층화로만 사용하기로 했다.
5. **월별·고도별 구조 확인**: 유형별 계절 패턴과 고도-기온 관계를 확인해 Step 2에서 통제해야 할 배경 변수를 구체화했다.
6. **캐나다 지수 배경 확정**: FWI 계열도 유형·계절에 따른 평상시 차이가 존재하므로 산불 발생일의 지수 상승은 동일 배경 대조군과 비교해야 한다.
7. **해석 경계 설정**: Step 1은 Target 없는 배경 EDA이므로 실제 산불 발생 원인·확률·피해·정책 결론은 Step 2 이후로 유보했다.

### Step 2에 전달하는 구체적 분석 기준

- 산불 발생 분석은 정제 사건과 고유 `기상셀ID × 기준시각` 노출을 구분한다.
- 전체 비발생 비교는 계절·권역 교란을 보여주는 탐색 결과로만 사용한다.
- 주 비교는 동일 셀·연도·월·시각의 고정 매칭 대조군을 사용한다.
- 영동 해안형·영서 내륙형·고지산간형은 층화 변수로 사용하되 위험등급으로 부르지 않는다.
- 기온은 계절·고도 교란 가능성이 크므로 사전 위험 방향을 정하지 않는다.
- 습도·강수·풍속과 FFMC·ISI·FWI를 함께 해석할 때 계산 구조와 다중공선성을 명시한다.
- `Indexed_FFMC`와 논문식 발생확률은 참조 변수로 분리하고 실제 강원도 발생확률로 표현하지 않는다.
- YS_0071은 자동 제외하지 않고, 해당 셀이 관련된 층화 결과에서 포함·제외 민감도를 제시한다.

# Step 1 진행예정로그

- 실행 노트북: `Step1_강원도_기후지형및캐나다지수_기본분석.ipynb`
- 역할: 산불 Target을 사용하지 않은 기후·지형·캐나다 지수 배경 분석
- 해석 기록 위치: 이 파일
- 노트북 역할: 코드 작성과 실행만 수행

## 운영 규칙

1. 분석 ID 순서대로 진행한다.
2. 현재 분석의 코드 실행이 끝나도 결과표와 플롯을 모두 검토하기 전에는 해석 완료로 처리하지 않는다.
3. 해석에는 결과표의 수치 근거와 플롯의 형태·방향·이상치를 동시에 기록한다.
4. 해석과 한계를 작성한 뒤 `다음 코드 반영`을 체크해야 다음 분석 ID로 넘어간다.
5. 노트북 Markdown에는 결과 해석을 작성하지 않는다.
6. 표와 플롯 경로는 각각 `outputs/Step1/tables`, `outputs/Step1/plots`를 기본으로 한다.
7. EDA는 시각화 중심으로 진행한다. 핵심 플롯을 먼저 설계하고 통계표는 시각적 패턴의 크기와 불확실성을 확인하는 보조 근거로 사용한다.
8. 플롯에서 다봉성, 비선형성, 이상치, 공간 군집 또는 층화 방향 차이가 발견되면 다음 기본 ID로 넘어가기 전에 추가 심화 분석 ID를 등록할 수 있다.

## 완료 판정

- `코드`: 분석 코드 작성 완료
- `실행`: error output 없이 실행 완료
- `표`: 표본 수, 결측, 검정통계량, p-value, 효과크기를 검토
- `플롯`: 축, 범례, 단위, 분포, 이상치와 공간 패턴을 직접 검토
- `해석`: 표와 플롯을 함께 근거로 이 로그에 해석 작성
- `반영`: 해석 결과가 다음 분석 코드의 변수·층화·검정 선택에 반영됨

### S1-01. 분석 모집단·키·결측·DEM 샘플링 감사

- 실행 범위: Step 1 노트북의 원천 로딩부터 S1-01 완료 검증까지 전체 실행했다. 코드 셀 14개가 모두 실행되었고 error output은 0건이다.

  - `outputs/Step1/plots/S1-01_cell_dem_sampling_map.png`
  - `outputs/Step1/plots/S1-01_monthly_completeness_heatmap.png`
- 결과표에서 확인한 핵심 수치: 기상셀 메타·기후지형유형·격자는 모두 92개이며 셀 키 집합이 일치했다. 시간기상은 2020-01-01 00:00~2021-12-31 23:00의 1,614,048행으로 셀당 17,544시간이고, 캐나다 지수는 2020-01-01~2021-12-31의 67,252행으로 셀당 731일이다. 두 자료 모두 중복 키, 누락 시간·날짜, 변수 결측이 각각 0건이며 행 완전성은 100%였다. 92개 중심점이 모두 대응 셀 내부와 DEM 범위 안에 있었고 DEM 샘플 성공률은 100%였다. 중심점 고도는 최소 2.55m, 중앙값 334.03m, 최대 1,197.04m였다. S1-01은 입력 감사이므로 p-value와 효과크기 검정은 적용 대상이 아니다.
- 플롯에서 확인한 패턴·이상치: 셀 지도에서 92개 중심점이 각 다각형 내부에 한 점씩 배치되어 좌표계 이동이나 경계 밖 표본이 보이지 않았다. DEM 배경 위의 표본 색은 해안·저지대의 낮은 고도와 내륙 산지의 높은 고도 표면을 따라 변해 위치와 샘플값 사이의 뚜렷한 불일치가 없었다. 월별 완전성 히트맵은 시간기상과 캐나다 지수 모두 24개월 전체가 단일한 100% 색으로 채워졌고 특정 셀·월의 공백이나 띠 모양 누락이 없었다.
- 표와 플롯의 통합 해석: Step 1의 분석 모집단은 92개 기상셀과 2020~2021년 전 기간으로 고정할 수 있다. 키 중복 제거, 시간 보간, 결측 대체 또는 DEM 최근접 보정 없이 원자료를 후속 분석에 사용할 수 있으며, 중심점 DEM 고도는 셀 단위 정적 변수로 일대일 결합할 수 있다.
- 추가 심화 분석 필요 여부와 근거: 필요하지 않다. 감사 지표와 두 플롯에서 누락 집중, 좌표계 불일치, DEM 미표본, 비연속 시간 구간 같은 결과 기반 심화 신호가 발견되지 않았다.
- 추가 ID 또는 추가하지 않은 이유: `S1-A01`은 등록하지 않는다. 확인된 고도 범위와 공간적 고저 차이는 예상된 지형 변동이며 이미 S1-02의 권역 비교와 S1-07의 고도-기후 관계 분석에 포함되어 있어 별도 감사 심화 분석으로 중복할 근거가 없다.
- 과거 EDA 결론 유지·변경: 이 단계는 분석 기반 감사이므로 영동·영서 또는 3개 기후지형유형에 대한 과거 결론을 변경하지 않는다. 과거 EDA를 재검정할 수 있는 모집단과 공간 키가 온전하다는 전제만 유지한다.
- 한계와 과해석 방지: 중심점 고도 한 값은 셀 내부의 산악 고도 분산과 경사·능선 구조를 대표하지 않는다. 자료 완전성은 관측값의 측정오차나 기상셀 대표성까지 보증하지 않으며, 고도 색상 패턴을 기후 차이나 산불 위험으로 해석하지 않는다.
- 다음 분석 코드에 반영할 사항: S1-02에서는 92개 셀 전체를 유지하고 `기상셀ID` 기준으로 기후권역과 중심점 `DEM_고도_m`를 일대일 병합한다. 시간기상은 2020~2021년 1,614,048행을 결측 대체 없이 사용하며, 중복 제거 또는 누락 보간 분기를 두지 않는다. 영동/영서 비교 표에는 셀 수와 관측 기간을 함께 출력하고, DEM은 중심점 대표값이라는 한계를 유지한다. S1-02 코드는 이번 세션에서 작성하지 않았다.

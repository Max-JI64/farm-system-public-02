# 전력 설비 산불 발화 위험도 이진 분류 모델링 전략 (Deep Dive)

이 문서는 한전(KEPCO) 전력설비(Pole) 산불 취약성 평가를 위한 이진 분류(1: 발생, 0: 미발생) 모델링을 어떻게 구축할 것인지에 대한 핵심 전략을 정리합니다. 데이터 불균형, 모델의 선택, FA 요인점수 활용이라는 세 가지 난제에 대한 명확한 해답을 담고 있습니다.

---

## 1. 비발생 데이터(Target=0) 생성 문제: 시공간 네거티브 샘플링

### 딜레마
산불 발생(1) 데이터만 있는 상태에서 이진 분류를 하려면 '발생하지 않은(0)' 데이터가 필수적입니다. 하지만 강원도 전역의 모든 면적과 모든 시간대를 0으로 상정하면 데이터가 폭발하고, 1(발생)과 0(미발생)의 비율이 극단적인 클래스 불균형(Class Imbalance) 상태가 되어 모델이 무조건 '0'으로만 예측하게 됩니다.

### 해결책: 공간과 시간을 분리한 듀얼 네거티브 샘플링(Dual Negative Sampling)
모델이 '공간적 취약성'과 '시간적(기상) 트리거'를 모두 완벽하게 학습하려면, 0(대조군) 데이터를 두 가지 그룹으로 나누어 혼합해야 합니다.

1. **시간 대조군 (Temporal Control 0): 실제 산불 발생 위치 + 매칭 비발생(평상시 기상) 시간**
   - **방식:** 이미 FA 분석에서 만드셨던 **'매칭 비발생'** 데이터를 그대로 사용합니다. (장소는 실제 불이 났던 그 위험한 위치이지만, 날짜/시간은 평상시인 데이터)
   - **목적:** 모델에게 **"위험한 장소라도, 어떤 날씨일 때 불이 나는가?"(동적 트리거)**를 가르칩니다.
   - *학습 효과:* "원래 산불이 잘 나는 도로변(위험 공간)이라도, 오늘처럼 습도가 높고 바람이 없으면 불이 안 나는구나."

2. **공간 대조군 (Spatial Background 0): 무작위 WUI 구역 + 1년 365일 완전 무작위 시간 (Uniform Random)**
   - **방식:** 강원도 전체 산림 및 도로 주변(WUI)에서 무작위 좌표를 뽑고, 기상 시간은 **1년 365일, 24시간 중 완전 무작위(동일 비율)**로 매칭합니다. (단, 무작위로 생성한 시/공간 샘플 중 실제 산불 기록과 겹치는 경우는 데이터 무결성을 위해 필터링하여 제외합니다.)
   - **위험 계절로만 안 묶고 완전 랜덤을 쓰는 이유:** 말씀하신 대로 여름이나 야간에도 산불 비율이 낮을 뿐 아예 안 나는 것은 아닙니다. 일부러 위험 계절(11~5월) 데이터만 추출한다면, 모델은 여름철이나 새벽의 절대적인 안전도를 배우지 못해 한여름에 바람만 좀 불어도 "위험!" 이라는 오경보를 낼 수 있습니다. 모든 시간대를 동일 비율로 추출해야 모델이 1년 전체의 객관적인 발생 확률(Global Baseline)을 정확히 계산할 수 있습니다.
   - **그럼 '너무 쉬운 문제(Easy Negative)'만 풀게 되지 않나요?:** 아닙니다! 이미 **1번 그룹(시간 대조군)**이 산불이 났던 바로 그 위험 계절/시간대의 데이터를 0으로 제공하고 있습니다. 즉, 1번 그룹이 모델을 괴롭히는 '어려운 오답(Hard Negative)' 역할을 완벽히 수행해 주므로, 2번 그룹은 인위적인 조작 없이 1년 365일의 전체 배경을 깔아주는 것이 가장 완벽한 역할 분담입니다.
   - **목적:** 모델에게 **"어떤 지형/위치가 애초에 산불에 취약한가?"(정적 위험)**를 가르칩니다. 

**결론 (최종 데이터셋 구성):**
학습 데이터셋은 다음과 같이 3개의 그룹이 섞인 형태가 됩니다.
- **Target 1:** 실제 산불 (실제 위치 + 실제 발생 시간) [비율 1]
- **Target 0 (A):** 매칭 비발생 (실제 위치 + 평상시 시간) [비율 5]
- **Target 0 (B):** 공간 대조군 (무작위 WUI 위치 + 무작위 시간) [비율 5]

이렇게 두 종류의 0 데이터를 함께 넣어 모델을 학습시킵니다. 완성된 이 '보편적 산불 예측 모델'에 **한전 전신주(Pole) 좌표와 당일 예보 기상**을 대입(Inference)하면, 공간과 기상을 모두 다각적으로 검증한 가장 완벽한 전신주별 위험도(확률)가 계산됩니다.

## 2. 예측 모델링 접근법: 로지스틱 회귀 vs 머신러닝 모델 선택 전략

과거에는 예측용(ML)과 설명용(로지스틱 회귀) 모델을 동시에 사용하는 '투트랙'을 고려했으나, 두 모델의 예측 결과가 어긋날 경우 발생하는 치명적인 논리적 모순을 방지하기 위해 **"두 모델을 모두 학습시켜 성능(Performance)과 설명력(Interpretability)의 교환비(Trade-off)를 평가한 후, 최종적으로 단 하나의 모델만 선택"**하는 단일 트랙 전략을 취합니다.

### 후보 1: 머신러닝 (LightGBM/XGBoost) + SHAP (가장 추천)
- **방식:** 복잡한 교차 작용(예: 강풍은 습도가 낮을 때만 위험하다)을 스스로 학습하는 비선형 ML 알고리즘을 사용하여 예측 성능을 극대화합니다.
- **설명력 확보 방안:** ML의 블랙박스 문제는 **SHAP (Shapley Additive exPlanations)** 기법을 통해 해결합니다. SHAP을 사용하면 "이 전신주의 위험도 85% 중 강풍이 +40%, 건조가 +30% 기여함"을 완벽하게 분해하여 현장에 설명할 수 있으므로, 굳이 설명용 로지스틱 회귀를 따로 만들 필요가 없어집니다.
- **선택 기준:** 예측 성능(AUROC 등)이 뛰어나고, 정교한 기상 임계치를 스스로 찾아내어 실전 관제 시스템의 예측력을 극대화하고자 할 때 최종 채택합니다.

### 후보 2: 로지스틱 회귀 (자체 지수화 모델)
- **방식:** 5대 절대 FA 요인점수를 독립변수로 하여 확률을 예측하고, 각 변수의 회귀계수를 기반으로 '한전 산불위험지표'라는 직관적인 수식(Index)을 만듭니다.
- **선택 기준:** 한전(KEPCO) 측에서 "인공지능 블랙박스는 믿을 수 없으니, 엑셀로도 누구나 계산할 수 있는 100% 투명하고 단순한 산식(Formula)을 내놔라"라고 강력히 요구하거나, 머신러닝 모델과 성능 차이가 1~2% 미만으로 거의 나지 않을 때 보수적 관점에서 최종 채택합니다.

## 3. 기구축한 FA 요인점수의 올바른 모델 투입 방안 (절대 FA 요인 사용)

EDA와 FA를 통해 만든 지표를 모델의 범용 피처(X)로 투입할 때, 상대적인 변화량인 '매칭비발생(Delta) FA' 점수를 직접 섞어 쓰는 것은 2번 공간 대조군(무작위 좌표)에 적용할 때 데이터 성격이 달라질 수 있다는 점을 고려해야 합니다. (공간 대조군은 무작위 좌표에 무작위 시간을 뽑은 것이라 '평소 대비 변화량'을 구하는 것이 정의상 모호할 수 있음)

따라서 모델의 입력 피처로는 `2026-06-08_FA.ipynb`에서 도출된 **5개의 '절대 기상/공간 FA 요인'**을 기본(Baseline)으로 고려합니다.

### 주의사항: 머신러닝에 FA 점수와 원본 변수를 섞어 쓰면 안 되나요?
과거에는 머신러닝의 성능을 극대화하기 위해 'FA 점수'와 '원본 기상 변수'를 모두 때려 넣는 방식을 쓰기도 했습니다. 예측력 자체는 트리 모델이 알아서 처리하므로 문제가 없지만, **SHAP을 통한 해석(Explainability) 단계에서 치명적인 문제**가 발생할 수 있습니다.
원본 변수(예: 직전 24시간 풍속)는 이미 FA 점수(`강풍_score`) 안에 녹아들어 있으므로 두 변수는 극도로 강한 상관관계를 가집니다. 이를 동시에 넣으면 SHAP이 강풍의 위험 기여도를 두 변수에 무작위로 쪼개버리게 되어(예: 강풍_score 20%, 원본풍속 20%), 실무자에게 "왜 위험한가?"를 설명할 때 해석이 완전히 꼬여버릴 우려가 있습니다.
따라서 SHAP의 깔끔한 해석을 위해서는 **5대 절대 FA 요인점수만**을 머신러닝의 입력 변수로 통일하여 사용하는 것이 가장 이상적(정석)입니다. 다만, 이러한 제약이 모델의 예측 성능(AUROC 등)을 얼마나 희생시키는지 정량적으로 확인하기 위해 향후 Action Plan에서 원본 변수를 포함한 비교 실험(A/B/C 테스트)을 거쳐 최종 확정할 예정입니다.

### 최종 예측 모델의 핵심 입력 피처 (5대 Absolute FA Score)
1. **`생활권접점_score` (절대 공간):** 이 전신주는 도로 및 시가화 구역에 얼마나 인접해 있는가?
2. **`산지접근성_score` (절대 공간):** 이 전신주는 고도가 높고 임도에 얼마나 인접해 있는가?
3. **`선행건조_score` (절대 기상):** 관측 시점 이전 1~3일간 습도가 절대적으로 얼마나 낮았는가?
4. **`강풍_score` (절대 기상):** 관측 시점 및 직전 24시간의 바람이 절대적으로 얼마나 강했는가?
5. **`강수부족_score` (절대 기상):** 관측 시점 기준 최근 강수량이 절대적으로 얼마나 부족했는가?

### 그럼 매칭 비발생(상대 Delta) FA는 원천적으로 학습에 못 쓰나요?
구조적으로 불가능한 것은 아닙니다! 기상학에서는 이를 **'기상 이변도(Anomaly)'**라고 부르며, 머신러닝의 훌륭한 파생 변수로 쓰일 수 있습니다. (공간 대조군에 뽑힌 무작위 위치라도, 그 위치의 '과거 평년 기상'을 뺀 Delta 값을 계산하면 변수로 넣을 수 있습니다.)

하지만 실무 시스템 배포(Inference) 관점에서 보면 이야기가 다릅니다.
만약 이 예측 모델이 한전 시스템에 올라가 내일 오전 10시 강원도 전신주 10만 개의 위험도를 실시간으로 계산해야 한다고 가정해 봅시다.
- **절대 기상 FA 사용 시:** 내일 기상청 예보(바람 10m/s 등)만 모델에 딱 집어넣으면 곧바로 확률이 계산됩니다. 매우 빠르고 가볍습니다.
- **상대(Delta) 기상 FA 사용 시:** 모델이 예측을 하려면 10만 개 전신주 각각의 '과거 10년 치 평년 기상 데이터베이스'를 뒤져서 평균을 빼고(Delta 계산) 점수로 변환해야 합니다. 실시간 연산 비용(Cost)과 DB 부하가 상상을 초월하게 됩니다.

따라서 배포 가성비 측면에서 매칭비발생 FA는 예측 모델의 입력 변수(X)에서 제외하는 것이 정석입니다. 대신, **"산불은 단순한 절대 수치뿐만 아니라 평소 평균 날씨 대비 기상이 갑자기 악화될 때 발화 임계점을 넘는다"**는 인사이트를 도출하는 **탐색적 데이터 분석(EDA/Report) 용도**로 쓰이며, 이 인사이트 덕분에 우리가 학습 데이터 대조군에 1번 그룹(시간 대조군)을 반드시 넣어야 한다는 완벽한 논리적 정당성을 얻게 됩니다.

## 4. 향후 Action Plan

1. **듀얼 네거티브 샘플링 데이터셋 구축:**
   - [Target 1] 실제 산불 (1건)
   - [Target 0-A] 시간 대조군: 실제 위치 + 평상시 무작위 기상 (5건)
   - [Target 0-B] 공간 대조군: 무작위 위치 + 1년 365일 무작위 기상 (5건)
   - **데이터 오염 필터링:** 무작위로 생성한 0-B 샘플 중 실제 Target 1과 시/공간이 겹치는 샘플은 필터링(제외)하여 데이터 무결성을 확보합니다.
2. **피처 엔지니어링 (Feature Engineering):**
   - 구축된 모든 0과 1 데이터셋에 대해 5대 '절대 FA 요인점수' 및 원본 기상 변수 매핑.
3. **모델 학습 및 클래스 불균형 처리:**
   - 1:10 비율(Target 1 : Target 0)의 잔존 불균형을 해소하기 위해 모델 학습 시 클래스 가중치 조정(예: LightGBM의 `scale_pos_weight` 파라미터 활용) 기법을 적용합니다.
4. **변수 조합 A/B/C 테스트 (성능 vs SHAP 해석력 교환비 검증):**
   - **Set A (FA 점수 5개만 투입):** SHAP 해석이 가장 깔끔하게 떨어지지만 예측 성능이 다소 낮아질 수 있는지 확인합니다.
   - **Set B (원본 변수들만 투입):** 트리가 날카로운 임계치를 직접 찾아내므로 성능이 매우 우수할 것으로 예상되나, SHAP 기여도가 자잘한 변수들로 쪼개지는지 확인합니다.
   - **Set C (FA 점수 + 원본 변수 동시 투입):** 성능이 가장 높게 나오겠지만, 다중공선성으로 인해 SHAP 해석이 완전히 파괴(기여도 분산)되는지 실제 눈으로 확인합니다.
5. **다각적 평가 및 최종 모델/변수셋 확정:**
   - **평가 지표 세분화:** '쉬운 오답(0-B)'으로 인한 AUROC 착시를 방지하기 위해 **AUPRC (PR-AUC) 및 F1-Score**를 핵심 평가지표로 추가합니다. 또한 전체 성능뿐만 아니라 `[Target 1 vs 0-A(Hard Negative)]`와 `[Target 1 vs 0-B(Easy Negative)]`를 분리하여 분류 성능을 측정합니다.
   - 위 4번의 A/B/C 테스트를 통해 얻어낸 정밀한 성능 지표와 (SHAP의 깔끔함)을 저울질합니다. 예를 들어 Set A의 성능이 Set C보다 불과 1% 낮다면, SHAP 해석을 살리기 위해 과감히 Set A를 채택합니다. 반대로 Set A의 성능이 형편없다면 FA를 버리고 Set B를 채택합니다.
6. **전신주 리스트업 시뮬레이션 및 임계값(Threshold) 설정 (Inference):**
   - 강원도 KEPCO 전신주 전체 좌표를 대상으로 특정 극단적 기상 시나리오 데이터를 대입하여 위험도 확률을 계산합니다.
   - **초고위험 Cut-off 설정:** 실무 가용 인력을 고려하여 "예측 확률 상위 1% 추출" 또는 "재현율(Recall) 90%를 달성하는 확률 임계값 역산" 등 명확한 기준(Threshold)을 설정하여 "당일 즉각 점검이 필요한 초고위험 전신주 리스트" 도출 및 시각화.

# 기상 데이터 및 공간정보 기반 전력 설비 인근 화재 위험도 분석

## 1. 프로젝트 배경

### 1.1 강풍 및 건조 기후로 인한 산불 위험
- **시기:** 초겨울에서 늦봄 (11월 ~ 익년 5월)
- **기상:** 이동성 고기압에 따른 급격한 건조 및 강풍 발생
- **지역 특성:** 강원 지역은 태백산맥 인근 '양간지풍'의 영향으로 산불 위험도가 특히 높음
- **관련 근거:** 산림보호법에 따른 산불조심기간 운영 (매년 2월 ~ 5월, 산림청)

### 1.2 한국전력공사(KEPCO)의 대응
- **현장관리:** 전력설비 화재 예방을 위해 현장 순시 및 대비활동 강화
- **효율화 목표:** 설비 산불발생 위험성 기반의 **'우선순위 선정 모델'** 개발 및 활용
  → 고위험 지역을 대상으로 집중 점검 및 설비 보강공사 추진

---

## 2. 분석 목표

### 2.1 핵심 질문
> **"산불이 발생했을 때, 어떤 전력설비(Pole)가 가장 큰 피해를 입을 위치에 있는가?"**

화재가 "언제, 어디서 발생할지"를 예측하는 것이 **아니라**, 산불이 발생했을 경우 **해당 위치의 지형/산림/기상 조건 때문에 얼마나 크게 확산될 것인가(= 진화 소요시간이 긴 대형 산불이 될 것인가)**를 평가하여 전력설비의 화재 취약성을 이진분류한다.

### 2.2 과제 정의
- **과제 유형:** 이진분류 (Binary Classification)
- **대상:** 전국 전력설비 Pole (송전탑, 전신주 등) 전체
- **분류 기준:**
  - **취약(1):** 해당 Pole 위치에서 산불이 발생할 경우, 지형·산림·기상 조건 상 대형 산불(진화 소요시간이 긴 산불)로 확산될 가능성이 높은 설비
  - **안전(0):** 산불 확산 위험이 낮은 설비 (도심지, 평탄지, 산림 미인접 등)

### 2.3 최종 결과물
- 전체 Pole에 대한 **화재 취약성 점수 및 이진분류 결과**
- KEPCO 현장 인력을 위한 **점검 우선순위 리스트** (위험도 상위 Pole 목록)
- 기상 조건(풍속, 습도 등)에 따라 **동적으로 변화하는 위험도 평가 체계**

## 3. 모델 설계

### 3.1 모델이 학습하는 것

과거 실제 산불 데이터를 기반으로, **"어떤 공간적·기상적 조건에서 산불이 크게 번졌는가(진화 소요시간이 길었는가)"**를 학습한다.

```
학습 데이터: 과거 산불 발생 기록 (좌표 + 진화소요시간)
  │
  ├─ X (입력 피처): 해당 산불 좌표의 조건들
  │   ├─ 지형: 경사도, TPI(능선/계곡), TWI(건조도), 고도, 사면방향
  │   ├─ 산림: 침엽수/활엽수/혼효림 여부, 영급, 소밀도
  │   └─ 기상: 당일 최대순간풍속, 평균습도, 기온, 연속무강수일 등
  │
  └─ Y (타겟): 진화소요시간(HH)
      ├─ 임계값 이상 → 취약(1): 대형 산불 (오래 타서 확산됨)
      └─ 임계값 미만 → 안전(0): 소형 산불 (빠르게 진화됨)
```

### 3.2 모델이 예측하는 것

학습된 모델에 **각 Pole 좌표의 동일한 피처(지형/산림/기상)**를 입력하면, 해당 Pole 위치에서 산불이 발생했을 경우 대형 산불로 번질 확률(취약도 점수)을 출력한다.

```
예측 과정:
  Pole 좌표 (위도, 경도)
  │
  ├─ DEM에서 추출: 경사도, TPI, TWI, 고도, 사면방향
  ├─ 임상도에서 추출: 수종, 영급, 소밀도 (산림이 없으면 NaN → 0 처리)
  └─ ASOS 기상: 특정 날짜의 풍속, 습도, 기온 등
  │
  → 학습된 모델에 입력
  │
  → 출력: "이 Pole에서 산불이 나면 대형 산불이 될 확률 = 87%"
  → 이진분류: 취약(1)
```

### 3.3 산림 밖 인접 Pole의 처리: 비화(Spotting) 공식 적용

ML 모델의 학습 데이터는 전부 **산림 내부에서 발생한 산불 기록**이다. 따라서 산림 밖에 위치한 Pole에 대해서는 모델이 학습한 근거가 없으므로, ML 예측을 적용할 수 없다.

그러나 산림 밖이라도 **산림 경계에 인접한 Pole**은 산불 발생 시 비화(飛火, Spotting/Firebrand)에 의해 불씨가 날아와 피해를 입을 수 있다. 이를 판정하기 위해 **ML이 아닌 비화 거리 공식(물리적 모델)**을 별도로 적용한다.

#### 3.3.1 비화(Spotting)란?
산불 발생 시 불씨(firebrand)가 화염의 상승 기류(plume)에 의해 공중으로 올라간 뒤, 바람을 타고 멀리 떨어진 지점으로 이동하여 새로운 착화점을 만드는 현상이다. 대형 산불의 예측 불가능한 확산의 주요 원인이며, 전력설비에 직접적인 위협이 된다.

#### 3.3.2 비화 거리 산정 근거

비화 거리는 **Albini(1979, 1983)의 비화 모델**을 기반으로 산정한다. 이 모델은 미국 산림청(USDA Forest Service)에서 개발되었으며, BehavePlus 등 전 세계 산불 행동 예측 시스템의 표준으로 사용되고 있다.

**비화 거리를 결정하는 주요 변수:**
- **풍속 (Wind Speed):** 비화 거리를 결정하는 가장 핵심적인 변수. 풍속이 높을수록 불씨가 더 멀리 이동
- **화염 높이 / 플룸 높이:** 불씨가 올라가는 높이. 수관화(Crown Fire)일수록 높아짐
- **불씨 특성:** 크기, 형태, 연소 지속 시간
- **지형:** 경사도, 골짜기 효과에 의한 풍속 가속

**실증 데이터 기반 비화 거리 참고치:**

| 화재 강도 | 풍속 조건 | 일반적 비화 거리 | 극단적 사례 |
|---|---|---|---|
| 지표화 (Surface Fire) | 10 m/s 이하 | 수십 ~ 수백 m | - |
| 수관화 (Crown Fire) | 10~15 m/s | **1 ~ 2 km** | - |
| 대형 수관화 | 15~20 m/s 이상 | **2 ~ 5 km** | 최대 30km 이상 (호주 Black Saturday, 2009) |

> **참고 문헌:**
> - Albini, F.A. (1979). "Spot fire distance from burning trees - a predictive model." USDA Forest Service, GTR-INT-56.
> - Albini, F.A. (1983). "Potential spotting distance from wind-driven surface fires." USDA Forest Service, GTR-INT-309.
> - BehavePlus (NWCG) 산불 행동 예측 시스템
> - 국립산림과학원(NIFOS) 산불 확산 예측 알고리즘 연구

#### 3.3.3 본 프로젝트에서의 적용 방법

비화 거리의 정확한 계산에는 화염 높이, 불씨 크기 등 현실적으로 확보 불가능한 파라미터가 필요하므로, 본 프로젝트에서는 **보수적(최악의 시나리오) 기준**으로 단순화하여 적용한다.

```
적용 로직:
  1. 각 Pole과 가장 가까운 산림 경계까지의 거리(D)를 계산
  2. 해당 날짜의 최대순간풍속(W)을 확인
  3. 풍속별 비화 위험 반경(R)을 설정:
     - W < 10 m/s  → R = 200m  (지표화 수준의 비화)
     - 10 ≤ W < 15  → R = 500m  (수관화 가능성)
     - 15 ≤ W < 20  → R = 1,000m (대형 산불 비화)
     - W ≥ 20       → R = 2,000m (극단적 비화)
  4. 판정:
     - D ≤ R → 비화 위험 있음 (취약 판정에 포함)
     - D > R → 비화 영향권 밖 (안전)
```

> ※ 위 반경(R) 값은 Albini 모델 및 실증 데이터를 참고한 보수적 기준이며, 프로젝트 진행 과정에서 국내 연구(국립산림과학원 등)의 실측 데이터를 반영하여 조정할 수 있다.

### 3.4 Pole 분류 체계 (하이브리드 모델)

모든 Pole은 위치에 따라 아래 3가지 영역 중 하나로 분류되며, 각 영역별로 다른 판단 방법을 적용한다.

```
[전체 Pole]
  │
  ├─ ① 산림 내부 Pole (임상도 값 존재)
  │   └─ 판단: ML 모델 (진화소요시간 기반 대형 산불 확률 예측)
  │   └─ 피처: 지형(경사도/TPI/TWI) + 산림(수종/영급/소밀도) + 기상(풍속/습도)
  │
  ├─ ② 산림 밖 ~ 비화 반경(R) 이내 Pole
  │   └─ 판단: 비화 공식 (Albini 모델 기반 풍속별 비화 거리)
  │   └─ 로직: 산림 경계까지 거리(D) ≤ 비화 반경(R) → 취약(1)
  │   └─ 추가: 인접 산림의 수종(침엽수 여부)에 따라 위험 가중치 부여
  │
  └─ ③ 비화 반경 밖 Pole (도심 등)
      └─ 판단: 자동 안전(0)
      └─ 근거: 산불 영향권 밖, 비화 불씨 도달 불가
```

| 영역 | 판단 방법 | 근거 | 비율 (추정) |
|---|---|---|---|
| ① 산림 내부 | **ML 모델** | 과거 산불 데이터 학습 | ~20% |
| ② 산림 인접 (비화 위험) | **비화 공식 (논문)** | Albini 모델 + 풍속 | ~10~15% |
| ③ 비화 반경 밖 | **자동 안전(0)** | 산불 영향권 외 | ~65~70% |

### 3.5 동적 위험도 (날씨에 따른 변화)

동일한 Pole이라도 날씨에 따라 위험도가 달라진다:
- **평상시 (비 오는 날):** 습도 높고 바람 약함 → 위험도 낮음
- **양간지풍 발생일:** 최대순간풍속 15m/s 이상, 습도 20% 이하 → 위험도 급등

**ML 모델 영역 (①):** 기상 피처를 날짜별로 바꿔 넣으면 위험도가 동적으로 변화
**비화 공식 영역 (②):** 풍속이 올라가면 비화 반경(R)이 확대 → 더 많은 Pole이 위험 영역에 진입

따라서 **"오늘 날씨 기준으로 가장 위험한 Pole Top N"**을 매일 갱신하는 실시간 모니터링이 가능하다.

### 3.6 베이지안 사후 확률(Bayesian Posterior)을 이용한 인적 발화(등산로) 위험 요인 보정
> 본 내용은 아직 가설이며, EDA 이후 판단해야 할 과제이다

ML 모델(진화소요시간 기반 대형 산불 예측)은 순수하게 **"물리적/자연 환경적 요인(지형, 산림, 기상)"**에 따른 산불의 확산 심각도만을 학습한다. 인위적 발화 요인인 등산객 실화(담배꽁초 등)는 물리적 확산 공식과 무관하며, ML 모델 학습에 노이즈를 유발할 수 있다.

따라서 본 프로젝트에서는 **학습 단계에서는 등산로 데이터를 제외**하고, 예측 단계에서 **베이지안 사후 확률(Bayesian Conditional Probability)을 활용한 사후 보정 가중치**를 적용하여 최종 위험도를 산출한다. 이는 근거 없는 임의의 가중치 부여 문제를 수학적·통계적으로 완벽히 방어한다.

#### 3.6.1 수학적 프레임워크

최종 위험도 점수($Risk_{final}$)는 ML 모델의 물리적 확산 예측 확률($P_{ML}$)에 등산로 근접성에 따른 인적 발화 확률 가중치($W_{human}$)를 결합하여 산정한다.

$$Risk_{final} = P_{ML} \times (1 + W_{human})$$

이때, 인적 발화 가중치 $W_{human}$는 베이지안 조건부 확률을 활용하여 아래와 같이 정의한다.

$$W_{human} = P(\text{등산객실화} | \text{산불}) \times P(\text{등산로근접} | \text{등산객실화}) \times f(Distance)$$

1. **$P(\text{등산객실화} | \text{산불})$ (실증 통계):**
   - 전체 산불 중 등산객 실화(입산자 실화, 담배꽁초 등)가 차지하는 역사적 비율.
   - 예: 산림청 통계 기준 전체 산불의 약 **35% ~ 40%**가 입산자 실화에 기인하므로, 상수값(예: 0.38)으로 매핑.
2. **$P(\text{등산로근접} | \text{등산객실화})$ (조건부 확률):**
   - 등산객 실화로 판정된 화재 중, 실제로 등산로 인근(예: 100m~300m 이내)에서 발화한 비율.
   - 이 비율 역시 과거 산불 세부 이력 데이터를 통해 공간 통계적으로 산출 가능 (예: 0.85).
3. **$f(Distance)$ (거리 감쇄 함수):**
   - Pole과 등산로 사이의 최단거리($D$)에 따른 위험도 감쇄. 등산로와 가까울수록 1에 수렴하고, 멀어질수록 0으로 급격히 감소하는 지수 감쇄(Exponential Decay) 함수를 적용.
   - $$f(Distance) = e^{-\lambda \cdot D}$$ (단, $D$는 등산로 최단거리, $\lambda$는 감쇄 계수)

#### 3.6.2 이 방식의 학술적·통계적 장점

1. **임의성 배제:** "등산로 옆이니까 1.2배 곱한다" 같은 주관적인 판단이 아니라, 산림청 공식 통계인 **"전체 산불 중 입산자 실화 비율"**이라는 실제 확률값에 기반하여 가중치의 최대 스케일을 통제한다.
2. **ML 모델의 정체성 보호:** 물리적 확산(경사, 바람) 모델인 ML 예측 영역에 사람의 행동 패턴(등산로)이라는 노이즈가 섞여 성능이 교란되는 현상을 원천 방지한다.
3. **위험의 총체적 정의:** 재난 관리론에서 정의하는 위험(Risk)의 공식인 **"위험도(Risk) = 취약도(Vulnerability, ML 모델) × 위해도(Hazard, 인적 발화 가능성)"**를 수학적으로 가장 완벽하게 구현한다.

## 5. 분석 파이프라인

```
[STEP 1] 데이터 결합
  산불발생위치도(좌표) + 산불상태별이력(진화소요시간) → 결합
  + 지형특성(DEM/TWI) + 임상도 + ASOS 기상 → 학습용 데이터셋 완성

[STEP 2] 타겟(Y) 라벨링
  진화소요시간 기준 임계값 설정 (예: 상위 25% 또는 특정 시간 이상)
  → 대형 산불(1) vs 소형 산불(0) 이진분류 라벨 생성

[STEP 3] 모델 학습
  XGBoost 등 트리 기반 앙상블 모델 학습
  Optuna를 활용한 하이퍼파라미터 튜닝
  SHAP 분석을 통한 피처 중요도 해석

[STEP 4] Pole 예측 데이터 준비
  전력설비 Pole 좌표 → DEM/임상도/TWI/기상 피처 동일하게 추출

[STEP 5] 예측 및 결과 도출
  학습된 모델로 모든 Pole의 화재 취약 확률 예측
  → 취약(1) / 안전(0) 이진분류
  → 위험도 상위 Pole 리스트 생성

[STEP 6] 시각화 및 결론
  GIS 기반 화재 취약 Pole 지도 (Risk Map) 작성
  기상 조건별 동적 위험도 변화 시뮬레이션
  KEPCO 점검 우선순위 가이드라인 제언
```

## 6. 과거 수상작 대비 차별화 포인트

| 항목 | 과거 수상작 (기상-화재 상관분석) | 본 프로젝트 |
|---|---|---|
| 분석 단위 | 시군구 (행정구역) | **개별 Pole 좌표 (인프라 단위)** |
| 공간 해상도 | 낮음 (시군구 평균) | **90m DEM + 임상도 = 초고해상도** |
| 타겟(Y) | 화재 발생 건수 / 여부 | **진화소요시간 기반 대형 산불 여부** |
| 활용 피처 | 기상 위주 | **기상 + 지형(TPI/TWI/경사도) + 임상도** |
| 결과물 | "이 지역 화재 위험" | **"이 Pole이 위험 → 여기 먼저 점검"** |
| 활용 대상 | 소방청/기상청 | **KEPCO 현장 순시 인력** |

## 7. 기대 효과

1. **KEPCO 현장 효율화:** 수만 개의 Pole을 모두 점검할 필요 없이, 위험도 상위 N%만 집중 관리
2. **동적 대응 체계:** 강풍특보/건조특보 발효 시, 해당 기상 조건에서 가장 위험한 Pole을 실시간 식별
3. **설비 보강 우선순위:** 만성적으로 위험도가 높은 Pole(급경사 침엽수림 인접) → 장기적 설비 보강/지중화 사업 대상 선정 근거
